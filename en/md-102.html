MD-102 sample questions

Five real questions from our 739-question bank. Try to answer before revealing the solution.

1. You want to create a device group in Microsoft Entra ID that automatically includes all corporate-owned devices. Which dynamic membership rule attribute should you use?

  1. device.operatingSystem -eq 'Windows'
  2. device.deviceOwnership -eq 'Company'
  3. device.isCompliant -eq true
  4. device.managementType -eq 'MDM'
Show answer

Correct answer: B. The device.deviceOwnership attribute with value 'Company' identifies corporate-owned devices, as opposed to 'Personal' for BYOD devices.

2. An administrator wants to configure Always On VPN on Windows devices managed by Intune so users are always connected to the corporate VPN without manually connecting. Which Intune profile type should they create?

  1. Device restrictions profile > Network section with Always On VPN options
  2. Windows device configuration profile of type VPN with Always On option enabled
  3. Endpoint Protection profile > VPN section with split tunnel configuration
  4. Conditional Access policy with corporate VPN requirement for resource access
Show answer

Correct answer: B. VPN profiles for Windows in Intune allow configuring Always On VPN, which keeps the VPN connection active at all times. It supports different VPN clients (Microsoft VPN, IKEv2, etc.).

3. Which Microsoft 365 Apps update channel provides the fastest updates with the latest features but with less pre-release testing?

  1. Current Channel
  2. Monthly Enterprise Channel
  3. Semi-Annual Enterprise Channel
  4. Beta Channel
Show answer

Correct answer: A. Current Channel receives new features as soon as they are ready, typically several times per month. It is the fastest but with less enterprise pre-release testing.

4. You enable App Control for Business but want apps deployed through Intune to keep running without adding each one to the policy. What should you configure?

  1. An attack surface reduction rule that blocks Office macros
  2. A Windows Defender Firewall rule for each installed application
  3. The Intune Management Extension as a managed installer
  4. A security baseline that disables SmartScreen for those apps
Show answer

Correct answer: C. In Endpoint security > App Control for Business, you can set the Intune Management Extension as a managed installer so apps it deploys are trusted automatically by App Control policies.

5. Which Microsoft Graph endpoint version should production automation for Intune generally use?

  1. v1.0, because beta APIs can change without notice
  2. beta, because it is always more stable
  3. Either one; Microsoft guarantees both equally
  4. The legacy Azure AD Graph endpoint
Show answer

Correct answer: A. The v1.0 endpoint is supported for production; beta is subject to breaking changes. Azure AD Graph is retired.
