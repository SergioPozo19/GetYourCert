AB-900 · Dominio 3 de 3 · 25-30% del examen

Administración de Copilot y agentes

El dominio 3 de AB-900 supone entre el 25 y el 30% del examen. En EarnYourCert tienes 174 preguntas originales de este dominio, todas con explicación: 110 de opción múltiple, 38 de sí o no y 26 de completar u ordenar, como en el examen real.

Practicar el dominio 3 gratis →Sin registro. Elige cuántas preguntas quieres hacer.

Qué entra en este dominio

  • Licencias: Microsoft 365 Copilot frente a Copilot Chat
  • Cómo Copilot usa Microsoft Graph y respeta los permisos existentes
  • Agentes: creación con Copilot Studio y administración desde el centro de administración
  • Informes de uso y adopción de Copilot

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 174 para este dominio. Intenta responder antes de ver la solución.

1. Una empresa prevé un consumo variable de agentes y no quiere comprometerse a una cuota fija por usuario. ¿Qué modelo de facturación encaja?

  1. Una licencia gratuita para todo el inquilino
  2. Una licencia por dispositivo de cada usuario
  3. El pago por uso (PAYG) facturado por consumo
  4. La licencia mensual fija asignada por usuario
Ver respuesta

Respuesta correcta: C. El pago por uso encaja con un consumo variable, ya que factura según el uso de los agentes. La licencia mensual es una cuota fija, no existe una licencia gratuita para todo el inquilino y la licencia por dispositivo no aplica.

2. ¿Qué describe mejor a un agente en el contexto de Microsoft 365 Copilot?

  1. Un servicio de identidad que autentica a los usuarios de Copilot
  2. Un buzón de recursos que almacena las conversaciones del usuario
  3. Una experiencia especializada construida sobre el modelo de Copilot
  4. Una directiva que bloquea el contenido sensible en los prompts
Ver respuesta

Respuesta correcta: C. Un agente es una experiencia especializada construida sobre el modelo y la orquestación de Copilot, con instrucciones, conocimiento y acciones. No es un servicio de identidad, una directiva ni un buzón.

3. ¿Qué debe asignar un administrador para que un usuario use Copilot?

  1. Una carpeta pública en la web para el usuario nuevo
  2. Una impresora compartida al equipo físico del usuario
  3. Una licencia de Copilot válida a la cuenta del usuario
  4. Un fondo de pantalla corporativo al equipo del usuario
Ver respuesta

Respuesta correcta: C. Correcto: Una licencia de Copilot válida a la cuenta del usuario.

4. Un administrador quiere eliminar un prompt inapropiado que un usuario compartió en Copilot Prompt Gallery. ¿Qué capacidad de gestión de prompts utiliza?

  1. La capacidad de eliminar prompts dentro de la gestión de la Copilot Prompt Gallery
  2. El portal de Microsoft Defender, mediante una directiva de protección frente a amenazas
  3. Una directiva DLP que bloquee el contenido sensible que aparece en los prompts
  4. Una etiqueta de retención que controle cuánto tiempo se conservan los prompts
Ver respuesta

Respuesta correcta: A. La gestión de prompts incluye eliminar prompts guardados/compartidos. DLP, retención y Defender no gestionan directamente la eliminación de prompts en Prompt Gallery.

5. Una empresa quiere habilitar el pago por uso de agentes solo para el equipo de marketing. ¿Cómo lo logra?

  1. Creando una directiva de retención para el equipo
  2. Con una directiva de facturación con ámbito en ese grupo
  3. Asignando la licencia mensual a todo el inquilino entero
  4. Aplicando una etiqueta de confidencialidad al equipo
Ver respuesta

Respuesta correcta: B. Una directiva de facturación con ámbito en el grupo de marketing habilita PAYG solo para ese equipo. La licencia mensual al inquilino entero no acota PAYG, y la etiqueta o la retención no controlan la facturación.

6. ¿Qué ventaja aporta un agente declarativo frente a empezar desde cero?

  1. Se configura con instrucciones y datos sin necesidad de programar
  2. Obliga a reescribir por completo el modelo de lenguaje base
  3. Funciona únicamente sin ninguna conexión a internet de la nube
  4. Impide por completo usar los datos propios de la organización
Ver respuesta

Respuesta correcta: A. Correcto: Se configura con instrucciones y datos sin necesidad de programar.

7. ¿Qué describe correctamente el propósito del registro de agentes (Agent Registry)?

  1. Inventariar los agentes desplegados y mostrar sus riesgos
  2. Crear los buzones compartidos para las conversaciones
  3. Asignar las licencias de Copilot a los creadores de agentes
  4. Cifrar el contenido al que acceden todos los agentes
Ver respuesta

Respuesta correcta: A. El Agent Registry inventaría los agentes desplegados y muestra sus riesgos, como las alertas de alta severidad. No cifra contenido, no asigna licencias ni crea buzones.

8. ¿Qué herramienta controla quién puede generar cargos de pago por uso?

  1. Copilot Studio se usa para crear y personalizar agentes
  2. Una directiva de facturación controla quién genera cargos
  3. Copilot Prompt Gallery guarda y comparte las indicaciones
  4. Viva Insights mide la adopción y el impacto de Copilot
Ver respuesta

Respuesta correcta: B. Correcto: Una directiva de facturación controla quién genera cargos.
