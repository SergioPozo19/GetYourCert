8 questions from our 174-question bank for this domain. Try to answer before revealing the solution.

1. A company expects variable agent consumption and does not want to commit to a fixed per-user fee. Which billing model fits?

  1. A free license for the entire tenant
  2. A per-device license for each user
  3. Pay-as-you-go (PAYG) billed by consumption
  4. The fixed monthly license assigned per user
Show answer

Correct answer: C. Pay-as-you-go fits variable consumption, since it bills based on agents' usage. The monthly license is a fixed fee, there is no free tenant-wide license, and a per-device license does not apply.

2. What best describes an agent in the context of Microsoft 365 Copilot?

  1. An identity service that authenticates Copilot's users
  2. A resource mailbox that stores the user's conversations
  3. A specialized experience built on Copilot's model
  4. A policy that blocks sensitive content in the prompts
Show answer

Correct answer: C. An agent is a specialized experience built on Copilot's model and orchestration, with instructions, knowledge, and actions. It is not an identity service, a policy, or a mailbox.

3. What must an admin assign for a user to use Copilot?

  1. A public web folder for the new user account
  2. A shared printer to the user's physical device
  3. A valid Copilot license to the user's account
  4. A corporate wallpaper to the user's device
Show answer

Correct answer: C. Correct: A valid Copilot license to the user's account.

4. An admin wants to delete an inappropriate prompt a user shared in Copilot Prompt Gallery. Which prompt-management capability is used?

  1. The ability to delete prompts within the management of the Copilot Prompt Gallery
  2. The Microsoft Defender portal, via a threat protection policy
  3. A DLP policy that blocks the sensitive content appearing in the prompts
  4. A retention label that controls how long the prompts are kept
Show answer

Correct answer: A. Prompt management includes deleting saved/shared prompts. DLP, retention, and Defender do not directly manage prompt deletion in Prompt Gallery.

5. A company wants to enable agent pay-as-you-go only for the marketing team. How does it achieve this?

  1. By creating a retention policy for the team
  2. With a billing policy scoped to that group
  3. By assigning the monthly license to the whole tenant
  4. By applying a sensitivity label to the team
Show answer

Correct answer: B. A billing policy scoped to the marketing group enables PAYG only for that team. A tenant-wide monthly license does not scope PAYG, and a label or retention do not control billing.

6. What advantage does a declarative agent offer over starting from scratch?

  1. It's set up with instructions and data, with no need to code
  2. It forces fully rewriting the underlying base language model
  3. It works only without any internet connection to the cloud
  4. It completely prevents using the organization's own data
Show answer

Correct answer: A. Correct: It's set up with instructions and data, with no need to code.

7. What correctly describes the purpose of the Agent Registry?

  1. Inventory the deployed agents and show their risks
  2. Create the shared mailboxes for the conversations
  3. Assign Copilot licenses to the agent creators
  4. Encrypt the content all the agents access
Show answer

Correct answer: A. The Agent Registry inventories the deployed agents and shows their risks, such as high-severity alerts. It does not encrypt content, assign licenses, or create mailboxes.

8. Which tool controls who can generate pay-as-you-go charges?

  1. Copilot Studio is used to build and customize agents
  2. A billing policy controls who can generate charges
  3. Copilot Prompt Gallery saves and shares the prompts
  4. Viva Insights measures Copilot adoption and impact
Show answer

Correct answer: B. Correct: A billing policy controls who can generate charges.
