SC-900 · Dominio 4 de 4 · 20-25% del examen

Describir las funcionalidades de las soluciones de cumplimiento de Microsoft

El dominio 4 de SC-900 supone entre el 20 y el 25% del examen. En EarnYourCert tienes 103 preguntas originales de este dominio, todas con explicación: 65 de opción múltiple, 16 de sí o no y 22 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 4

8 preguntas de nuestro banco de 103 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué solución de Microsoft Priva identifica datos personales sobreexpuestos o conservados demasiado tiempo y guía a los usuarios para corregirlo?

  1. eDiscovery (Premium) con conjuntos de revisión
  2. Solicitudes de derechos del interesado
  3. Administración de riesgos de privacidad
  4. Caja de seguridad del cliente
Ver respuesta

Respuesta correcta: C. Las directivas de administración de riesgos de privacidad detectan sobreexposición, transferencias y problemas de minimización de datos.

2. ¿Cómo pondera Compliance Manager las acciones de mejora en la puntuación de cumplimiento?

  1. Todas las acciones valen lo mismo
  2. Con puntos según el tipo y el riesgo del control
  3. Por el coste de cada acción
  4. Solo por cuántos usuarios las completaron el último mes
Ver respuesta

Respuesta correcta: B. Las acciones obligatorias y preventivas puntúan más que las discrecionales o de detección.

3. ¿Para qué se usan las etiquetas de confidencialidad en Microsoft Purview?

  1. Decidir cuánto tiempo se conserva el contenido y cuándo se elimina automáticamente
  2. Clasificar y proteger contenido con marcas, cifrado y restricciones
  3. Crear cuentas de usuario
  4. Supervisar el tráfico de red en busca de datos confidenciales que salen de la red
Ver respuesta

Respuesta correcta: B. Las etiquetas de confidencialidad acompañan al contenido y pueden aplicar cifrado, marcas de contenido y control de acceso.

4. ¿Qué configuración de una etiqueta de confidencialidad puede restringir quién puede abrir, editar o imprimir un documento?

  1. Conector de datos
  2. Retención del registro de auditoría
  3. Cifrado con permisos asignados
  4. Período de retención
Ver respuesta

Respuesta correcta: C. El cifrado de la etiqueta usa la administración de derechos para aplicar permisos allí donde vaya el archivo.

5. ¿Qué capacidad de DLP protege los datos confidenciales en dispositivos Windows y macOS, por ejemplo bloqueando la copia a unidades USB?

  1. Vínculos seguros
  2. DLP de endpoints
  3. Azure Firewall
  4. Entra Private Access
Ver respuesta

Respuesta correcta: B. DLP de endpoints supervisa y restringe actividades en los dispositivos.

6. ¿Qué puede hacer una sugerencia de directiva DLP?

  1. Eliminar el buzón del usuario
  2. Crear una regla de firewall que bloquee el dispositivo del usuario hasta quitar el contenido
  3. Restablecer la contraseña del usuario y exigir el registro de MFA en el siguiente inicio de sesión
  4. Advertir al usuario de que una acción puede infringir la directiva, permitiendo opcionalmente invalidarla
Ver respuesta

Respuesta correcta: D. Las sugerencias de directiva educan a los usuarios en el momento de riesgo.

7. ¿Qué herramienta de Purview ayuda a ver las tendencias de las actividades de etiquetas, como las etiquetas aplicadas, cambiadas o eliminadas?

  1. Explorador de actividad
  2. Explorador de contenido
  3. Service Trust Portal
  4. Simulación de ataques
Ver respuesta

Respuesta correcta: A. El Explorador de actividad muestra la actividad de etiquetas y DLP a lo largo del tiempo.

8. ¿Qué ocurre con el contenido cuando se coloca en una retención de eDiscovery?

  1. Se elimina de inmediato
  2. Se conserva aunque los usuarios lo editen o eliminen
  3. Se comparte automáticamente con el equipo legal contrario
  4. Se cifra con una clave nueva
Ver respuesta

Respuesta correcta: B. Las retenciones conservan el contenido en su ubicación mientras dure el caso.
