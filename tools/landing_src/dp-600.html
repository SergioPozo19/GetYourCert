Confusiones típicas en el examen

Common exam traps

Almacén de lago frente a almacén de datos

Lakehouse vs warehouse

El almacén de lago guarda archivos y tablas Delta y se trabaja sobre todo con Spark (su punto de conexión SQL es de solo lectura); el almacén de datos admite T-SQL completo con escrituras.

A lakehouse stores files and Delta tables and is worked mainly with Spark (its SQL endpoint is read-only); a warehouse supports full T-SQL with writes.

Direct Lake frente a DirectQuery

Direct Lake vs DirectQuery

Direct Lake lee directamente las tablas Delta de OneLake con rendimiento cercano a Import y sin copiar datos; DirectQuery manda consultas a la fuente en cada interacción.

Direct Lake reads Delta tables in OneLake directly, with near-Import performance and no data copy; DirectQuery sends queries to the source on every interaction.

Acceso directo frente a copiar datos

Shortcut vs copying data

Un acceso directo apunta a datos que ya están en otro lugar (otro almacén de lago, ADLS, S3) sin moverlos; copiar duplica el almacenamiento y hay que mantenerlo sincronizado.

A shortcut points to data that already lives elsewhere (another lakehouse, ADLS, S3) without moving it; copying duplicates storage and must be kept in sync.
