Domain 2 sample questions

8 questions from our 114-question bank for this domain. Try to answer before revealing the solution.

1. An employee works remotely and signs in from a personal laptop that is not managed by the organization. Which Microsoft Entra concept lets the company still recognize and control this device for access decisions?

  1. A guest user
  2. Microsoft Entra Domain Services
  3. An administrative unit
  4. Microsoft Entra registered device
Show answer

Correct answer: D. Registered devices represent personally owned devices that access organizational resources.

2. Which feature lets users reset their own forgotten passwords without calling the help desk?

  1. Access reviews
  2. Privileged Identity Management
  3. Self-service password reset (SSPR)
  4. Conditional Access
Show answer

Correct answer: C. SSPR lets users verify their identity with registered methods and reset their own password.

3. Which statement about passkeys is correct?

  1. Passkeys work only offline
  2. Passkeys use public-key cryptography, so there is no shared secret that can be phished
  3. Passkeys store the user's password in plain text
  4. Passkeys are the same as security questions
Show answer

Correct answer: B. Passkeys bind credentials to the relying party and are phishing-resistant.

4. Which authentication method is a physical USB or NFC device that provides phishing-resistant passwordless sign-in?

  1. FIDO2 security key
  2. Security questions answered during password reset
  3. SMS verification code
  4. Voice call
Show answer

Correct answer: A. FIDO2 security keys hold a passkey bound to the site, so codes cannot be phished.

5. A new employee has no credentials yet and must register a passkey on day one. Which method lets them sign in once for a limited time?

  1. Security defaults
  2. Smart lockout
  3. A permanent password shared by the help desk team
  4. Temporary Access Pass
Show answer

Correct answer: D. A Temporary Access Pass is a time-limited passcode used to onboard or recover passwordless methods.

6. Which role would you assign to an administrator who only needs to reset passwords for non-administrator users?

  1. Global Administrator
  2. Privileged Role Administrator
  3. Security Administrator
  4. Helpdesk Administrator
Show answer

Correct answer: D. Least privilege: Helpdesk Administrator can reset passwords for non-admins without full tenant control.

7. Which capability lets Microsoft Entra ID revoke access in near real time, for example when a user is disabled, instead of waiting for the token to expire?

  1. Password hash synchronization every two minutes
  2. Continuous access evaluation
  3. Report-only mode
  4. Access reviews
Show answer

Correct answer: B. Continuous access evaluation lets supporting services react to critical events such as account disable or location change.

8. What do access reviews in Microsoft Entra ID Governance help an organization do?

  1. Periodically verify that users still need access to groups, apps and roles
  2. Detect risky sign-ins with machine learning
  3. Automatically create user accounts from HR data
  4. Encrypt data stored in SharePoint sites
Show answer

Correct answer: A. Access reviews remove unnecessary access and help prevent permission creep.
