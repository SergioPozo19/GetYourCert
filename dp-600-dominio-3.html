Implementar y administrar modelos semánticos

El dominio 3 de DP-600 supone entre el 25 y el 30% del examen. En EarnYourCert tienes 105 preguntas originales de este dominio, todas con explicación: 64 de opción múltiple, 16 de sí o no y 25 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 105 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué construcción DAX almacena un valor intermedio para reutilizarlo y mejora la legibilidad?

  1. Solo DEFINE
  2. TOPN
  3. VAR ... RETURN
  4. EVALUATE
Ver respuesta

Respuesta correcta: C. Las variables se evalúan una vez y se reutilizan.

2. ¿Qué función DAX devuelve una tabla filtrada por una condición y se usa a menudo como argumento de filtro de CALCULATE?

  1. FORMAT
  2. FILTER
  3. LEN
  4. VALUE
Ver respuesta

Respuesta correcta: B. FILTER devuelve las filas que cumplen un predicado.

3. ¿Qué característica permite a los usuarios del informe cambiar qué medida o columna muestra un objeto visual mediante una segmentación?

  1. Grupos de cálculo
  2. Integración de Git
  3. Parámetros de campo
  4. Replicación
Ver respuesta

Respuesta correcta: C. Los parámetros de campo crean una lista seleccionable de campos.

4. ¿Qué característica debes habilitar cuando un modelo semántico puede superar el límite de tamaño predeterminado y necesita un manejo eficiente de modelos grandes?

  1. Formato de almacenamiento de modelo semántico grande
  2. Aplicaciones de plantilla con actualización incremental
  3. Enmascaramiento dinámico de datos
  4. Etiquetas de confidencialidad en tablas grandes
Ver respuesta

Respuesta correcta: A. El formato grande permite que los modelos crezcan hasta los límites de la capacidad.

5. Un autor de informes quiere ampliar un modelo semántico certificado existente con tablas adicionales de un archivo de Excel sin cambiar el original. ¿Qué enfoque encaja?

  1. Crear un modelo compuesto sobre el modelo semántico (DirectQuery al modelo)
  2. Aplicar una etiqueta de confidencialidad
  3. Copiar el modelo en un PBIX y eliminar el original
  4. Crear una rama de Git
Ver respuesta

Respuesta correcta: A. Los modelos compuestos pueden ampliar modelos semánticos compartidos.

6. ¿Por qué se recomienda deshabilitar Fecha/hora automática en modelos grandes que ya tienen una tabla de fechas?

  1. Habilita Direct Lake
  2. Evita las tablas de fechas ocultas que añaden tamaño
  3. Cifra el modelo
  4. Crea relaciones automáticamente
Ver respuesta

Respuesta correcta: B. Fecha/hora automática crea una tabla oculta por cada columna de fecha.

7. ¿Qué configuración de comportamiento de Direct Lake obliga a las consultas a fallar en lugar de recurrir a DirectQuery?

  1. DirectLakeOnly
  2. DirectQueryOnly
  3. ImportOnly
  4. Automatic
Ver respuesta

Respuesta correcta: A. DirectLakeOnly deshabilita la reserva.

8. ¿Qué característica de las tablas Delta ayuda al rendimiento de Direct Lake comprimiendo y ordenando los datos para lecturas rápidas?

  1. Aprobación
  2. V-Order
  3. Enmascaramiento dinámico de datos
  4. Ramas de Git
Ver respuesta

Respuesta correcta: B. V-Order optimiza los archivos Parquet para lecturas rápidas.
