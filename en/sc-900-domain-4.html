Domain 4 sample questions

8 questions from our 103-question bank for this domain. Try to answer before revealing the solution.

1. Which Microsoft Priva solution identifies personal data that is overexposed or kept too long and guides users to fix it?

  1. eDiscovery (Premium) with review sets
  2. Subject rights requests
  3. Privacy risk management
  4. Customer Lockbox
Show answer

Correct answer: C. Privacy risk management policies detect data overexposure, transfers and minimization issues.

2. How does Compliance Manager weight improvement actions in the compliance score?

  1. All actions are worth the same
  2. By points based on the type and risk of the control
  3. By the cost of each action
  4. Only by how many users completed them in the last month
Show answer

Correct answer: B. Mandatory and preventive actions score more than discretionary or detective ones.

3. What are sensitivity labels in Microsoft Purview used for?

  1. Decide how long content is retained and when it is deleted automatically
  2. Classify and protect content with markings, encryption and restrictions
  3. Create user accounts
  4. Monitor network traffic for sensitive data leaving the corporate network
Show answer

Correct answer: B. Sensitivity labels travel with the content and can enforce encryption, content markings and access control.

4. Which sensitivity label setting can restrict who can open, edit or print a document?

  1. Data connector
  2. Audit log retention
  3. Encryption with assigned permissions
  4. Retention period
Show answer

Correct answer: C. Label encryption uses rights management to enforce permissions wherever the file goes.

5. Which DLP capability protects sensitive data on Windows and macOS devices, for example by blocking copy to USB drives?

  1. Safe Links
  2. Endpoint DLP
  3. Azure Firewall
  4. Entra Private Access
Show answer

Correct answer: B. Endpoint DLP monitors and restricts activities on devices.

6. What can a DLP policy tip do?

  1. Delete the user's mailbox
  2. Create a firewall rule that blocks the user's device until the content is removed
  3. Reset the user's password and require MFA registration at the next sign-in
  4. Warn users that an action may violate policy, optionally allowing an override
Show answer

Correct answer: D. Policy tips educate users at the moment of risk.

7. Which Purview tool helps you see trends of label activities, such as labels applied, changed or removed?

  1. Activity explorer
  2. Content explorer
  3. Service Trust Portal
  4. Attack simulation
Show answer

Correct answer: A. Activity explorer shows label and DLP activity over time.

8. What happens to content when it is placed on an eDiscovery hold?

  1. It is deleted immediately
  2. It is preserved even if users edit or delete it
  3. It is shared with the opposing legal team automatically
  4. It is encrypted with a new key
Show answer

Correct answer: B. Holds preserve content in place for the duration of a case.
