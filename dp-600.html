Preguntas de ejemplo de DP-600

Cinco preguntas reales de nuestro banco de 309. Intenta responder antes de ver la solución.

1. Muchos autores de informes deben reutilizar un modelo semántico gobernado en lugar de crear sus propias copias. ¿Qué enfoque encaja?

  1. Exportar los datos a Excel para cada autor
  2. Crear un PBIX por autor con datos importados
  3. Dar a cada autor el rol de administrador
  4. Crear informes sobre un modelo semántico compartido
Ver respuesta

Respuesta correcta: D. Un modelo compartido da una única fuente de verdad.

2. ¿Qué operador de KQL visualiza los resultados como gráfico, por ejemplo un gráfico temporal?

  1. parse
  2. lookup
  3. top
  4. render
Ver respuesta

Respuesta correcta: D. render dibuja gráficos a partir de los resultados.

3. ¿Qué operador de KQL une dos tablas por una clave, por ejemplo registros y una lista de dispositivos?

  1. render
  2. take
  3. join
  4. extend
Ver respuesta

Respuesta correcta: C. join combina tablas por claves coincidentes.

4. ¿Qué tipo de función DAX evalúa una expresión fila por fila sobre una tabla y luego agrega los resultados?

  1. Operador lógico
  2. Solo función de inteligencia de tiempo
  3. Iterador (por ejemplo SUMX)
  4. Función de información
Ver respuesta

Respuesta correcta: C. Los iteradores crean un contexto de fila.

5. ¿Qué práctica DAX mejora el rendimiento cuando la misma subexpresión se usa varias veces en una medida?

  1. Repetirla cada vez
  2. Guardarla en una variable
  3. Convertirla a texto
  4. Envolverla en FORMAT
Ver respuesta

Respuesta correcta: B. Una variable se evalúa una sola vez.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica DP-600?

El banco de preguntas tiene 309 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar DP-600?

El examen oficial de Microsoft DP-600 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen DP-600?

Tres dominios: mantener una solución de análisis de datos (25-30%), preparar los datos (45-50%) e implementar y administrar modelos semánticos (25-30%).

¿Es gratis el examen de práctica DP-600?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para DP-600, no extractos del examen real ni "exam dumps".
