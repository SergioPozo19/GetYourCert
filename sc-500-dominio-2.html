SC-500 · Dominio 2 de 4 · 25-30% del examen

Proteger almacenamiento, bases de datos y redes

El dominio 2 de SC-500 supone entre el 25 y el 30% del examen, el de más peso del temario. En EarnYourCert tienes 106 preguntas originales de este dominio, todas con explicación: 71 de opción múltiple, 16 de sí o no y 19 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 106 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué configuración de la cuenta de almacenamiento impide el acceso de lectura público anónimo a los blobs a nivel de cuenta?

  1. Deshabilitar 'Permitir acceso anónimo a blobs'
  2. Habilitar contenedores públicos con SAS de solo lectura
  3. Habilitar sitio web estático con un dominio personalizado
  4. Usar claves de cuenta en el código
Ver respuesta

Respuesta correcta: A. Deshabilitar el acceso anónimo es un paso básico de refuerzo.

2. ¿Qué característica garantiza que los datos de blobs no se puedan modificar ni eliminar durante un período determinado para cumplir requisitos normativos?

  1. Una regla de ciclo de vida que elimina blobs tras siete años
  2. Control de versiones de blobs combinado con eliminación temporal
  3. Almacenamiento inmutable con una directiva de retención basada en el tiempo
  4. Un bloqueo de recursos de solo lectura en la cuenta de almacenamiento
Ver respuesta

Respuesta correcta: C. El almacenamiento WORM cumple requisitos como los de la SEC.

3. ¿Adónde escribe sus registros la auditoría de SQL Managed Instance?

  1. Archivos locales en el host de la instancia
  2. Solo los registros de auditoría de Microsoft 365
  3. Azure Storage, Log Analytics o Event Hubs
  4. Solo el registro de actividad de Azure
Ver respuesta

Respuesta correcta: C. Los destinos de auditoría incluyen Storage, Log Analytics y Event Hubs.

4. ¿Qué opción de autenticación para Azure Database for PostgreSQL Flexible Server permite usar identidades de Microsoft Entra?

  1. Tokens públicos
  2. Solo contraseña de administrador compartida
  3. Inicio de sesión anónimo
  4. Autenticación de Microsoft Entra
Ver respuesta

Respuesta correcta: D. La autenticación de Entra centraliza la administración de identidades.

5. ¿Qué tipo de regla de Azure Firewall traduce el tráfico entrante de internet a una IP privada y un puerto de la red virtual?

  1. Reglas de aplicación
  2. Reglas de red
  3. Filtrado basado en inteligencia sobre amenazas
  4. Reglas DNAT
Ver respuesta

Respuesta correcta: D. DNAT publica servicios internos mediante la IP del firewall.

6. Una organización quiere proteger un concentrador de Virtual WAN con inspección de firewall del tráfico entre sucursales y de internet. ¿Qué debe implementar?

  1. Grupos de seguridad de red en cada conexión de sucursal
  2. Un concentrador virtual protegido con Azure Firewall e intención de enrutamiento
  3. Una dirección IP pública en cada dispositivo de sucursal
  4. Un centro virtual sin intención de enrutamiento ni firewall
Ver respuesta

Respuesta correcta: B. La intención de enrutamiento envía el tráfico a través del firewall del concentrador.

7. ¿Qué característica de Network Watcher prueba si las reglas de NSG permiten o deniegan un paquete concreto para una VM?

  1. Comprobación de flujo IP
  2. Solo captura de paquetes
  3. Vista de costes
  4. Solo topología
Ver respuesta

Respuesta correcta: A. La comprobación de flujo IP identifica la regla que permite o deniega el tráfico.

8. Los registros de flujo de NSG se están retirando. ¿Qué característica de Network Watcher debes usar para registrar el tráfico a nivel de red virtual?

  1. Registros de flujo de red virtual
  2. Comprobación del flujo de IP
  3. Monitor de conexión
  4. Captura de paquetes en cada VM de la red virtual
Ver respuesta

Respuesta correcta: A. Los registros de flujo de red virtual registran el tráfico de toda la red, incluido el que no regulan los NSG.
