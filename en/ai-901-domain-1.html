1. A company removes personally identifiable information from training data and restricts access to the dataset. Which principle does this address?

  1. Fairness
  2. Transparency
  3. Privacy and security
  4. Accountability
Show answer

Correct answer: C. Protecting personal data is a privacy matter.

2. Which principle states that people and organizations that design and deploy AI must be answerable for how it operates?

  1. Accountability
  2. Fairness
  3. Inclusiveness
  4. Transparency
Show answer

Correct answer: A. Accountability assigns ownership and oversight.

3. Why should AI solutions be monitored after deployment?

  1. Monitoring makes models smaller
  2. Monitoring removes the need for testing
  3. Performance and behavior can change over time
  4. Monitoring guarantees fairness
Show answer

Correct answer: C. Ongoing monitoring supports reliability and safety.

4. Which content safety layer adds rules to the system message, such as 'only answer using the provided sources'?

  1. Metaprompt and grounding layer
  2. Network security layer of the subscription
  3. Model layer
  4. User experience layer
Show answer

Correct answer: A. The mitigation layers are model, safety system, metaprompt and grounding, and user experience; system message rules belong to the metaprompt layer.

5. What limits how many tokens per minute a deployment can process?

  1. Quota and rate limits
  2. The temperature
  3. The model name
  4. The system message
Show answer

Correct answer: A. Quota controls throughput per deployment.

6. Which text analysis capability identifies the language of a piece of text?

  1. Sentiment analysis
  2. Language detection
  3. Summarization
  4. Image tagging
Show answer

Correct answer: B. Language detection returns the language of the text.

7. Which AI workload converts spoken audio into written text?

  1. Speech synthesis (text-to-speech)
  2. Image classification
  3. Speech recognition (speech-to-text)
  4. Entity detection on the audio stream
Show answer

Correct answer: C. Speech recognition transcribes audio.

8. Detecting an unusual spike in server CPU usage is an example of which AI workload?

  1. Translation
  2. Speech synthesis
  3. Anomaly detection
  4. Image generation
Show answer

Correct answer: C. Anomaly detection finds unusual patterns.
