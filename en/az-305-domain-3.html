Domain 3 sample questions

8 questions from our 74-question bank for this domain. Try to answer before revealing the solution.

1. Compliance requires yearly SQL database backups to be retained for 10 years. Which feature supports this?

  1. Read scale-out
  2. Serverless auto-pause
  3. Long-term retention (LTR) policies
  4. Dynamic data masking
Show answer

Correct answer: C. LTR keeps full backups for up to 10 years.

2. A recovery plan in Azure Site Recovery allows you to do what?

  1. Create budgets for the recovered VMs
  2. Delete the primary VMs automatically after a successful failover
  3. Change DNS names permanently for every protected application
  4. Group VMs, order their failover and add scripts or manual steps
Show answer

Correct answer: D. Recovery plans orchestrate multi-tier failover.

3. Which service provides application-consistent snapshots of Azure VMs during backups?

  1. Azure Backup with VSS (Windows) or pre/post scripts (Linux)
  2. Managed disk snapshots taken on a schedule without using VSS
  3. Azure Files share snapshots
  4. Azure Site Recovery crash-consistent recovery points only
Show answer

Correct answer: A. Application-consistent backups protect transactional data.

4. A critical VM needs several backups per day with an RPO of 4 hours. Which Azure Backup option fits?

  1. Enhanced backup policy with hourly frequency
  2. Archive tier for all recovery points older than one hour
  3. Soft delete
  4. Standard policy with one daily backup
Show answer

Correct answer: A. Enhanced policies support multiple backups per day (every 4, 6, 8 or 12 hours).

5. Which load balancer SKU feature distributes traffic across VMs in multiple availability zones with zone redundancy?

  1. Basic Load Balancer
  2. Standard Load Balancer with zone-redundant frontend
  3. A single public IP assigned to a VM
  4. A DNS round-robin record only
Show answer

Correct answer: B. Standard SKU supports zones and a 99.99% SLA.

6. Which recovery tier gives the lowest RTO for a critical VM workload across regions?

  1. Restoring from daily Azure Backup
  2. Copying VHDs manually with AzCopy
  3. Azure Site Recovery replication with a recovery plan
  4. Recreating VMs from templates
Show answer

Correct answer: C. Site Recovery keeps replicas ready, giving minute-level RTO compared with restore from backup.

7. An architect must validate that the solution survives a zone outage by injecting faults in a controlled way. Which service should be used?

  1. Azure Advisor reliability recommendations for the subscription
  2. Azure Chaos Studio
  3. Service Health
  4. Azure Load Testing
Show answer

Correct answer: B. Chaos Studio runs experiments such as VM shutdown or zone-down to test resilience.

8. A SaaS platform must scale to many customers and limit the blast radius of failures by deploying identical independent units. Which pattern fits?

  1. Deployment stamps
  2. A single global database shared by every customer
  3. Sidecar
  4. Gateway aggregation
Show answer

Correct answer: A. Each stamp hosts a subset of tenants, so a failure affects only that stamp.
