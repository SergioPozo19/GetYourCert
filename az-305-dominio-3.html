Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 74 para este dominio. Intenta responder antes de ver la solución.

1. El cumplimiento exige conservar durante 10 años copias de seguridad anuales de la base de datos SQL. ¿Qué característica lo admite?

  1. Escalabilidad horizontal de lectura
  2. Pausa automática sin servidor
  3. Directivas de retención a largo plazo (LTR)
  4. Enmascaramiento dinámico de datos
Ver respuesta

Respuesta correcta: C. LTR conserva copias completas hasta 10 años.

2. ¿Qué permite hacer un plan de recuperación en Azure Site Recovery?

  1. Crear presupuestos para las VM recuperadas
  2. Eliminar automáticamente las VM principales tras una conmutación correcta
  3. Cambiar permanentemente los nombres DNS de cada aplicación protegida
  4. Agrupar VM, ordenar su conmutación y agregar scripts o pasos manuales
Ver respuesta

Respuesta correcta: D. Los planes de recuperación orquestan la conmutación por error de varios niveles.

3. ¿Qué servicio proporciona instantáneas coherentes con la aplicación de las VM de Azure durante las copias de seguridad?

  1. Azure Backup con VSS (Windows) o scripts previos y posteriores (Linux)
  2. Instantáneas de discos administrados programadas sin usar VSS
  3. Instantáneas de recursos compartidos de Azure Files
  4. Solo puntos de recuperación coherentes con bloqueos de Site Recovery
Ver respuesta

Respuesta correcta: A. Las copias coherentes con la aplicación protegen los datos transaccionales.

4. Una VM crítica necesita varias copias al día con un RPO de 4 horas. ¿Qué opción de Azure Backup encaja?

  1. Directiva de copia mejorada con frecuencia por horas
  2. Nivel de archivo para todos los puntos de recuperación de más de una hora
  3. Eliminación temporal
  4. Directiva estándar con una copia diaria
Ver respuesta

Respuesta correcta: A. Las directivas mejoradas admiten varias copias al día (cada 4, 6, 8 o 12 horas).

5. ¿Qué característica de la SKU de equilibrador de carga distribuye el tráfico entre VM de varias zonas de disponibilidad con redundancia de zona?

  1. Basic Load Balancer
  2. Standard Load Balancer con front-end con redundancia de zona
  3. Una sola IP pública asignada a una VM
  4. Solo un registro DNS round-robin
Ver respuesta

Respuesta correcta: B. La SKU Estándar admite zonas y un SLA del 99,99 %.

6. ¿Qué nivel de recuperación da el menor RTO para una carga crítica de VM entre regiones?

  1. Restaurar desde Azure Backup diario
  2. Copiar VHD manualmente con AzCopy
  3. Replicación de Azure Site Recovery con un plan de recuperación
  4. Recrear las VM desde plantillas
Ver respuesta

Respuesta correcta: C. Site Recovery mantiene réplicas listas, con RTO de minutos frente a restaurar desde copia.

7. Un arquitecto debe validar que la solución sobrevive a la caída de una zona inyectando errores de forma controlada. ¿Qué servicio debe usarse?

  1. Recomendaciones de fiabilidad de Azure Advisor para la suscripción
  2. Azure Chaos Studio
  3. Service Health
  4. Azure Load Testing
Ver respuesta

Respuesta correcta: B. Chaos Studio ejecuta experimentos como el apagado de VM o la caída de una zona para probar la resiliencia.

8. Una plataforma SaaS debe escalar a muchos clientes y limitar el impacto de los fallos implementando unidades idénticas e independientes. ¿Qué patrón encaja?

  1. Sellos de implementación
  2. Una única base de datos global compartida por todos los clientes
  3. Sidecar
  4. Agregación de puerta de enlace
Ver respuesta

Respuesta correcta: A. Cada sello aloja un subconjunto de inquilinos, así que un fallo solo afecta a ese sello.
