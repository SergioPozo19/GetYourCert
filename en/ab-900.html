AB-900 sample questions

Five real questions from our 559-question bank. Try to answer before revealing the solution.

1. Which tool would you use to review administrative actions performed across SharePoint, Exchange, and Teams from a central location?

  1. Mail flow rules
  2. Entra Sign-in diagnostics
  3. Microsoft Purview Audit
  4. Viva Insights Copilot Analytics
Show answer

Correct answer: C. Microsoft Purview Audit centralizes logging of user and admin activity across all M365 workloads. Sign-in diagnostics is for authentication, Copilot Analytics for adoption, and mail flow rules for routing.

2. An organization needs to centrally assign Microsoft 365 licenses to employees. Which admin center does it use?

  1. The Microsoft Teams admin center
  2. The Microsoft Purview compliance portal
  3. The Microsoft 365 admin center
  4. The Microsoft Defender security portal
Show answer

Correct answer: C. Licenses are centrally assigned in the Microsoft 365 admin center. Teams manages teams, Purview manages compliance, and Defender manages security.

3. Complete the sentence: Microsoft Purview Information Protection consists of, among others, [___].

  1. The mailboxes, the distribution lists, and the accepted domains of the current tenant
  2. The teams, the channels, and the chats that users create to collaborate in their daily work
  3. PIM, Conditional Access, and the Identity Secure Score that Microsoft Entra offers for identity
  4. Data classification, sensitivity labels, and the Information Protection scanner
Show answer

Correct answer: D. Information Protection includes data classification, sensitivity labels, and the scanner. The other options are Exchange/Teams objects or identity features.

4. Your org wants only the Marketing department to generate PAYG agent charges. How do you configure this?

  1. Apply a retention policy to the content the Marketing department generates
  2. Create a PAYG billing policy scoped to a specific security group (Marketing)
  3. Create a sensitivity label for Marketing and apply it to its content
  4. Assign E5 licenses only to the users in the tenant's Marketing department
Show answer

Correct answer: B. A PAYG policy scoped to a specific security group restricts consumption charges to that group. E5, labels, and retention do not control PAYG billing scope.

5. An admin needs to enable or disable access to Microsoft 365 Copilot Chat for certain users. What primarily controls this access?

  1. A retention label that controls how long the conversations are kept
  2. The license assignment and the Copilot settings in the Microsoft 365 admin center
  3. A DLP policy that detects and blocks sensitive content in the user's prompts
  4. The Microsoft Defender portal, via a threat protection policy
Show answer

Correct answer: B. Access to Copilot experiences is managed via license assignment and Copilot settings in the Microsoft 365 admin center. DLP, retention, and Defender do not control Copilot Chat access.
