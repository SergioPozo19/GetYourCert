AI-901 sample questions

Five real questions from our 302-question bank. Try to answer before revealing the solution.

1. In a chat model request, which message role sets the overall behavior and rules for the assistant?

  1. Assistant
  2. System
  3. Tool output
  4. User
Show answer

Correct answer: B. The system message guides the model's behavior.

2. Which capability finds and can redact sensitive items such as phone numbers and email addresses in text?

  1. Image captioning
  2. Object detection
  3. PII detection
  4. Speech synthesis
Show answer

Correct answer: C. PII detection helps protect personal data.

3. Which authentication approach is preferred over embedding an API key in application code?

  1. No authentication
  2. A shared key stored in a public repo
  3. Microsoft Entra ID (managed identity)
  4. Hard-coded passwords in the config file
Show answer

Correct answer: C. Keyless Entra ID authentication avoids leaking secrets.

4. What does a sentiment analysis response typically include for each document?

  1. A translated audio file
  2. A bounding box for each word and its position on the page
  3. Only the word count and the detected language of the document
  4. A sentiment label (positive, neutral or negative) with scores
Show answer

Correct answer: D. Sentiment results include labels and scores.

5. Which feature of audio analysis labels which speaker said each part of a conversation?

  1. Image tagging
  2. OCR
  3. Speaker diarization
  4. Entity redaction only
Show answer

Correct answer: C. Diarization attributes speech to speakers.
