Guía de estudio de AZ-305: qué entra y cómo prepararlo

AZ-305 es el examen de arquitecto de soluciones de Azure. No pregunta cómo configurar algo, sino qué servicio elegir para unos requisitos de coste, disponibilidad, seguridad y rendimiento. Se da por hecho que ya sabes lo de AZ-104.

Identidad, gobernanza y supervisión (25-30%)

  • Jerarquía de grupos de administración, suscripciones y Azure Policy
  • Autenticación y autorización: Entra ID, B2B, External ID e identidades administradas
  • Key Vault para secretos, claves y certificados
  • Registro y supervisión con Log Analytics, Azure Monitor y alertas

Almacenamiento de datos (20-25%)

  • Datos relacionales: Azure SQL Database, Managed Instance y SQL en VM
  • Datos no relacionales: Cosmos DB, Table Storage y Blob Storage
  • Integración de datos: Data Factory, Fabric y Databricks
  • Niveles, redundancia y escalado de cada servicio

Continuidad del negocio (15-20%)

  • RPO y RTO, y cómo se traducen en servicios
  • Azure Backup y Azure Site Recovery
  • Replicación geográfica, grupos de conmutación por error y Cosmos DB multirregión
  • Zonas de disponibilidad y pares de regiones

Infraestructura (30-35%)

  • Proceso: VM, conjuntos de escalado, App Service, Functions, AKS y Container Apps
  • Mensajería y eventos: Service Bus, Event Grid, Event Hubs y colas
  • Redes: hub-spoke, VPN, ExpressRoute, Front Door, Application Gateway y Load Balancer
  • Migración con Azure Migrate y Cloud Adoption Framework

Plan de estudio de 6 semanas

1Identidad, gobernanza y supervisión.
2Bases de datos: cuándo usar cada opción de Azure SQL y Cosmos DB.
3Continuidad del negocio: RPO, RTO, Backup, Site Recovery y replicación.
4Proceso y mensajería. Es parte del dominio con más peso.
5Redes y migración: hub-spoke, conectividad híbrida y equilibrio de carga global.
6Simulacros completos con casos prácticos hasta superar el 80%.

Confusiones típicas en el examen

Front Door, Application Gateway, Traffic Manager y Load Balancer

Front Door es global y HTTP(S); Application Gateway es regional y HTTP(S) con WAF; Traffic Manager es global por DNS para cualquier protocolo; Load Balancer es regional en la capa 4.

Service Bus, Event Grid y Event Hubs

Service Bus es mensajería empresarial con colas, temas y orden; Event Grid reparte eventos discretos a suscriptores; Event Hubs ingiere flujos de telemetría a gran escala.

SQL Database frente a Managed Instance

SQL Database es una base de datos PaaS individual o en grupo elástico; Managed Instance da casi toda la compatibilidad de SQL Server (Agente SQL, consultas entre bases de datos) para migrar sin cambios.

RPO frente a RTO

El RPO es cuántos datos puedes perder (distancia a la última copia); el RTO es cuánto tiempo puedes estar sin servicio hasta recuperarte.

Preguntas de ejemplo de AZ-305

Cinco preguntas reales de nuestro banco de 413. Intenta responder antes de ver la solución.

1. Una VM de Azure debe acceder a Azure SQL Database sin ninguna contraseña en su configuración. ¿Qué debes recomendar?

  1. Una identidad administrada con autenticación de Microsoft Entra en la base de datos
  2. Acceso anónimo restringido por reglas de firewall
  3. Una contraseña guardada en una variable de entorno
  4. Una contraseña en la configuración de la aplicación
Ver respuesta

Respuesta correcta: A. Una identidad administrada con autenticación de Microsoft Entra en la base de datos permite a la VM conectarse sin ninguna contraseña en la configuración. El acceso anónimo es inseguro, y guardar la contraseña en variables de entorno o en la configuración de la aplicación sigue exponiendo un secreto.

2. ¿Qué característica cifra columnas sensibles de modo que ni siquiera los administradores de la base de datos puedan ver los valores en texto sin formato?

  1. Solo enmascaramiento dinámico de datos
  2. Always Encrypted
  3. Solo cifrado de datos transparente
  4. Punto de conexión público
Ver respuesta

Respuesta correcta: B. Always Encrypted cifra columnas concretas en el cliente y las claves nunca llegan al motor, así que ni el administrador de la base de datos ve los valores. El enmascaramiento dinámico solo oculta en las consultas, TDE cifra el disco y un punto de conexión público no protege nada.

3. ¿Qué factor es más importante al elegir una clave de partición de Cosmos DB?

  1. La clave de partición debe ser un valor booleano
  2. Un valor constante para todos los elementos para simplificar las consultas
  3. Una cardinalidad alta que distribuya las solicitudes y el almacenamiento de forma uniforme
  4. El valor de cadena más corto posible
Ver respuesta

Respuesta correcta: C. Una buena clave de partición tiene muchos valores distintos (alta cardinalidad) para repartir solicitudes y almacenamiento de forma uniforme. Un valor booleano o constante crea particiones calientes, y la longitud del texto no importa.

4. Una organización necesita proteger bases de datos de SQL Server que se ejecutan en VM de Azure con copias de registros cada 15 minutos. ¿Qué opción encaja?

  1. Azure Backup para SQL Server en VM de Azure
  2. Instantáneas de VM de Azure
  3. Copias de seguridad nativas de SQL en un disco local
  4. Azure Site Recovery
Ver respuesta

Respuesta correcta: A. Azure Backup para SQL Server en VM de Azure entiende la carga de trabajo: hace copias de registro cada 15 minutos y permite restaurar a un momento dado. Las instantáneas de VM no tienen copias de registro, las copias a disco local se pierden con la VM y Site Recovery no es una copia de seguridad.

5. ¿Qué servicio ofrece equilibrio de carga regional de capa 7 con enrutamiento basado en URL, terminación TLS y un WAF opcional?

  1. Azure Load Balancer
  2. Azure Traffic Manager
  3. Azure Application Gateway
  4. Azure NAT Gateway
Ver respuesta

Respuesta correcta: C. Azure Application Gateway es un equilibrador regional de capa 7 con enrutamiento por URL, terminación TLS y WAF opcional. Load Balancer es de capa 4, Traffic Manager es DNS global y NAT Gateway da salida a internet.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica AZ-305?

El banco de preguntas tiene 413 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar AZ-305?

El examen oficial de Microsoft AZ-305 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen AZ-305?

Cuatro dominios: diseñar soluciones de identidad, gobernanza y supervisión (25-30%), de almacenamiento de datos (20-25%), de continuidad del negocio (15-20%) y de infraestructura (30-35%).

¿Es gratis el examen de práctica AZ-305?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para AZ-305, no extractos del examen real ni "exam dumps".

¿Cuánto cuesta el examen oficial AZ-305?

En Estados Unidos cuesta 165 USD. En otros países el precio cambia según la moneda y el país, y lo ves al reservar desde Microsoft Learn. Los estudiantes pueden tener descuento.

¿Cuánto dura el examen AZ-305 y cuántas preguntas tiene?

Tienes unos 100 minutos para responder, normalmente entre 40 y 60 preguntas, que pueden incluir casos prácticos con varias preguntas sobre el mismo escenario. Además de opción múltiple hay preguntas de sí o no, de arrastrar y de completar, como en nuestros simulacros.

¿Se puede consultar Microsoft Learn durante el examen AZ-305?

Sí. Durante el examen puedes abrir Microsoft Learn en una ventana, pero el tiempo sigue contando. Úsalo solo para dudas concretas, no para aprender algo desde cero.

¿Caduca la certificación AZ-305?

Sí, dura un año. Se renueva gratis con una evaluación en línea en Microsoft Learn durante los seis meses anteriores a la caducidad, sin volver a pagar el examen.

¿Necesito aprobar AZ-104 para ser Azure Solutions Architect Expert?

Sí. La certificación Expert se obtiene al aprobar AZ-305 y tener también AZ-104 (Azure Administrator Associate). Puedes hacer los exámenes en cualquier orden, pero AZ-305 da por sabido casi todo lo de AZ-104.
