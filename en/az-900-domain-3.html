1. A finance team needs to automatically generate a file each month with detailed Azure cost data to load into their accounting system, without manually logging into the portal. Which Microsoft Cost Management feature should they configure?

  1. Azure Advisor with cost recommendations based on analysis of historical CPU and memory usage of VMs
  2. A Microsoft Cost Management budget with automatic email alerts when the threshold is exceeded
  3. A scheduled cost data export to a storage account
  4. The Azure pricing calculator for estimating the monthly cost of services before deploying them
Show answer

Correct answer: C. Microsoft Cost Management exports let you schedule the periodic (daily, weekly, or monthly) generation of files with detailed cost data and automatically save them to a storage account, from which other systems can consume them. A budget only triggers alerts when a threshold is exceeded, it doesn't export detailed data; Azure Advisor provides recommendations, and the pricing calculator estimates future costs, not historical ones.

2. A company with on-premises SQL Server workloads, with licenses covered by Software Assurance, plans to migrate those databases to Azure SQL Database. Which benefit lets it reduce Azure compute costs by reusing those licenses?

  1. Azure Hybrid Benefit
  2. A Spot VM
  3. Dev/Test pricing
  4. A storage savings plan
Show answer

Correct answer: A. Azure Hybrid Benefit allows customers with SQL Server or Windows Server licenses covered by Software Assurance (or equivalent subscriptions) to apply those licenses to Azure resources such as Azure SQL Database or virtual machines, significantly reducing compute costs. Spot VMs offer discounts on unused capacity unrelated to licensing, Dev/Test pricing is limited to development and test environments, and there is no such thing as a 'storage savings plan' in Azure.

3. A company wants to identify virtual machines that are underutilized and could be resized to reduce costs, based on historical CPU and memory usage. Which tool should it consult first?

  1. The Azure pricing calculator for comparing the theoretical cost of different VM sizes in each region
  2. Azure Advisor, in its cost recommendations section
  3. The Service Trust Portal for reviewing Microsoft audit reports and security certifications
  4. Azure Blueprints for deploying standardized environments with predefined policies and role assignments
Show answer

Correct answer: B. Azure Advisor analyzes the configuration and usage patterns of deployed resources and, in its cost category, suggests actions like resizing or shutting down underutilized VMs to save money. The pricing calculator is used to estimate costs before deployment, not to analyze existing resources; Azure Blueprints is used to define governance templates; and the Service Trust Portal provides compliance documentation, not cost optimization recommendations.

4. A European company needs to ensure that its handling of customers' personal data complies with the GDPR. What type of requirement does this primarily describe?

  1. A requirement related only to virtual machine sizing
  2. A requirement exclusively related to network performance
  3. A compliance requirement related to data protection
  4. A requirement that only affects local backups
Show answer

Correct answer: C. The GDPR is a data protection regulation that imposes compliance requirements on how personal data is collected, stored, and processed, which organizations must consider when using cloud services.

5. A resource group contains a critical production database. An administrator applies a 'ReadOnly' lock to that resource group. What effect does this have on operations that other users with Contributor permissions can perform?

  1. The ReadOnly lock does not affect users with the Contributor role; it only restricts users with the Reader role
  2. Users with the Contributor role can still modify resource configurations, but cannot delete them
  3. Users with the Contributor role can delete resources individually, but cannot modify their configuration
  4. They won't be able to modify or delete any resource in the group, even though RBAC grants them Contributor permissions
Show answer

Correct answer: D. A 'ReadOnly' lock operates independently of RBAC: it prevents any modify or delete operation on the resources within the locked scope, regardless of what RBAC permissions the user has, even administrators. This contrasts with 'CanNotDelete', which only prevents deletion but allows modification. The lock applies to all users, not just those with the Reader role.

6. What does Azure Monitor autoscale allow you to configure for a virtual machine scale set?

  1. The default language of the virtual machines
  2. Rules that scale instances by metrics or schedule
  3. The encryption of the scale set's disks
  4. The tags applied to the entire subscription
Show answer

Correct answer: B. Azure Monitor autoscale allows defining rules that add or remove instances of a scale set based on metrics, such as CPU usage, or on a time-based schedule.

7. A developer writes a Bicep file to define a storage account, a virtual network, and a virtual machine. What happens to that file before Azure Resource Manager processes it?

  1. It is transpiled (compiled) into a JSON-based ARM template, which is what Resource Manager ultimately processes
  2. It is automatically converted into an Azure Automation runbook executable in a PowerShell 7 environment
  3. It is executed directly as a PowerShell script with no prior transformation by Azure
  4. Azure Resource Manager natively interprets Bicep code without conversion thanks to the bicep-runtime module
Show answer

Correct answer: A. Bicep is a declarative language with simplified syntax that gets transpiled into a JSON-based ARM template; it's that resulting JSON template that Azure Resource Manager actually processes to deploy the resources. It is not executed as a PowerShell script, it's not converted into a runbook, and although the process is transparent to the user, Resource Manager still internally works with JSON, not Bicep directly.

8. An engineer configures diagnostic settings on a storage account to send activity logs to a Log Analytics workspace. What is primarily achieved with this configuration?

  1. Access to the storage account is restricted to allow connections only from internal IP ranges
  2. A daily backup copy of all data stored in the Blob Storage account is automatically created
  3. Additional encryption with customer-managed keys in Azure Key Vault is applied to all data at rest
  4. The resource's platform logs are routed to a destination where they can be queried, analyzed, and used for alerts or dashboards
Show answer

Correct answer: D. Diagnostic settings let you route a resource's platform logs (for example, activity logs or metrics) to destinations such as a Log Analytics workspace, a storage account, or Event Hubs, where the data can be queried with KQL, visualized in workbooks, or used as the basis for alerts. They don't create backup copies of the resource's data, they don't apply additional encryption, and they aren't a network restriction mechanism.
