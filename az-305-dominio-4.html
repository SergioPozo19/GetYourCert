Diseñar soluciones de infraestructura

El dominio 4 de AZ-305 supone entre el 30 y el 35% del examen, el de más peso del temario. En EarnYourCert tienes 136 preguntas originales de este dominio, todas con explicación: 93 de opción múltiple, 18 de sí o no y 25 de completar u ordenar, como en el examen real.

Qué entra en este dominio

  • Proceso: VM, conjuntos de escalado, App Service, Functions, AKS y Container Apps
  • Mensajería y eventos: Service Bus, Event Grid, Event Hubs y colas
  • Redes: hub-spoke, VPN, ExpressRoute, Front Door, Application Gateway y Load Balancer
  • Migración con Azure Migrate y Cloud Adoption Framework

Preguntas de ejemplo del dominio 4

8 preguntas de nuestro banco de 136 para este dominio. Intenta responder antes de ver la solución.

1. Un equipo necesita control total de Kubernetes, operadores personalizados e integración con una malla de servicios. ¿Qué servicio debe elegir?

  1. Azure App Service
  2. Azure Kubernetes Service (AKS)
  3. Azure Container Instances
  4. Azure Functions
Ver respuesta

Respuesta correcta: B. Azure Kubernetes Service da Kubernetes administrado con acceso completo a la API, así que admite operadores personalizados y una malla de servicios. App Service, Container Instances y Functions no exponen Kubernetes.

2. Debe transferir 80 TB a Azure por un enlace lento. ¿Qué opción es más adecuada?

  1. AzCopy por internet
  2. Una VPN con más ancho de banda
  3. Azure Data Box
  4. Solo Azure File Sync
Ver respuesta

Respuesta correcta: C. Con 80 TB y un enlace lento, lo adecuado es Azure Data Box, un dispositivo físico para transferir datos sin conexión. AzCopy por internet o una VPN tardarían demasiado, y File Sync sincroniza servidores, no hace cargas masivas iniciales.

3. ¿Qué patrón protege a un servicio posterior de la sobrecarga almacenando solicitudes en búfer entre productores y consumidores?

  1. Acoplamiento síncrono
  2. Base de datos compartida
  3. Nivelación de carga basada en colas
  4. Copia directa de archivos
Ver respuesta

Respuesta correcta: C. La nivelación de carga basada en colas pone una cola entre productores y consumidores para absorber picos y que el servicio de destino procese a su ritmo. El acoplamiento síncrono transmite los picos, una base de datos compartida acopla y copiar archivos no amortigua.

4. ¿Qué servicio detecta y evalúa servidores, bases de datos y aplicaciones web locales para determinar su preparación para la migración y estimar costes?

  1. Azure Advisor
  2. Azure Migrate
  3. Azure Site Recovery
  4. Azure Database Migration Service
Ver respuesta

Respuesta correcta: B. Azure Migrate descubre y evalúa servidores, bases de datos y aplicaciones web locales, indica si están listos para Azure y estima su coste. Advisor recomienda sobre lo que ya está en Azure, Site Recovery replica y Database Migration Service migra bases de datos pero no hace la evaluación general.

5. ¿Qué estrategia de migración rediseña una aplicación para usar servicios nativos de la nube como microservicios y sin servidor?

  1. Retirar y sustituir por SaaS
  2. Rediseñar o recompilar
  3. Conservar en local por ahora
  4. Volver a hospedar en VM de Azure (lift and shift)
Ver respuesta

Respuesta correcta: B. Rediseñar o reconstruir (rearchitect/rebuild) cambia la aplicación para usar servicios nativos de la nube como microservicios y serverless; da el máximo beneficio con más esfuerzo. Retirar o reemplazar por SaaS, mantener en local o rehospedar no reescriben la arquitectura.

6. ¿Qué servicio ofrece una conexión privada y dedicada entre el entorno local y Azure que no atraviesa internet público?

  1. Azure DNS
  2. Azure VPN Gateway por internet
  3. Azure ExpressRoute
  4. Azure Bastion
Ver respuesta

Respuesta correcta: C. Azure ExpressRoute es una conexión privada y dedicada entre tu red local y Azure a través de un proveedor, sin pasar por internet. La VPN Gateway cifra el tráfico pero va por internet, DNS resuelve nombres y Bastion da acceso a VM.

7. ¿Qué opción de red mejora el rendimiento de red de las VM al omitir el conmutador virtual del host?

  1. Conjunto de disponibilidad
  2. Redes aceleradas
  3. Grupos de ubicación por proximidad
  4. Discos Premium SSD v2
Ver respuesta

Respuesta correcta: B. Las redes aceleradas usan SR-IOV para que el tráfico de la VM evite el conmutador virtual del host, con más rendimiento, menos latencia y menos CPU. Un conjunto de disponibilidad da resiliencia, un grupo de selección de ubicación acerca las VM y los discos Premium SSD v2 mejoran el almacenamiento.

8. ¿Qué servicio ofrece acceso RDP/SSH seguro a las VM sin exponer IP públicas ni abrir puertos de administración?

  1. Azure Firewall
  2. Azure NAT Gateway
  3. Azure DDoS Protection
  4. Azure Bastion
Ver respuesta

Respuesta correcta: D. Azure Bastion da acceso RDP/SSH seguro a las VM desde el portal por TLS, sin IP públicas en las VM ni puertos de administración abiertos. Azure Firewall filtra tráfico, NAT Gateway da salida y DDoS Protection mitiga ataques.
