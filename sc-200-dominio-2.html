SC-200 · Dominio 2 de 3 · 35-40% del examen

Responder a incidentes de seguridad

El dominio 2 de SC-200 supone entre el 35 y el 40% del examen. En EarnYourCert tienes 140 preguntas originales de este dominio, todas con explicación: 92 de opción múltiple, 22 de sí o no y 26 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 140 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué acciones de corrección de Defender for Office 365 se pueden aplicar al correo ya entregado?

  1. Bloquear la IP del remitente en el firewall perimetral durante 30 días
  2. Deshabilitar el buzón del destinatario hasta que se analice el mensaje
  3. Mover a correo no deseado, eliminación temporal, definitiva o cuarentena
  4. Restablecer la contraseña del destinatario
Ver respuesta

Respuesta correcta: C. Las acciones de corrección ayudan a eliminar amenazas de los buzones.

2. ¿Qué capacidad da a un analista una sesión de línea de comandos remota en un dispositivo para ejecutar comandos y recopilar archivos?

  1. Cloud Discovery
  2. Respuesta en vivo
  3. Vínculos seguros
  4. Simulación de ataques
Ver respuesta

Respuesta correcta: B. La respuesta en vivo admite comandos como getfile y run.

3. ¿Qué hace restringir la ejecución de aplicaciones en un dispositivo?

  1. Restablece la contraseña del usuario
  2. Elimina el perfil de usuario
  3. Permite ejecutar solo ejecutables firmados por Microsoft
  4. Bloquea todo el acceso a internet del dispositivo
Ver respuesta

Respuesta correcta: C. Limita las herramientas del atacante manteniendo las funciones del sistema.

4. Una investigación muestra un archivo sospechoso. ¿Qué página de entidad ayuda a ver la prevalencia, las alertas relacionadas y los dispositivos que observaron el archivo?

  1. La página de licencias
  2. La página de facturación
  3. La página de entidad de archivo
  4. La página de dominio
Ver respuesta

Respuesta correcta: C. Las páginas de entidad agregan evidencias sobre archivos, IP, URL y usuarios.

5. Un analista quiere impedir que un archivo malicioso se ejecute en todos los dispositivos tras identificar su hash. ¿Qué acción ayuda?

  1. Asignar una licencia de Defender a cada dispositivo
  2. Crear un usuario invitado
  3. Bloquear el hash del archivo con un indicador
  4. Cambiar el nombre del dispositivo y volver a incorporarlo a Defender
Ver respuesta

Respuesta correcta: C. Los indicadores propagan bloqueos en los dispositivos incorporados.

6. ¿Qué función de Defender for Endpoint investiga alertas y corrige amenazas automáticamente?

  1. Filtrado de contenido web por categoría para dispositivos
  2. La puntuación de exposición de la página del dispositivo
  3. Investigación y respuesta automatizadas (AIR)
  4. Grupos de dispositivos con RBAC asignado a analistas
Ver respuesta

Respuesta correcta: C. AIR examina artefactos y puede corregir automáticamente según el nivel de automatización del grupo de dispositivos.

7. ¿Qué acción recopila un paquete de investigación de un dispositivo?

  1. Restringir la ejecución de aplicaciones en el dispositivo
  2. Retirar el dispositivo del servicio
  3. Recopilar paquete de investigación en la página del dispositivo
  4. Ejecutar un examen antivirus completo del dispositivo
Ver respuesta

Respuesta correcta: C. El paquete contiene datos forenses como procesos, conexiones y ejecuciones automáticas para análisis.

8. Debes averiguar quién agregó a un usuario al rol de administrador global la semana pasada. ¿Qué registro debes revisar?

  1. Registros de inicio de sesión
  2. Registro de actividad de Azure de la suscripción del inquilino
  3. Seguimiento de mensajes
  4. Registros de auditoría de Microsoft Entra
Ver respuesta

Respuesta correcta: D. Los cambios del directorio como las asignaciones de roles se registran en los registros de auditoría de Entra (tabla AuditLogs).
