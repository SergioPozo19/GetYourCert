Domain 1 sample questions

8 questions from our 102-question bank for this domain. Try to answer before revealing the solution.

1. Which item permission lets a user read the underlying files and Delta tables of a lakehouse through OneLake, for example with Spark?

  1. Reshare
  2. Build
  3. ReadData
  4. ReadAll
Show answer

Correct answer: D. ReadAll grants access to OneLake data; ReadData only grants SQL access.

2. Which Microsoft service provides the sensitivity labels that you can apply to Fabric items?

  1. Microsoft Purview Information Protection
  2. Microsoft Intune
  3. Azure Monitor
  4. Microsoft Defender for Cloud Apps only
Show answer

Correct answer: A. Fabric uses Purview Information Protection labels.

3. A team owner wants to highlight a semantic model as ready for wider use without a formal review. Which endorsement fits?

  1. Master data
  2. Sensitivity label
  3. Promoted
  4. Certified
Show answer

Correct answer: C. Any user with write permission can promote an item.

4. How can you restrict rows in a KQL database in an Eventhouse for different users?

  1. Use a Spark session configuration
  2. Use a Power BI report-level filter
  3. Use a Dataflow Gen2 parameter
  4. Use a row level security policy on the table
Show answer

Correct answer: D. KQL databases support row level security policies.

5. A viewer in the workspace should not read a sensitive warehouse table even though Viewers can normally query the SQL endpoint. What can you use?

  1. A Promoted endorsement
  2. A deployment rule
  3. A new workspace theme
  4. A T-SQL DENY on the table
Show answer

Correct answer: D. T-SQL permissions can further restrict workspace Viewers.

6. Before changing a lakehouse, you want to see which semantic models, reports and dashboards depend on it. Which feature helps?

  1. Impact analysis in the lineage view
  2. Row-level security role testing view
  3. A dataflow refresh
  4. Capacity metrics app item history
Show answer

Correct answer: A. Impact analysis lists downstream items and affected users.

7. Which endpoint lets tools such as Tabular Editor or SSMS read and write the metadata of a semantic model in a Fabric capacity?

  1. The OneLake DFS endpoint
  2. The KQL query URI
  3. The XMLA endpoint
  4. The SQL analytics endpoint
Show answer

Correct answer: C. The XMLA endpoint supports read/write operations on models.

8. Which report format in a Power BI project saves each page and visual as separate JSON files that are easier to diff?

  1. PBIDS
  2. PBIT with parameters for each data source
  3. PBIX
  4. PBIR
Show answer

Correct answer: D. PBIR (enhanced report format) splits the report definition into many files, improving source control.
