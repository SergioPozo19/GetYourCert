SC-300 · Dominio 1 de 4 · 20-25% del examen

Implementar y administrar identidades de usuario

El dominio 1 de SC-300 supone entre el 20 y el 25% del examen. En EarnYourCert tienes 98 preguntas originales de este dominio, todas con explicación: 67 de opción múltiple, 13 de sí o no y 18 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 98 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué rol puede administrar los roles y las asignaciones de roles de todos los demás administradores, incluida la configuración de MFA de los administradores globales?

  1. Lectores de directorio con ámbito elevado
  2. Administrador de usuarios para todas las unidades
  3. Administrador de roles con privilegios
  4. Invitador de invitados
Ver respuesta

Respuesta correcta: C. Se necesitan roles con privilegios para administrar los métodos de autenticación y las asignaciones de roles de los administradores.

2. Tu organización ha adquirido otra empresa y quiere que los usuarios inicien sesión con contoso.com y fabrikam.com. ¿Qué debes hacer?

  1. Agregar y verificar ambos dominios personalizados; uno es el principal
  2. Usar solo el dominio onmicrosoft.com para todos los usuarios
  3. Usar solo cuentas de invitado
  4. Crear un segundo inquilino para cada dominio adquirido
Ver respuesta

Respuesta correcta: A. Un inquilino puede alojar varios dominios personalizados comprobados.

3. Una unidad administrativa debe incluir automáticamente a todos los usuarios cuyo Country sea 'Spain'. ¿Qué debes configurar?

  1. Una directiva de acceso condicional dirigida a la ubicación con nombre de España
  2. Administración restringida
  3. Una directiva de nomenclatura
  4. Reglas de pertenencia dinámica en la unidad administrativa
Ver respuesta

Respuesta correcta: D. Las unidades administrativas admiten reglas de pertenencia dinámica para usuarios o dispositivos (requiere P1).

4. Quieres que la pertenencia a un grupo se actualice automáticamente cuando el atributo Departamento de un usuario cambie a Ventas. ¿Qué tipo de grupo debes crear?

  1. Un grupo de seguridad con pertenencia asignada
  2. Solo un grupo de seguridad habilitado para correo
  3. Una lista de distribución
  4. Un grupo de seguridad con pertenencia dinámica de usuarios
Ver respuesta

Respuesta correcta: D. Las reglas de pertenencia dinámica evalúan atributos y agregan o quitan miembros automáticamente.

5. ¿Qué regla de pertenencia dinámica agregaría a un grupo todos los dispositivos que ejecutan Windows?

  1. (user.country -eq "Windows")
  2. (user.jobTitle -contains "PC")
  3. (group.type -eq "Windows")
  4. (device.deviceOSType -eq "Windows")
Ver respuesta

Respuesta correcta: D. Los grupos dinámicos de dispositivos evalúan atributos de dispositivo como deviceOSType.

6. Cientos de dispositivos no inician sesión desde hace más de un año. ¿Cuál es el enfoque de limpieza recomendado?

  1. Esperar a que Microsoft los quite automáticamente tras 90 días
  2. Usar la marca aproximada de último inicio de sesión para deshabilitar y luego eliminar los dispositivos obsoletos
  3. Restablecer la contraseña de cada usuario
  4. Eliminar todos los dispositivos de inmediato
Ver respuesta

Respuesta correcta: B. Deshabilitar primero permite recuperar si un dispositivo aún se usa; las claves de BitLocker se pierden al eliminar un dispositivo.

7. Un usuario invitado no tiene cuenta Microsoft ni cuenta profesional. ¿Qué característica le permite iniciar sesión con un código de un solo uso enviado a su correo?

  1. Código de acceso de un solo uso por correo
  2. Application Proxy
  3. Autenticación transferida
  4. Windows Hello
Ver respuesta

Respuesta correcta: A. El código por correo es una alternativa para invitados sin otro proveedor de identidades.

8. Un usuario de la nube se asocia con un usuario local con la misma dirección de correo durante la primera sincronización. ¿Cómo se llama este comportamiento?

  1. Implementación por fases
  2. Coincidencia flexible (soft match)
  3. Eliminación permanente
  4. Break glass
Ver respuesta

Respuesta correcta: B. La coincidencia flexible usa atributos como userPrincipalName o proxyAddresses; la rígida usa el identificador inmutable.
