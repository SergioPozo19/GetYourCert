1. Azure Update Manager is the newer solution for managing OS updates. What is a key feature that differentiates it from Update Management in Azure Automation?

  1. Requires an Azure Automation account and a linked Log Analytics workspace to manage Windows and Linux updates
  2. Supports both Azure VMs and Arc-enabled servers without needing an Automation account
  3. Only supports Windows Server 2019 and 2022 virtual machines; Linux distributions are not compatible with this service
  4. Requires the MMA (Microsoft Monitoring Agent) or OMS agent installed on each VM to collect update data
Show answer

Correct answer: B. Azure Update Manager is a native solution that does not depend on an Azure Automation account or a Log Analytics workspace. It supports Azure VMs and Azure Arc-enabled servers, making it more flexible and simpler to deploy than the older Update Management solution.

2. An administrator reviews Azure Advisor recommendations and wants to understand in which category suggestions to reduce the cost of underutilized resources will appear.

  1. Performance
  2. Reliability
  3. Cost
  4. Operational Excellence
Show answer

Correct answer: C. Azure Advisor organizes recommendations into five categories: Cost, Security, Reliability, Performance, and Operational Excellence. Suggestions to reduce spending on underutilized resources, such as resizing or shutting down VMs, appear under the 'Cost' category.

3. An administrator needs Azure Monitor alerts for a production environment to not generate notifications during a nightly maintenance window (11 PM to 6 AM on Saturdays). What is the most efficient way to achieve this?

  1. Manually disable and re-enable each alert rule before and after maintenance
  2. Create an alert processing rule with notification suppression for that time window
  3. Delete the action group during maintenance and recreate it afterward
  4. Configure an activity log alert to suppress other alerts
Show answer

Correct answer: B. Alert processing rules allow configuring notification suppression for recurring or one-time time windows without modifying alert rules. This is the recommended way to silence alerts during maintenance, as alert rules continue to evaluate but notifications are suppressed.

4. After a failover with Azure Site Recovery to a secondary region, once the issue in the primary region is resolved, which operation allows running the workloads in the original region again?

  1. Factory reset
  2. Failback
  3. Vault deletion
  4. Automatic geo-redundant replication
Show answer

Correct answer: B. Failback is the process of replicating the changes made in the secondary region back to the original primary region and switching the workloads back to that region once it becomes available again.

5. Which Azure Backup storage redundancy level keeps three copies of the data within a single region, protecting against hardware failures but not a complete regional outage?

  1. Locally redundant storage (LRS)
  2. Zone-redundant storage (ZRS) only in geo-replicated scenarios
  3. No redundancy
  4. Geo-redundant storage (GRS)
Show answer

Correct answer: A. Locally redundant storage (LRS) replicates backup data three times within a single datacenter in the region, protecting against hardware failures (disk, node, rack) but not against the loss of the entire region.

6. A company needs to back up an Azure Files share. How does the Azure Backup mechanism for Azure Files work?

  1. Copies files to a dedicated backup storage account in another region
  2. Uses share snapshots stored in the same storage account
  3. Requires the MARS agent installed on a Windows server to copy files
  4. Converts the SMB share to a managed disk and performs block-level backup
Show answer

Correct answer: B. Azure Backup for Azure Files uses share snapshots, which are incremental copies stored in the same storage account as the file share. The Recovery Services vault maintains recovery point metadata, but the actual data remains in the storage account.

7. In an ASR replication policy for Hyper-V VMs, which replication frequencies are available?

  1. Every 1 minute, 5 minutes, or 15 minutes
  2. Every 30 seconds, 5 minutes, or 15 minutes
  3. Every 1 hour, 4 hours, or 24 hours
  4. Every 5 minutes or 30 minutes
Show answer

Correct answer: B. For Hyper-V VMs replicated with ASR, the available replication frequencies are 30 seconds, 5 minutes, and 15 minutes. A lower replication frequency results in a lower potential RPO but higher bandwidth usage and performance impact.

8. The Mobility Service agent is a required component of Azure Site Recovery. For which machine types is it required?

  1. Only for Hyper-V VMs replicated to Azure from a Hyper-V host managed by System Center VMM
  2. For physical servers and VMware VMs replicating to Azure
  3. For Azure VMs replicating from a primary Azure region to a secondary Azure region as DR target
  4. For any VM using the MARS (Microsoft Azure Recovery Services) agent in backup with Azure Backup
Show answer

Correct answer: B. The Mobility Service agent must be installed on each physical server or VMware VM to be replicated to Azure via ASR. It captures data writes on the server and forwards them to the ASR process server. For Hyper-V VMs and Azure VMs between regions, the replication mechanism is different and does not require the Mobility Service agent.
