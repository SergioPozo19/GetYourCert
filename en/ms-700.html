MS-700 sample questions

Five real questions from our 500-question bank. Try to answer before revealing the solution.

1. You want to allow Teams access from unmanaged devices, but only through the browser and without downloading files. What do you use?

  1. A retention policy applied to all of the teams' stored files
  2. An information barrier set between managed and unmanaged devices
  3. A messaging policy that disables the sending of files in the chats
  4. Conditional Access with app-enforced restrictions for unmanaged devices
Show answer

Correct answer: D. Conditional Access with app-enforced session restrictions limits unmanaged devices to web-only with no downloads.

2. A deleted Microsoft 365 group needs to be recovered. Within what period can it normally be restored?

  1. Within 30 days of deletion
  2. Never, deletion is permanent
  3. Within 24 hours only
  4. Within 10 years with a hold
Show answer

Correct answer: A. Deleted groups are soft-deleted for 30 days.

3. In a cross-tenant shared channel, who can be the channel owner?

  1. Any external guest added to the shared channel
  2. Only a user from the host tenant that owns the channel
  3. The auto attendant linked to the resource account
  4. Any user with an active Teams Phone license
Show answer

Correct answer: B. A shared channel's owner must belong to the host tenant; externals participate as members.

4. A Teams call queue agent wants to toggle their availability in the queue without an administrator having to do it. Which feature allows the agent to manage their own queue availability?

  1. The agent's presence status setting that automatically syncs with queue availability
  2. The call queue agent dashboard in Teams Admin Center that each agent can view
  3. The agent's calling policy with self-managed queue option enabled by the administrator
  4. The agent toggle option in the Teams app or in the agent's call queue widget
Show answer

Correct answer: D. Call queue agents can toggle their participation in the queue directly from the Teams client. When activated, the agent receives queue calls; when deactivated, calls won't reach them until they re-activate.

5. A macOS Teams user reports the app is unresponsive after updating to a new OS version. Other macOS users with earlier OS versions don't have the problem. What is the first diagnostic step?

  1. Uninstall and reinstall the Teams client to resolve potential incompatibility issues with the new OS version
  2. Check whether the new macOS version is on the supported OS list for the current Teams client in Microsoft documentation
  3. Review the user's Teams client logs using Cmd+Opt+Shift+1 keyboard combination to identify the error
  4. Create a support ticket with Microsoft indicating the OS version and affected Teams client version
Show answer

Correct answer: B. When a Teams client fails after an OS update, the first step is to check compatibility. Microsoft publishes minimum requirements and supported OS versions for Teams. If the new macOS version isn't officially supported yet, there may be issues until Teams updates.
