MD-102 · Dominio 1 de 5 · 20-25% del examen

Preparar la infraestructura para dispositivos

El dominio 1 de MD-102 supone entre el 20 y el 25% del examen. En EarnYourCert tienes 194 preguntas originales de este dominio, todas con explicación: 129 de opción múltiple, 30 de sí o no y 35 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 194 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué atributo de dispositivo en Microsoft Entra ID indica el nivel de cumplimiento del dispositivo con las directivas de Intune?

  1. device.isManaged
  2. device.isCompliant
  3. device.complianceState
  4. device.intuneStatus
Ver respuesta

Respuesta correcta: B. device.isCompliant es el atributo booleano de Microsoft Entra ID que indica si el dispositivo cumple las directivas de cumplimiento de Intune. Es usado en reglas de acceso condicional con 'Requerir dispositivo conforme'.

2. Quieres que cuando un usuario inscriba un dispositivo iOS personal en Intune (modo BYOD), el dispositivo quede registrado pero no supervisado. ¿Cuál es el método de inscripción apropiado para este escenario BYOD de iOS?

  1. Inscripción ADE con Apple Business Manager configurada para gestionar dispositivos iOS personales como si fueran dispositivos corporativos supervisados
  2. Inscripción mediante el Portal de empresa de Intune (instalando la aplicación desde la App Store y siguiendo las instrucciones)
  3. Inscripción con Apple Configurator 2 mediante conexión por cable USB para dispositivos iOS personales no supervisados por la organización
  4. Inscripción de dispositivo dedicado para dispositivos iOS de uso personal con configuración automatizada sin intervención manual del usuario
Ver respuesta

Respuesta correcta: B. Para BYOD de iOS, el usuario descarga el Portal de empresa de Intune desde la App Store y sigue el proceso de inscripción. El dispositivo queda registrado con un perfil de gestión básico, no como dispositivo supervisado.

3. Se compran dispositivos Android de varios fabricantes a un revendedor autorizado y deben inscribirse como totalmente administrados en el primer arranque. ¿Qué opción encaja?

  1. Apple Configurator con un perfil de inscripción USB
  2. Inscripción sin intervención de Google vinculada a Intune
  3. Inscripción masiva con un paquete de aprovisionamiento de Windows
  4. Solo registro del dispositivo en Microsoft Entra ID
Ver respuesta

Respuesta correcta: B. La inscripción sin intervención de Google, configurada con los datos DPC de Intune, aprovisiona automáticamente en Intune en el primer arranque los dispositivos Android compatibles comprados a revendedores zero-touch.

4. Necesitas asignar el rol de administrador de Intune solo a los miembros del equipo de soporte técnico, sin concederles acceso a otras partes de Microsoft 365. ¿Qué función de Intune debes usar?

  1. Roles integrados de Microsoft Entra ID con asignación directa a los miembros del equipo de soporte
  2. Control de acceso basado en roles (RBAC) de Intune con roles personalizados o integrados
  3. Directivas de cumplimiento de Intune con configuración de acceso restringido para el equipo de soporte
  4. Grupos de Microsoft Entra ID con permisos delegados y acceso administrativo condicional
Ver respuesta

Respuesta correcta: B. El RBAC de Intune permite asignar roles específicos de Intune (como 'Operador del departamento de soporte técnico') a grupos de usuarios, limitando el acceso solo a las funciones de Intune necesarias.

5. Quieres crear una directiva de cumplimiento en Intune que requiera que los dispositivos Windows 11 tengan el cifrado de BitLocker habilitado. ¿Dónde creas esta directiva en el centro de administración de Intune?

  1. Seguridad de puntos de conexión > Cifrado de disco
  2. Dispositivos > Directivas de cumplimiento > Crear directiva
  3. Configuración de dispositivos > Perfiles > Crear perfil
  4. Aplicaciones > Directivas de configuración de las aplicaciones
Ver respuesta

Respuesta correcta: B. Las directivas de cumplimiento en Intune se crean en Dispositivos > Directivas de cumplimiento. Ahí puedes definir requisitos como BitLocker, versión mínima de SO, PIN, etc.

6. Necesitas crear un rol personalizado de Intune que permita a los técnicos de soporte ver dispositivos y reiniciarlos de forma remota, pero sin poder borrarlos ni cambiar directivas. ¿Dónde creas este rol en el centro de administración de Intune?

  1. Microsoft Entra ID > Roles y administradores
  2. Administración de inquilinos > Roles > Crear
  3. Seguridad de puntos de conexión > Roles de seguridad
  4. Dispositivos > Acceso condicional > Roles
Ver respuesta

Respuesta correcta: B. Los roles personalizados de Intune se crean en Administración de inquilinos > Roles > Crear. Puedes seleccionar permisos específicos para cada acción disponible en Intune.

7. ¿Cuál es el período de gracia predeterminado en Intune para que un dispositivo no conforme tome acciones de incumplimiento (como el bloqueo de acceso)?

  1. Inmediatamente (0 días): el bloqueo de acceso se aplica en cuanto se detecta el incumplimiento
  2. 1 día de período de gracia predeterminado antes de que las acciones de no cumplimiento entren en vigor en Intune
  3. No hay período de gracia predeterminado; se configura en las acciones de no cumplimiento de cada directiva
  4. 30 días de período de gracia predeterminado para todas las directivas de cumplimiento nuevas de Intune
Ver respuesta

Respuesta correcta: C. El período de gracia se configura manualmente en las acciones de incumplimiento de cada directiva de cumplimiento. No hay ningún valor predeterminado universal; el administrador lo define según las necesidades de la organización.

8. ¿Qué protocolo de autenticación sin contraseña admite Windows Hello para Empresas cuando se integra con Microsoft Entra ID?

  1. SAML 2.0 con tokens de portador firmados por el proveedor de identidad de Microsoft Entra ID
  2. FIDO2 y el protocolo de Microsoft WebAuthn mediante claves asimétricas vinculadas al hardware del dispositivo (TPM)
  3. OAuth 2.0 con tokens de actualización persistentes almacenados en el Administrador de cuentas web de Windows
  4. Kerberos V5 exclusivamente, con tickets emitidos por el controlador de dominio de Active Directory local
Ver respuesta

Respuesta correcta: B. Windows Hello para Empresas usa criptografía de clave pública (WebAuthn/FIDO2) con el par de claves almacenado en el TPM del dispositivo. La clave privada nunca sale del hardware, lo que previene el robo de credenciales.
