1. What does Azure Private Link allow you to do?

  1. Encrypt email in transit between Exchange Online and external mail servers
  2. Reach Azure PaaS services through a private endpoint in your VNet
  3. Create a public website for a PaaS app with a custom domain and TLS
  4. Replace Azure Firewall entirely
Show answer

Correct answer: B. A private endpoint assigns a private IP address from your VNet to the service.

2. What is a benefit of Azure Front Door with WAF for a global web application?

  1. Global load balancing with edge protection against web exploits
  2. It replaces Microsoft Entra ID for user sign-in to the web application
  3. It manages user licenses globally
  4. It stores the web app's secrets and certificates in a global vault
Show answer

Correct answer: A. Front Door is a global entry point; WAF filters malicious requests.

3. Which Defender for Cloud plan provides threat protection for virtual machines and servers, including endpoint detection and response integration?

  1. Defender for Servers
  2. Defender for Key Vault
  3. Defender for Storage
  4. Defender for DNS only
Show answer

Correct answer: A. Defender for Servers integrates Defender for Endpoint and vulnerability assessment.

4. In Microsoft Sentinel, what groups related alerts into a single actionable item that an analyst can investigate?

  1. An incident
  2. A workbook
  3. A watchlist
  4. A data connector
Show answer

Correct answer: A. Incidents aggregate alerts and entities so analysts can investigate and respond together.

5. Where can security teams use Microsoft Sentinel together with Defender XDR in a single unified security operations experience?

  1. The Microsoft 365 admin center
  2. The Microsoft Defender portal
  3. The Intune admin center
  4. The Service Trust Portal compliance reports page
Show answer

Correct answer: B. Sentinel is onboarded to the Defender portal so incidents, hunting and automation work across both.

6. Which Defender product is a cloud access security broker (CASB) that gives visibility and control over cloud apps and shadow IT?

  1. Microsoft Sentinel
  2. Microsoft Defender for Office 365
  3. Microsoft Defender for Cloud Apps
  4. Microsoft Defender for Endpoint
Show answer

Correct answer: C. Defender for Cloud Apps discovers apps in use, enforces policies and protects data in SaaS apps.

7. Which Defender for Office 365 capability lets security teams run realistic phishing campaigns to train users?

  1. Threat explorer only
  2. Attack simulation training
  3. Access reviews
  4. Retention labels
Show answer

Correct answer: B. Attack simulation training helps measure and improve user resilience to phishing.

8. An analyst wants context about an IP address seen in an alert, such as related threat actors and infrastructure. Which solution provides this?

  1. Microsoft Purview Activity explorer reports
  2. Azure DDoS Protection telemetry dashboards
  3. Microsoft Entra access reviews history
  4. Microsoft Defender Threat Intelligence
Show answer

Correct answer: D. Microsoft Defender Threat Intelligence gives analysts curated intelligence about indicators such as IPs and domains, including linked threat actors, infrastructure and articles.
