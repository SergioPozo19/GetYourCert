Domain 2 sample questions

8 questions from our 116-question bank for this domain. Try to answer before revealing the solution.

1. What does marking a table as a date table enable?

  1. Hiding the table from the report view
  2. Correct behavior of time intelligence functions
  3. Automatic row-level security
  4. Faster refresh of all tables
Show answer

Correct answer: B. A marked date table with continuous dates lets functions such as TOTALYTD and SAMEPERIODLASTYEAR work reliably.

2. Which function removes all filters from a table or column inside CALCULATE, for example to compute a percentage of total?

  1. KEEPFILTERS
  2. ALLSELECTED on the visual
  3. VALUES (or DISTINCT)
  4. ALL (or REMOVEFILTERS)
Show answer

Correct answer: D. ALL clears filters for the specified table or columns.

3. Which function returns the first N rows of a table ranked by an expression, such as the top 5 products by sales?

  1. TOPN
  2. SAMPLE only
  3. FIRSTNONBLANK
  4. EARLIER
Show answer

Correct answer: A. TOPN returns a table.

4. A measure must return 0 instead of blank when there are no sales. Which function is the most concise?

  1. DIVIDE([Sales], 1, 0) used as a wrapper around the measure
  2. COALESCE([Sales], 0)
  3. BLANK()
  4. IFERROR([Sales], 0)
Show answer

Correct answer: B. COALESCE returns the first non-blank argument.

5. A DateTime column has high cardinality because of time stamps and is only used by date. How can you improve compression?

  1. Duplicate the column in the fact table and hide the original one
  2. Split into Date and Time columns or keep only the date
  3. Convert the column to text
  4. Keep the milliseconds for precision and sort the column ascending
Show answer

Correct answer: B. Reducing granularity reduces cardinality.

6. Which tool helps you find slow visuals and see DAX query durations?

  1. Performance Analyzer
  2. Selection pane
  3. Themes
  4. Bookmarks pane
Show answer

Correct answer: A. Performance Analyzer records visual load times.

7. Which DAX approach is usually more efficient than iterating over a large table row by row?

  1. Nest several FILTER functions
  2. Use set-based aggregators and variables
  3. Use calculated columns for every metric
  4. Convert measures to text first
Show answer

Correct answer: B. Variables avoid recomputing expressions and aggregators leverage the storage engine.

8. A large Import table with incremental refresh must also show today's transactions in real time. What should you enable?

  1. Automatic page refresh on an Import-only model
  2. Get the latest data in real time with DirectQuery (hybrid table)
  3. Disable incremental refresh and refresh the full table every 30 minutes
  4. Auto date/time
Show answer

Correct answer: B. Hybrid tables keep historical partitions imported and add a DirectQuery partition for the latest data.
