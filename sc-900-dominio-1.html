SC-900 · Dominio 1 de 4 · 10-15% del examen

Describir los conceptos de seguridad, cumplimiento e identidad

El dominio 1 de SC-900 supone entre el 10 y el 15% del examen. En EarnYourCert tienes 52 preguntas originales de este dominio, todas con explicación: 36 de opción múltiple, 7 de sí o no y 9 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 52 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué enfoque de seguridad usa varias capas de protección para que, si una falla, las demás sigan protegiendo los datos?

  1. Herencia de roles
  2. Defensa en profundidad
  3. Soberanía de los datos
  4. Inicio de sesión único
Ver respuesta

Respuesta correcta: B. La defensa en profundidad superpone protecciones físicas, de identidad, de perímetro, de red, de proceso, de aplicación y de datos.

2. Un actor malicioso cambia el importe de un registro financiero. ¿Qué propiedad de la tríada CIA se vulnera?

  1. Integridad
  2. Confidencialidad
  3. Disponibilidad
  4. Autenticación
Ver respuesta

Respuesta correcta: A. La integridad significa que los datos son exactos y no se han modificado sin autorización.

3. Un ataque DDoS deja un sitio web sin servicio para los clientes. ¿Qué propiedad de la tríada CIA resulta afectada principalmente?

  1. Confidencialidad
  2. No repudio
  3. Disponibilidad
  4. Integridad
Ver respuesta

Respuesta correcta: C. La disponibilidad garantiza que los usuarios autorizados puedan acceder a sistemas y datos cuando lo necesitan.

4. En el cifrado asimétrico, ¿qué clave se usa para descifrar datos cifrados con la clave pública del destinatario?

  1. La misma clave pública
  2. Un hash del mensaje
  3. La clave privada del destinatario
  4. La clave privada del remitente
Ver respuesta

Respuesta correcta: C. Solo el titular de la clave privada puede descifrar lo cifrado con la clave pública correspondiente.

5. ¿Qué capa de la defensa en profundidad incluye controles como credenciales, cámaras y salas de servidores cerradas?

  1. Seguridad física
  2. Identidad y acceso
  3. Aplicación
  4. Datos
Ver respuesta

Respuesta correcta: A. La capa física es la primera línea de defensa de las instalaciones y el hardware.

6. ¿Qué estándar abierto es un marco de autorización que permite a una aplicación acceder a recursos en nombre de un usuario sin compartir su contraseña?

  1. SMTP
  2. RADIUS
  3. OAuth 2.0
  4. DHCP
Ver respuesta

Respuesta correcta: C. OAuth 2.0 proporciona autorización delegada mediante tokens de acceso.

7. ¿Qué estándar basado en XML se usa ampliamente para intercambiar datos de autenticación y autorización entre un proveedor de identidades y un proveedor de servicios?

  1. ICMP
  2. HTML
  3. SAML
  4. SSH
Ver respuesta

Respuesta correcta: C. Las aserciones SAML permiten el inicio de sesión único federado.

8. En un flujo de autenticación moderna, ¿qué representa un token de seguridad?

  1. Un registro DNS que asigna un nombre a una IP
  2. Una clave VPN usada para cifrar el túnel
  3. Una credencial física para acceder a un edificio
  4. Una prueba de autenticación o autorización que contiene notificaciones (claims) sobre el usuario o la aplicación
Ver respuesta

Respuesta correcta: D. Los tokens contienen notificaciones como la identidad del usuario y los permisos, y los firma el proveedor de identidades.
