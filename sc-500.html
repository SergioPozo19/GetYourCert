Preguntas de ejemplo de SC-500

Cinco preguntas reales de nuestro banco de 329. Intenta responder antes de ver la solución.

1. ¿Cuál es el beneficio de un pase de acceso temporal para incorporar a un nuevo administrador con métodos sin contraseña?

  1. Sustituye permanentemente la MFA de la cuenta, así que no se necesita otro método
  2. El usuario puede registrar claves de acceso o Authenticator sin una credencial
  3. Quita los métodos de autenticación existentes del usuario antes de la incorporación
  4. Concede el rol de administrador de autenticación
Ver respuesta

Respuesta correcta: B. TAP tiene vigencia limitada y está pensado para el arranque y la recuperación.

2. ¿Qué efecto de Azure Policy bloquea la creación de un recurso no conforme?

  1. Disabled
  2. Modify
  3. Audit
  4. Deny
Ver respuesta

Respuesta correcta: D. Deny impide la solicitud; Audit solo registra el incumplimiento.

3. ¿Qué capacidad de Defender for Storage analiza los blobs cargados en busca de malware?

  1. Administración del ciclo de vida
  2. Hospedaje de sitios web estáticos
  3. Análisis de malware
  4. Replicación de objetos
Ver respuesta

Respuesta correcta: C. Defender for Storage añade análisis de malware y detección de amenazas.

4. ¿Qué configuración de AKS limita la exposición del servidor de API manteniéndolo fuera de internet público?

  1. Deshabilitar RBAC
  2. kubeconfig compartido
  3. Un clúster público con API abierta
  4. Un clúster privado
Ver respuesta

Respuesta correcta: D. Los clústeres privados exponen el servidor de API mediante un punto de conexión privado.

5. ¿Qué rol debe tener un responsable de equipo para crear y editar reglas de análisis y libros en Sentinel?

  1. Lector de Microsoft Sentinel
  2. Colaborador de Microsoft Sentinel
  3. Lector de facturación
  4. Invitado
Ver respuesta

Respuesta correcta: B. El Colaborador administra el contenido de Sentinel.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica SC-500?

El banco de preguntas tiene 329 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar SC-500?

El examen oficial de Microsoft SC-500 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen SC-500?

Cuatro dominios: administrar identidad, acceso y gobernanza (20-25%), proteger almacenamiento, bases de datos y redes (25-30%), proteger el proceso (20-25%) y administrar y supervisar la posición de seguridad (20-25%).

¿Es gratis el examen de práctica SC-500?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para SC-500, no extractos del examen real ni "exam dumps".
