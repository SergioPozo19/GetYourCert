Preparar los datos

El dominio 1 de PL-300 supone entre el 25 y el 30% del examen, el de más peso del temario. En EarnYourCert tienes 104 preguntas originales de este dominio, todas con explicación: 69 de opción múltiple, 14 de sí o no y 21 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 104 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué conector usarías para importar datos de una carpeta de archivos CSV mensuales y combinarlos automáticamente?

  1. Consulta en blanco con una lista manual de archivos
  2. Conector web que apunta a cada ruta de archivo
  3. Conector de carpeta con Combinar archivos
  4. Fuente OData expuesta por el servidor de archivos
Ver respuesta

Respuesta correcta: C. Combinar archivos anexa archivos con el mismo esquema.

2. ¿Qué configuración de modo de almacenamiento hace que una tabla de dimensión se cargue en memoria mientras la tabla de hechos grande permanece en DirectQuery para mejorar el rendimiento de las segmentaciones?

  1. Importar solo en la tabla de hechos
  2. Columnas ocultas
  3. Streaming
  4. Modo de almacenamiento dual en la dimensión
Ver respuesta

Respuesta correcta: D. Las tablas duales actúan como Importar o DirectQuery según se necesite.

3. ¿Qué conector importa datos de una carpeta de SharePoint que contiene muchos libros de Excel con el mismo diseño?

  1. Carpeta de SharePoint
  2. Página web
  3. Solo consulta en blanco
  4. Fuente OData
Ver respuesta

Respuesta correcta: A. El conector de carpeta de SharePoint enumera y combina archivos.

4. Quieres ampliar un modelo semántico publicado con tu propia tabla de Excel sin copiar los datos originales. ¿Qué debes usar?

  1. Un flujo de datos
  2. DirectQuery para modelos semánticos de Power BI (modelo compuesto)
  3. Importar el modelo semántico a un nuevo PBIX con todas las tablas
  4. Solo una conexión dinámica
Ver respuesta

Respuesta correcta: B. Convertir una conexión dinámica en DirectQuery permite agregar tablas locales mientras se consulta el modelo remoto.

5. ¿Qué función permite reutilizar una transformación en varias consultas como función?

  1. Crear función desde una consulta con parámetros
  2. Duplicar la consulta muchas veces
  3. Hacer referencia a la consulta sin cambios
  4. Deshabilitar la carga de la consulta
Ver respuesta

Respuesta correcta: A. Las funciones personalizadas encapsulan pasos para invocarlos por fila o reutilizarlos.

6. ¿Qué tipo de combinación devuelve solo las filas de la primera tabla que no tienen coincidencia en la segunda?

  1. Externa completa
  2. Externa derecha
  3. Anti izquierda
  4. Interna
Ver respuesta

Respuesta correcta: C. Anti izquierda encuentra las filas sin coincidencia.

7. Necesitas una copia de una consulta que siga los cambios realizados en los pasos anteriores de la consulta original. ¿Qué opción debes usar?

  1. Duplicar
  2. Referencia
  3. Cambiar nombre
  4. Deshabilitar carga
Ver respuesta

Respuesta correcta: B. Una consulta de referencia se basa en la original; un duplicado copia los pasos de forma independiente.

8. ¿Qué diseño de clave es mejor para una relación entre una tabla de hechos Ventas y una tabla de dimensión Producto?

  1. Sin clave, relacionando las tablas por el texto del nombre de producto
  2. Una columna de fecha de la tabla de hechos
  3. Una clave de texto concatenada con espacios entre las partes
  4. Una clave única de una columna, como ProductKey
Ver respuesta

Respuesta correcta: D. Las relaciones necesitan una clave única en el lado uno.
