Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 222 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué opción muestra la salida del modelo de forma progresiva mientras se genera, mejorando la sensación de respuesta?

  1. Respuestas en streaming
  2. Región aprovisionada
  3. Mayor temperatura
  4. Un prompt del sistema más largo
Ver respuesta

Respuesta correcta: A. El streaming devuelve tokens a medida que se producen.

2. Una aplicación cliente quiere usar un agente ya creado en un proyecto de Foundry. ¿Qué necesita normalmente?

  1. Una nueva implementación de modelo creada para cada solicitud
  2. La contraseña de administrador del portal de Foundry y el ID de suscripción
  3. Solo el color del agente
  4. El punto de conexión del proyecto, credenciales y el ID del agente
Ver respuesta

Respuesta correcta: D. Los clientes hacen referencia al agente del proyecto.

3. ¿Qué técnica permite que un modelo multimodal responda directamente a una pregunta hablada del usuario?

  1. Enviar el audio como entrada a un modelo que admita audio
  2. Enviar solo una captura de pantalla de la pregunta
  3. Usar una hoja de cálculo para guardar el audio
  4. Usar solo texto a voz en el cliente
Ver respuesta

Respuesta correcta: A. Los modelos con soporte de audio aceptan prompts hablados.

4. ¿Qué capacidad de Azure Speech permite que una aplicación pronuncie la salida traducida a otro idioma durante una conversación?

  1. Extracción de frases clave con resumen
  2. Detección de idioma seguida de análisis de texto
  3. Reconocimiento de voz sin traducción
  4. Traducción de voz con texto a voz
Ver respuesta

Respuesta correcta: D. La traducción de voz puede producir texto y voz traducidos.

5. Una aplicación debe admitir usuarios que hablan varios idiomas. ¿Con qué se debe configurar el reconocedor de voz?

  1. Una plantilla PDF para las transcripciones generadas
  2. El idioma o idiomas de reconocimiento esperados
  3. Una temperatura más alta para adaptarse a cada usuario
  4. Una voz neuronal personalizada para cada usuario
Ver respuesta

Respuesta correcta: B. La configuración del idioma de reconocimiento mejora la precisión.

6. Una imagen generada se publicará en un sitio web. ¿Qué práctica respalda la transparencia?

  1. Ocultar el origen de la imagen
  2. Quitar todas las descripciones
  3. Informar de que la imagen fue generada por IA
  4. Evitar cualquier revisión
Ver respuesta

Respuesta correcta: C. La divulgación forma parte de la transparencia.

7. ¿Qué política se aplica al uso de IA para identificar personas a partir de imágenes faciales?

  1. No tiene restricciones para ningún cliente de Azure
  2. Nunca necesita consentimiento si las imágenes están en Azure
  3. El acceso está restringido y requiere aprobación
  4. Siempre es gratuito
Ver respuesta

Respuesta correcta: C. La identificación facial es un escenario sensible de acceso limitado.

8. En un resultado de extracción, ¿en qué formato se devuelven normalmente los valores de los campos extraídos?

  1. Una imagen de mapa de bits
  2. Solo una hoja de cálculo comprimida
  3. Un archivo WAV
  4. JSON estructurado
Ver respuesta

Respuesta correcta: D. Los resultados contienen los campos como JSON estructurado.
