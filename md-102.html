Preguntas de ejemplo de MD-102

Cinco preguntas reales de nuestro banco de 727. Intenta responder antes de ver la solución.

1. Quieres crear un grupo de dispositivos en Microsoft Entra ID que incluya automáticamente todos los dispositivos de propiedad corporativa. ¿Qué atributo de regla de membresía dinámica debes usar?

  1. device.operatingSystem -eq 'Windows'
  2. device.deviceOwnership -eq 'Company'
  3. device.isCompliant -eq true
  4. device.managementType -eq 'MDM'
Ver respuesta

Respuesta correcta: B. El atributo device.deviceOwnership con valor 'Company' identifica dispositivos de propiedad corporativa, en contraste con 'Personal' para dispositivos BYOD.

2. Un administrador quiere configurar el acceso VPN siempre activo (Always On VPN) en dispositivos Windows gestionados por Intune para que los usuarios estén siempre conectados a la VPN corporativa sin tener que conectarse manualmente. ¿Qué tipo de perfil de Intune debe crear?

  1. Perfil de restricciones de dispositivos > Sección de red con opciones de VPN siempre activa
  2. Perfil de configuración de dispositivos Windows de tipo VPN con la opción Always On habilitada
  3. Perfil de Endpoint Protection > Sección de VPN con configuración de túnel dividido
  4. Directiva de acceso condicional con requisito de VPN corporativa para acceso a recursos
Ver respuesta

Respuesta correcta: B. Los perfiles de VPN para Windows en Intune permiten configurar Always On VPN, que mantiene la conexión VPN activa en todo momento. Soporta diferentes clientes VPN (Microsoft VPN, IKEv2, etc.).

3. ¿Qué canal de actualización de Microsoft 365 Apps proporciona las actualizaciones más rápidas con las últimas características, pero con menos pruebas previas al lanzamiento?

  1. Canal actual (Current Channel)
  2. Canal mensual empresarial (Monthly Enterprise Channel)
  3. Canal semestral empresarial (Semi-Annual Enterprise Channel)
  4. Canal beta
Ver respuesta

Respuesta correcta: A. El Canal actual (Current Channel) recibe nuevas características en cuanto están listas, normalmente varias veces al mes. Es el más rápido pero con menos pruebas empresariales previas al lanzamiento.

4. Habilita App Control for Business, pero quiere que las apps implementadas con Intune sigan funcionando sin agregarlas una a una a la directiva. ¿Qué configura?

  1. Una regla de reducción de la superficie de ataque que bloquea macros
  2. Una regla del Firewall de Windows Defender para cada app instalada
  3. La Extensión de administración de Intune como instalador administrado
  4. Una línea de base de seguridad que deshabilite SmartScreen para ellas
Ver respuesta

Respuesta correcta: C. En Seguridad de puntos de conexión > App Control for Business se puede definir la Extensión de administración de Intune como instalador administrado, de modo que las apps que implementa se consideran de confianza automáticamente.

5. ¿Qué versión del endpoint de Microsoft Graph debe usar normalmente la automatización de producción para Intune?

  1. v1.0, porque las API beta pueden cambiar sin previo aviso
  2. beta, porque siempre es más estable
  3. Cualquiera; Microsoft garantiza ambas por igual
  4. El endpoint heredado de Azure AD Graph
Ver respuesta

Respuesta correcta: A. El endpoint v1.0 es el soportado para producción; beta puede cambiar con modificaciones incompatibles. Azure AD Graph está retirado.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica MD-102?

El banco de preguntas tiene 727 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar MD-102?

El examen oficial de Microsoft MD-102 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen MD-102?

Cinco dominios: preparar la infraestructura para dispositivos (20-25%), administrar y mantener dispositivos (25-30%), proteger dispositivos (15-20%), administrar y proteger aplicaciones (15-20%), y optimizar las operaciones de endpoints con automatización, supervisión e informes (10-15%).

¿Es gratis el examen de práctica MD-102?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para MD-102, no extractos del examen real ni "exam dumps".
