Preguntas de ejemplo de AZ-104

Cinco preguntas reales de nuestro banco de 551. Intenta responder antes de ver la solución.

1. ¿Cuál es el límite máximo de niveles de jerarquía (sin contar el grupo de administración raíz) que admite la jerarquía de grupos de administración de Azure?

  1. 6 niveles
  2. No hay límite
  3. 10 niveles
  4. 2 niveles
Ver respuesta

Respuesta correcta: A. Azure permite hasta 6 niveles de profundidad en la jerarquía de grupos de administración, sin contar el nivel raíz ni el nivel de las suscripciones individuales.

2. ¿Qué es una 'instantánea' (snapshot) de un blob en Azure Storage?

  1. Una directiva de ciclo de vida que mueve el blob a una capa más económica tras un periodo sin acceso
  2. Una copia de solo lectura del estado del blob en un momento dado, creada explícitamente por el usuario
  3. Una copia de seguridad automática realizada cada hora sin intervención del usuario ni posibilidad de configuración
  4. Un tipo de cuenta de almacenamiento optimizado para el acceso frecuente a blobs pequeños
Ver respuesta

Respuesta correcta: B. Una instantánea de blob es una copia de solo lectura del blob tal como estaba en el momento en que se creó la instantánea; se crea explícitamente (por ejemplo, mediante AzCopy, PowerShell o el portal) y puede usarse para restaurar versiones anteriores.

3. ¿Qué método de autenticación se recomienda para que un Azure Container Instance extraiga (pull) imágenes de Azure Container Registry de forma más segura, evitando el uso de credenciales de administrador (admin user)?

  1. Identidad administrada (managed identity) con un rol RBAC como AcrPull asignado al registro
  2. Usar exclusivamente acceso público anónimo al registro, sin ningún tipo de autenticación
  3. Habilitar el usuario administrador (admin user) y compartir su contraseña con el equipo
  4. Compartir la clave de suscripción con los desarrolladores para que la usen en el pipeline
Ver respuesta

Respuesta correcta: A. Se recomienda usar una identidad administrada con el rol RBAC 'AcrPull' asignado sobre el registro, lo que permite a ACI autenticarse de forma segura sin manejar credenciales estáticas del usuario administrador.

4. ¿Qué ocurre con el tráfico entrante hacia una VM detrás de un Azure Load Balancer Standard si no hay ninguna regla NSG configurada en la interfaz de red o la subred?

  1. El tráfico se permite, ya que el Load Balancer Standard hereda las reglas permisivas del balanceador básico
  2. El tráfico se bloquea, ya que el Load Balancer Standard es seguro por defecto y requiere que los NSG permitan explícitamente el tráfico
  3. El tráfico solo se bloquea si el balanceador tiene habilitada la opción 'Secure by default'
  4. El Load Balancer Standard permite automáticamente el tráfico en los puertos configurados en las reglas de balanceo
Ver respuesta

Respuesta correcta: B. El Azure Load Balancer Standard es seguro por defecto (secure by default): todo el tráfico de Internet hacia el backend está bloqueado a menos que una regla NSG lo permita explícitamente. El Load Balancer Basic, en cambio, permite el tráfico por defecto. Esta diferencia es importante para el examen AZ-104.

5. Un administrador configura una alerta de métrica de Azure Monitor para una VM. La regla tiene dos condiciones: CPU > 90 % Y Memoria disponible < 1 GB. ¿Cuándo se activará la alerta?

  1. Cuando se cumpla cualquiera de las dos condiciones (lógica OR)
  2. Cuando se cumplan ambas condiciones simultáneamente (lógica AND)
  3. Cuando la CPU supere el 90 % durante más de 5 minutos, independientemente de la memoria
  4. No es posible combinar dos condiciones en la misma regla de alerta de métrica
Ver respuesta

Respuesta correcta: B. Cuando se configuran múltiples condiciones en una regla de alerta de métrica de Azure Monitor, se utiliza lógica AND: la alerta solo se activa cuando todas las condiciones se cumplen simultáneamente. Esto permite crear alertas más precisas que solo disparan cuando ocurre una combinación específica de condiciones.

¿Cuántas preguntas tiene el examen de práctica AZ-104?

El banco de preguntas tiene 551 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar AZ-104?

El examen oficial de Microsoft AZ-104 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen AZ-104?

Cinco dominios: administrar identidades y gobernanza de Azure (20-25%), implementar y administrar el almacenamiento (15-20%), implementar y administrar recursos de proceso de Azure (20-25%), implementar y administrar redes virtuales (15-20%), y supervisar y mantener los recursos de Azure (10-15%).

¿Es gratis el examen de práctica AZ-104?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para AZ-104, no extractos del examen real ni "exam dumps".
