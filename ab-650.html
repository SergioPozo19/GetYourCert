Preguntas de ejemplo de AB-650

Cinco preguntas reales de nuestro banco de 303. Intenta responder antes de ver la solución.

1. ¿Qué necesita antes de proteger sitios de SharePoint, cuentas de OneDrive y buzones de Exchange con Microsoft 365 Backup?

  1. Facturación de pago por uso configurada para Microsoft 365 Backup
  2. Una app de copia de seguridad de terceros aprobada en la tienda
  3. Una directiva de retención que conserve todo durante 10 años
  4. Un almacén de Azure Backup en la misma región que el inquilino
Ver respuesta

Respuesta correcta: A. Microsoft 365 Backup es un servicio de pago por uso: primero se conecta la facturación a una suscripción de Azure, luego se activa Backup y se crean directivas de copia.

2. La información de conectividad de red no muestra datos de sus sucursales. ¿Qué debe hacer primero?

  1. Abrir Estado del servicio y suscribirse a los avisos
  2. Habilitar la recopilación de ubicación y agregar las oficinas
  3. Crear una ubicación con nombre de acceso condicional por oficina
  4. Asignar una licencia de Teams Phone a cada usuario de sucursal
Ver respuesta

Respuesta correcta: B. La información requiere ubicaciones de oficina (manuales o detectadas) y permiso para recopilar datos de ubicación desde Windows o la prueba de conectividad.

3. Un elemento está sujeto a una directiva de retención de 3 años y a una etiqueta de 7 años, ambas de conservación. ¿Cuánto tiempo se conserva?

  1. 10 años, porque los periodos se suman
  2. 3 años, porque las directivas prevalecen sobre las etiquetas
  3. Depende de cuál se creó primero
  4. 7 años, porque prevalece el periodo de retención más largo
Ver respuesta

Respuesta correcta: D. Según los principios de retención, la conservación prevalece sobre la eliminación y gana el periodo de conservación más largo.

4. Muchos agentes creados con el mismo diseño deben compartir propietarios, patrocinadores y configuración de acceso. ¿Qué debe usar en Entra Agent ID?

  1. Un buzón compartido por familia de agentes
  2. Una plantilla de identidad de agente (blueprint)
  3. Un paquete de directivas de Teams
  4. Una lista de distribución dinámica
Ver respuesta

Respuesta correcta: B. Una plantilla de identidad de agente es un modelo reutilizable que estandariza cómo se crean y gobiernan las identidades de agente (propietarios, patrocinadores, acceso, ciclo de vida).

5. Los creadores de Copilot Studio comparten agentes con toda la empresa. ¿Cómo puede limitar el uso compartido a grupos pequeños?

  1. Deshabilitar la búsqueda web de Copilot en la directiva
  2. Asignar a los creadores solo el rol Lector global
  3. Definir límites de uso compartido en Power Platform
  4. Bloquear las URL de los agentes en la lista de permitidos
Ver respuesta

Respuesta correcta: C. Los controles de uso compartido de Copilot Studio (roles Editor y Lector, límites) se definen en el entorno administrado o grupo de entornos del centro de Power Platform.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica AB-650?

El banco de preguntas tiene 303 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar AB-650?

El examen oficial de Microsoft AB-650 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen AB-650?

Tres dominios: configurar y administrar inquilinos y cargas de trabajo de Microsoft 365 (20-25%), gobernarlos y protegerlos (40-45%) y administrar y proteger servicios de IA en Microsoft 365 (35-40%).

¿Es gratis el examen de práctica AB-650?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para AB-650, no extractos del examen real ni "exam dumps".
