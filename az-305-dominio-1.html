AZ-305 · Dominio 1 de 4 · 25-30% del examen

Diseñar soluciones de identidad, gobernanza y supervisión

El dominio 1 de AZ-305 supone entre el 25 y el 30% del examen. En EarnYourCert tienes 106 preguntas originales de este dominio, todas con explicación: 74 de opción múltiple, 14 de sí o no y 18 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 106 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué tipo de alerta ejecuta una consulta KQL sobre registros y se activa cuando los resultados cumplen una condición?

  1. Regla de alertas de búsqueda de registros
  2. Alerta de métrica
  3. Alerta de presupuesto
  4. Alerta de Service Health
Ver respuesta

Respuesta correcta: A. Las alertas de búsqueda de registros son adecuadas para condiciones complejas en los registros.

2. Los datos personales deben eliminarse de los registros antes de guardarlos en el área de Log Analytics. ¿Qué debes diseñar?

  1. Un grupo de acciones
  2. Una transformación en tiempo de ingesta en una regla de recopilación de datos
  3. Una regla de alerta de registro que elimine las filas coincidentes cada hora
  4. Un libro
Ver respuesta

Respuesta correcta: B. Las transformaciones de las DCR ejecutan KQL sobre los datos entrantes para filtrar o enmascarar columnas antes de guardarlos.

3. Operaciones debe encontrar qué cambios de configuración se hicieron en los recursos de varias suscripciones en los últimos 14 días. ¿Qué herramienta encaja?

  1. Métricas en directo de Application Insights para cada aplicación
  2. Cambios de recursos de Azure Resource Graph
  3. Azure Advisor
  4. Service Health
Ver respuesta

Respuesta correcta: B. Resource Graph conserva un historial de cambios de propiedades que se puede consultar con KQL (resourcechanges).

4. ¿Qué servicio proporciona activación justo a tiempo y basada en aprobación de roles de recursos de Azure como Propietario?

  1. Revisiones de acceso de Microsoft Entra
  2. Roles personalizados de Azure RBAC
  3. Azure Lighthouse
  4. Microsoft Entra Privileged Identity Management
Ver respuesta

Respuesta correcta: D. PIM admite la elegibilidad y activación de roles de Azure RBAC.

5. Los empleados de una organización asociada necesitan acceder a una aplicación interna con sus propias credenciales corporativas. ¿Qué enfoque debes recomendar?

  1. Crear cuentas locales para cada usuario del socio
  2. Colaboración B2B de Microsoft Entra con usuarios invitados
  3. Usar Microsoft Entra Domain Services
  4. Publicarla con el proxy de aplicaciones y acceso anónimo
Ver respuesta

Respuesta correcta: B. B2B permite que los socios se autentiquen con sus propios proveedores de identidades.

6. ¿Qué enfoque debe usarse para que una canalización de Azure DevOps implemente en Azure sin almacenar secretos?

  1. Acceso anónimo
  2. Un secreto de cliente de larga duración en el repositorio
  3. Una contraseña de administrador compartida
  4. Una conexión de servicio que use federación de identidades de carga de trabajo
Ver respuesta

Respuesta correcta: D. La federación elimina la administración de secretos.

7. ¿Qué efecto de Azure Policy implementa automáticamente un recurso como la configuración de diagnóstico cuando se crea un recurso coincidente?

  1. Append
  2. Deny
  3. DeployIfNotExists
  4. Solo AuditIfNotExists
Ver respuesta

Respuesta correcta: C. DeployIfNotExists corrige implementando recursos relacionados.

8. ¿Qué diseño de organización de recursos se recomienda para separar cargas de producción y no producción con gobernanza diferente?

  1. Suscripciones separadas bajo grupos de administración con sus propias directivas
  2. Un grupo de recursos para todas las cargas, con etiquetas para cada entorno
  3. Una VM compartida para todos los entornos
  4. Solo etiquetas en una suscripción compartida, con una convención de nombres
Ver respuesta

Respuesta correcta: A. Las suscripciones actúan como límites de acceso, directiva y facturación.
