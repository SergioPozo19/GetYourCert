SC-300 sample questions

Five real questions from our 306-question bank. Try to answer before revealing the solution.

1. Two companies in the same group want users in each tenant to appear in the other tenant's directory automatically. Which feature provides this?

  1. AD FS
  2. Seamless SSO
  3. Password hash synchronization
  4. Cross-tenant synchronization
Show answer

Correct answer: D. Cross-tenant synchronization automates creating, updating and deleting B2B collaboration users between tenants.

2. How often does Microsoft Entra Connect Sync run delta synchronization by default?

  1. Only manually
  2. Once a year
  3. Every 30 minutes
  4. Every 30 seconds
Show answer

Correct answer: C. The scheduler runs delta sync about every 30 minutes; you can force a cycle with Start-ADSyncSyncCycle.

3. Which Global Secure Access capability secures access to public internet and SaaS apps with web filtering and Conditional Access?

  1. PIM
  2. Microsoft Entra Internet Access
  3. Microsoft Entra Connect Sync
  4. Microsoft Entra Private Access
Show answer

Correct answer: B. Internet Access is a secure web gateway integrated with Entra.

4. What is the relationship between an app registration and an enterprise application?

  1. An enterprise application is a user account that signs in on behalf of the app registration
  2. They are two names for exactly the same object in every tenant, with no difference at all
  3. The registration is the app object; the enterprise app is its service principal in a tenant
  4. An app registration is a device
Show answer

Correct answer: C. The application object is global to the home tenant; each tenant has its own service principal.

5. Which reviewer option lets users review their own access?

  1. Guest inviter
  2. Self-review
  3. Global Reader
  4. Break-glass account
Show answer

Correct answer: B. Reviewers can be owners, selected users, managers or the users themselves.

Frequently asked questions

How many questions does the SC-300 practice exam have?

The question bank has 306 original questions. Each practice exam draws 50 questions weighted by domain, just like the official exam.

What's the passing score for SC-300?

Microsoft's official SC-300 exam requires a score equivalent to 70% to pass. We use the same threshold in our practice exams so you train under realistic conditions.

What domains does the SC-300 exam cover?

Four domains: implement and manage user identities (20-25%), implement authentication and access management (25-30%), plan and implement workload identities (20-25%), and plan and automate identity governance (20-25%).
