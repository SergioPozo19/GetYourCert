Preguntas de ejemplo del dominio 4

8 preguntas de nuestro banco de 72 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué característica le envía un correo cuando un icono de tarjeta de un panel supera un umbral?

  1. Marcadores
  2. Sincronizar segmentaciones
  3. Alertas de datos
  4. Temas
Ver respuesta

Respuesta correcta: C. Las alertas de datos funcionan en iconos de tarjeta, medidor y KPI.

2. ¿Cuándo se requiere una puerta de enlace de datos local para la actualización programada?

  1. Nunca
  2. Cuando el origen es un libro de Excel almacenado en OneDrive para la Empresa
  3. Siempre para orígenes en la nube como Azure SQL Database o SharePoint Online
  4. Cuando los orígenes están en una red privada inaccesible para el servicio
Ver respuesta

Respuesta correcta: D. Los orígenes en la nube suelen actualizarse sin una puerta de enlace.

3. ¿Qué característica envía por correo una instantánea de una página de informe a los usuarios con una programación?

  1. Canalizaciones de implementación
  2. Suscripciones por correo
  3. Seguridad de nivel de fila
  4. Flujos de datos
Ver respuesta

Respuesta correcta: B. Las suscripciones entregan instantáneas programadas de informes.

4. ¿Por qué es arriesgado 'Publicar en la web' para informes internos?

  1. Elimina el informe original tras crear el código público para insertar
  2. Deshabilita la RLS solo para los administradores del área
  3. Requiere capacidad Premium
  4. Cualquiera con el vínculo puede ver los datos sin iniciar sesión
Ver respuesta

Respuesta correcta: D. Publicar en la web crea un vínculo público sin autenticación; usa la inserción segura para compartir internamente.

5. Los responsables quieren seguir objetivos como las metas de ventas mensuales con comprobaciones y estado dentro de Power BI. ¿Qué característica encaja?

  1. Vista de linaje
  2. Flujos de datos
  3. Métricas (cuadros de mandos)
  4. Suscripciones a informes paginados con parámetros por equipo
Ver respuesta

Respuesta correcta: C. Las métricas de los cuadros de mandos vinculan objetivos a datos de informes y admiten comprobaciones y estados.

6. ¿Qué rol de área de trabajo puede ver el contenido pero no editarlo ni publicarlo?

  1. Lector
  2. Administrador
  3. Miembro
  4. Colaborador
Ver respuesta

Respuesta correcta: A. Lector es de solo lectura.

7. ¿Qué característica de seguridad restringe las filas de datos que un usuario puede ver en un informe según su identidad?

  1. Marcadores por grupo de usuarios
  2. Seguridad de nivel de objeto (OLS)
  3. Etiquetas de confidencialidad en el informe
  4. Seguridad a nivel de fila (RLS)
Ver respuesta

Respuesta correcta: D. RLS filtra los datos por rol.

8. ¿Cómo puede compartir un informe con compañeros que no son miembros del área sin incluirlos en ella?

  1. Publicar una aplicación del área y asignar audiencias
  2. Compartir el archivo .pbix por correo
  3. Exportar a PDF cada semana
  4. Agregar a todos como Administrador
Ver respuesta

Respuesta correcta: A. Las aplicaciones empaquetan contenido para consumidores con acceso específico por audiencia.
