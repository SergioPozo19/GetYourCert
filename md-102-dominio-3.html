Administrar y proteger aplicaciones

El dominio 3 de MD-102 supone entre el 15 y el 20% del examen. En EarnYourCert tienes 127 preguntas originales de este dominio, todas con explicación: 84 de opción múltiple, 22 de sí o no y 21 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 127 para este dominio. Intenta responder antes de ver la solución.

1. Quieres gestionar el canal de actualización de Microsoft 365 Apps en dispositivos de tu organización de forma centralizada. ¿Qué herramienta de Microsoft es la más adecuada para esto?

  1. Windows Update for Business con directivas de actualización de canal para aplicaciones de Microsoft 365
  2. Centro de administración de Aplicaciones de Microsoft 365 (apps.microsoft.com) con el servicio de inventario de Office
  3. Catálogo de Microsoft Update con clasificaciones de actualización para aplicaciones empresariales de Office
  4. Windows Server Update Services (WSUS) con aprobaciones de actualizaciones de canal de Office
Ver respuesta

Respuesta correcta: B. El Centro de administración de Microsoft 365 Apps permite ver el inventario de instalaciones de Office, gestionar canales de actualización y configurar directivas para todos los dispositivos con M365 Apps instalado.

2. ¿Qué directiva de acceso condicional debes configurar para requerir que las aplicaciones cliente aprobadas usen directivas de protección de aplicaciones de Intune antes de acceder a Exchange Online desde dispositivos iOS/Android?

  1. Una directiva de acceso condicional con control de concesión 'Requerir dispositivo conforme'
  2. Una directiva de acceso condicional con control de concesión 'Requerir directiva de protección de aplicaciones'
  3. Una directiva de acceso condicional con control de concesión 'Requerir aplicación cliente aprobada'
  4. Una directiva de acceso condicional con control de sesión de restricción de aplicaciones
Ver respuesta

Respuesta correcta: B. El control de concesión 'Requerir directiva de protección de aplicaciones' en el acceso condicional de Entra ID garantiza que solo las apps con una APP de Intune activa puedan acceder a los recursos protegidos desde iOS/Android.

3. ¿Qué configuración de una directiva de protección de aplicaciones (APP) de Intune controla si los usuarios pueden transferir datos desde aplicaciones gestionadas a aplicaciones no gestionadas (como aplicaciones personales)?

  1. Cifrar los datos de la organización en reposo dentro de las aplicaciones administradas
  2. Enviar datos de la organización a otras aplicaciones (Enviar datos de la org. a)
  3. Recibir datos de otras aplicaciones (Recibir datos de)
  4. Sincronizar datos con aplicaciones nativas del dispositivo como contactos y calendario
Ver respuesta

Respuesta correcta: B. La configuración 'Enviar datos de la organización a otras aplicaciones' controla si los datos de apps gestionadas pueden moverse a otras apps. Las opciones son: Sin restricciones / Apps gestionadas por directiva / Ninguna.

4. ¿Qué configuración en las directivas de protección de aplicaciones de Intune controla si los datos corporativos en las aplicaciones gestionadas deben cifrarse?

  1. Requerir cifrado de dispositivo
  2. Cifrar datos de la organización
  3. Nivel mínimo de parche de seguridad
  4. Acceso condicional de aplicaciones
Ver respuesta

Respuesta correcta: B. La configuración 'Cifrar datos de la organización' en las APP de Intune habilita el cifrado de datos corporativos almacenados por las aplicaciones gestionadas, usando las APIs de cifrado del sistema operativo.

5. ¿Cuál es el propósito de la configuración 'Número máximo de intentos de PIN' en una directiva de protección de aplicaciones de Intune?

  1. Limitar el número de veces que un usuario puede restablecer su PIN de Microsoft Entra ID en un período de 24 horas
  2. Definir después de cuántos intentos de PIN incorrectos se borran los datos corporativos de la aplicación o se resetea el PIN
  3. Establecer la complejidad mínima del PIN de la aplicación, incluyendo la longitud y el tipo de caracteres permitidos
  4. Controlar cuántas aplicaciones gestionadas con APP puede abrir el usuario simultáneamente en el dispositivo
Ver respuesta

Respuesta correcta: B. La configuración de máximos intentos de PIN define el umbral de intentos fallidos. Cuando se alcanza, la app puede borrar los datos corporativos o bloquear el acceso, según la configuración de la directiva.

6. ¿Qué característica de las directivas de protección de aplicaciones (APP) de Intune permite requerir al usuario que se autentique de nuevo con biometría o PIN después de un período de inactividad específico en la aplicación?

  1. La reautenticación de acceso condicional que requiere que el usuario vuelva a autenticarse tras un período de inactividad
  2. El tiempo de espera de PIN (PIN timeout) o el requisito de comprobación de acceso tras un período de gracia de acceso (Access grace period)
  3. El cifrado de datos de la organización que se activa automáticamente tras un período de sesión prolongada
  4. El borrado selectivo automático de datos corporativos que se ejecuta tras un período de inactividad prolongado
Ver respuesta

Respuesta correcta: B. La configuración 'Comprobar requisitos de acceso después de (minutos de inactividad)' en las APP define cuánto tiempo puede estar inactivo el dispositivo antes de que la app requiera que el usuario vuelva a introducir su PIN o autenticarse.

7. ¿Qué configuración de las directivas de protección de aplicaciones de Intune para Android controla si los usuarios pueden copiar y pegar texto entre una app gestionada y el teclado del sistema (para autocompletado o portapapeles)?

  1. La configuración 'Bloquear capturas de pantalla' que impide al usuario tomar capturas de la pantalla cuando datos corporativos están visibles en la app
  2. La configuración de 'Teclados no gestionados' o 'Bloquear teclados de terceros'
  3. La configuración 'Enviar datos de la organización a otras aplicaciones' que controla el nivel de transferencia de datos hacia apps no gestionadas por APP
  4. La configuración de 'Transferencia de datos entre aplicaciones' que define qué apps pueden recibir datos de las aplicaciones protegidas por la directiva APP
Ver respuesta

Respuesta correcta: B. La configuración de teclados de terceros/no gestionados en las APP de Android controla si el portapapeles del sistema o los teclados alternativos pueden acceder a datos corporativos de la aplicación gestionada.

8. ¿Qué condición adicional pueden incluir las directivas de protección de aplicaciones (APP) de Intune para iOS que no está disponible en las APP para Android?

  1. Requerir PIN numérico en lugar de biométrico para acceder a los datos corporativos de la app, aumentando la seguridad mediante un código de varios dígitos
  2. Exigir Face ID o Touch ID para acceder a los datos corporativos de la app
  3. El cifrado de datos de la app con un certificado de la organización que garantiza la confidencialidad de los datos incluso si el dispositivo es comprometido
  4. La detección y bloqueo automático de la captura de pantalla del contenido de la app para evitar la fuga de información corporativa sensible
Ver respuesta

Respuesta correcta: B. Las APP de iOS en Intune pueden requerir Face ID o Touch ID (biometría de Apple) como método de acceso a datos corporativos en la app. Android tiene configuraciones similares para biometría, pero las opciones específicas varían por plataforma.
