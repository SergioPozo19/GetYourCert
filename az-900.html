Preguntas de ejemplo de AZ-900

Cinco preguntas reales de nuestro banco de 468. Intenta responder antes de ver la solución.

1. ¿Cuál de las siguientes opciones describe mejor la informática en la nube (cloud computing)?

  1. La instalación de software únicamente en equipos de sobremesa
  2. La entrega de recursos de TI a través de Internet con pago por uso
  3. Un tipo de cableado de red exclusivo para oficinas
  4. Un sistema operativo diseñado solo para servidores físicos
Ver respuesta

Respuesta correcta: B. La informática en la nube es la entrega de recursos de TI (proceso, almacenamiento, redes, etc.) a través de Internet, con un modelo de precios de pago por uso.

2. ¿Las etiquetas (tags) aplicadas a un grupo de recursos se heredan automáticamente por los recursos que contiene?

  1. No, las etiquetas no se heredan a los recursos
  2. Solo se heredan en suscripciones con contrato Enterprise
  3. Sí, siempre se heredan automáticamente sin excepción
  4. Solo se heredan si el recurso es una máquina virtual
Ver respuesta

Respuesta correcta: A. Las etiquetas aplicadas a un grupo de recursos o a una suscripción no se heredan automáticamente por los recursos que contienen; cada recurso debe etiquetarse de forma individual o mediante directivas específicas.

3. Una empresa quiere proteger sus cuentas de almacenamiento frente a la eliminación accidental de blobs por parte de un administrador, permitiendo recuperar los blobs eliminados dentro de un periodo configurable. ¿Qué característica de Azure Storage proporciona esta protección?

  1. La capa de acceso premium de Azure Blob Storage de alto rendimiento
  2. La redundancia de zona (ZRS) para replicar datos entre datacenters de la región
  3. Eliminación temporal (soft delete) para blobs
  4. Azure File Sync para sincronizar archivos locales con Azure Files en la nube
Ver respuesta

Respuesta correcta: C. La eliminación temporal (soft delete) para blobs conserva los datos eliminados o sobrescritos durante un periodo de retención configurable, permitiendo restaurarlos si la eliminación fue accidental. La redundancia con zona (ZRS) protege contra fallos de centros de datos, pero no contra eliminaciones lógicas. La capa de acceso premium se refiere al rendimiento de E/S, no a la recuperación de datos eliminados. Azure File Sync sincroniza archivos entre servidores on-premises y Azure Files, sin relación con la recuperación de blobs eliminados.

4. ¿Qué ocurre si una organización configura un límite de gasto (spending limit) en una cuenta gratuita de Azure y alcanza ese límite?

  1. Se generan cargos adicionales automáticamente sin previo aviso
  2. Los recursos de pago por uso se deshabilitan hasta ajustar el límite
  3. Se crean automáticamente nuevas suscripciones gratuitas
  4. La suscripción se elimina permanentemente sin posibilidad de recuperación
Ver respuesta

Respuesta correcta: B. Si se alcanza el límite de gasto en una cuenta gratuita, los recursos de pago por uso se deshabilitan automáticamente para evitar cargos no deseados, hasta que el usuario elimina o ajusta dicho límite.

5. Una organización aplica un bloqueo de tipo 'CanNotDelete' a una cuenta de almacenamiento, pero más adelante necesita cambiar su configuración de redundancia (de LRS a GRS). ¿Qué ocurrirá al intentar este cambio?

  1. El bloqueo se eliminará automáticamente al intentar modificar la configuración
  2. El cambio se podrá realizar, ya que 'CanNotDelete' solo impide eliminar el recurso, no modificarlo
  3. El cambio será bloqueado, ya que 'CanNotDelete' también impide cualquier modificación
  4. Será necesario eliminar primero la cuenta de almacenamiento y volver a crearla
Ver respuesta

Respuesta correcta: B. El bloqueo 'CanNotDelete' (también llamado 'Delete') impide únicamente que el recurso se elimine, pero permite seguir modificando su configuración, como cambiar el tipo de redundancia. Si se quisiera impedir también las modificaciones, sería necesario usar un bloqueo 'ReadOnly'. No es necesario eliminar y recrear el recurso, y el bloqueo no se elimina automáticamente por intentar una modificación permitida.

El banco de preguntas tiene 468 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar AZ-900?

El examen oficial de Microsoft AZ-900 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen AZ-900?

Tres dominios: descripción de los conceptos de la nube (25-30%), descripción de la arquitectura y los servicios de Azure (35-40%), y descripción de la administración y la gobernanza de Azure (30-35%).

¿Es gratis el examen de práctica AZ-900?
