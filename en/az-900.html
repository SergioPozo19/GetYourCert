AZ-900 sample questions

Five real questions from our 468-question bank. Try to answer before revealing the solution.

1. Which of the following best describes cloud computing?

  1. Installing software only on desktop computers
  2. IT resources delivered over the internet, billed per use
  3. A type of network cabling used only in offices
  4. An operating system designed only for physical servers
Show answer

Correct answer: B. Cloud computing is the delivery of IT resources (compute, storage, networking, etc.) over the internet, using a pay-as-you-go pricing model.

2. Are tags applied to a resource group automatically inherited by the resources it contains?

  1. No, tags are not automatically inherited by resources
  2. Only in subscriptions with an Enterprise Agreement
  3. Yes, they are always automatically inherited without exception
  4. Only if the resource is a virtual machine
Show answer

Correct answer: A. Tags applied to a resource group or subscription are not automatically inherited by the resources within them; each resource must be tagged individually or through specific policies.

3. A company wants to protect its storage accounts against accidental deletion of blobs by an administrator, allowing deleted blobs to be recovered within a configurable period. Which Azure Storage feature provides this protection?

  1. The Azure Blob Storage premium high-performance access tier
  2. Zone redundancy (ZRS) for replicating data across datacenters in the region
  3. Soft delete for blobs
  4. Azure File Sync for synchronizing on-premises files with Azure Files in the cloud
Show answer

Correct answer: C. Soft delete for blobs retains deleted or overwritten data for a configurable retention period, allowing restoration if the deletion was accidental. Zone redundancy (ZRS) protects against datacenter failures, not logical deletions. The premium access tier refers to I/O performance, not deleted data recovery. Azure File Sync synchronizes files between on-premises servers and Azure Files, unrelated to recovering deleted blobs.

4. What happens if an organization sets a spending limit on an Azure free account and reaches that limit?

  1. Additional charges are automatically generated without notice
  2. Pay-as-you-go resources are disabled until the limit is removed or increased
  3. New free subscriptions are automatically created
  4. The subscription is permanently deleted with no possibility of recovery
Show answer

Correct answer: B. If the spending limit on a free account is reached, pay-as-you-go resources are automatically disabled to prevent unwanted charges, until the user removes or adjusts that limit.

5. An organization applies a 'CanNotDelete' lock to a storage account, but later needs to change its redundancy configuration (from LRS to GRS). What will happen when attempting this change?

  1. The lock will be automatically removed when attempting to modify the configuration
  2. The change will be possible, since 'CanNotDelete' only prevents the resource from being deleted, not modified
  3. The change will be blocked, since 'CanNotDelete' also prevents any modification
  4. The storage account will need to be deleted first and recreated
Show answer

Correct answer: B. The 'CanNotDelete' lock (also called 'Delete') only prevents the resource from being deleted, but still allows modifying its configuration, such as changing the redundancy type. If modifications also needed to be prevented, a 'ReadOnly' lock would be required instead. There's no need to delete and recreate the resource, and the lock isn't automatically removed by attempting a permitted modification.
