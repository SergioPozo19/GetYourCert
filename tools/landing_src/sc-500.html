Confusiones típicas en el examen

Common exam traps

Azure Firewall frente a NSG frente a WAF

Azure Firewall vs NSG vs WAF

El NSG filtra por IP y puerto en una subred o NIC; Azure Firewall es un firewall central con reglas de aplicación y FQDN; el WAF protege aplicaciones web de ataques como inyección SQL.

An NSG filters by IP and port on a subnet or NIC; Azure Firewall is a central firewall with application and FQDN rules; a WAF protects web apps from attacks such as SQL injection.

TDE frente a Always Encrypted

TDE vs Always Encrypted

TDE cifra la base de datos en disco y es transparente para todos; Always Encrypted cifra columnas concretas y ni el administrador de la base de datos ve los valores.

TDE encrypts the database at rest and is transparent to everyone; Always Encrypted encrypts specific columns so even the database admin cannot see the values.

Acceso RBAC de Key Vault frente a directivas de acceso

Key Vault RBAC vs access policies

El modelo RBAC usa roles de Azure con ámbito por almacén o por secreto y es el recomendado; las directivas de acceso son el modelo antiguo, por almacén completo.

The RBAC model uses Azure roles scoped to a vault or a single secret and is the recommended one; access policies are the older, whole-vault model.
