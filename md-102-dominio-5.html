Preguntas de ejemplo del dominio 5

8 preguntas de nuestro banco de 85 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué solicitud de Microsoft Graph desencadena una sincronización inmediata de Intune en un dispositivo administrado concreto?

  1. POST /deviceManagement/managedDevices/{id}/syncDevice
  2. GET /deviceManagement/managedDevices/{id}/sync
  3. DELETE /deviceManagement/managedDevices/{id}
  4. PATCH /devices/{id}/refresh
Ver respuesta

Respuesta correcta: A. Las acciones remotas se exponen como acciones POST sobre el recurso managedDevice, como syncDevice, rebootNow o wipe.

2. Tu script de Graph recibe HTTP 429 (Too Many Requests) al procesar miles de dispositivos. ¿Cuál es el enfoque recomendado?

  1. Respetar el encabezado Retry-After y agrupar solicitudes para reducir las llamadas
  2. Cambiar al punto de conexión beta, que nunca se limita para cuentas de administrador
  3. Reintentar inmediatamente en un bucle continuo
  4. Ejecutar el mismo script desde varias cuentas de administrador a la vez para repartir la carga
Ver respuesta

Respuesta correcta: A. Graph limita a los llamadores intensivos; lo correcto es esperar el tiempo indicado en Retry-After y combinar solicitudes con $batch (hasta 20 por lote).

3. ¿Qué debe devolver un script de detección de cumplimiento personalizado para que Intune lo evalúe con las reglas JSON?

  1. Un objeto JSON comprimido con los valores de configuración detectados
  2. Solo un código de salida 0 o 1, sin ninguna otra salida
  3. Un informe XML guardado en el escritorio del usuario que ha iniciado sesión
  4. Un archivo de texto cargado en SharePoint
Ver respuesta

Respuesta correcta: A. El script escribe un objeto JSON en la salida estándar; cada clave se asocia a un SettingName del archivo JSON de reglas.

4. ¿Cuál es la función de un agente de Security Copilot en Microsoft Intune?

  1. Un asistente de IA que analiza datos del inquilino y propone cambios que revisa el administrador
  2. Un sustituto del control de acceso basado en roles de Intune que asigna permisos por sí solo
  3. Una app cliente que debe instalarse en cada dispositivo antes de que pueda informar de su estado
  4. Un módulo de PowerShell para empaquetar aplicaciones Win32
Ver respuesta

Respuesta correcta: A. Los agentes de Security Copilot en Intune analizan señales, explican hallazgos y sugieren acciones; el administrador mantiene el control y aprueba o descarta las recomendaciones.

5. ¿Qué capacidad de los agentes de Security Copilot en Intune ayuda a priorizar vulnerabilidades de software de Microsoft Defender Vulnerability Management y sugiere cómo corregirlas?

  1. El agente de corrección de vulnerabilidades
  2. El agente de implementación de Autopilot
  3. El agente de Optimización de la distribución
  4. El agente del Portal de empresa
Ver respuesta

Respuesta correcta: A. El agente de corrección de vulnerabilidades correlaciona datos de vulnerabilidades de Defender con los dispositivos administrados por Intune, prioriza por riesgo y recomienda pasos de corrección para que el administrador los apruebe.

6. En un paquete de corrección, ¿qué señal envía el script de detección para que se ejecute el script de corrección?

  1. Un código de salida 1, que indica que se detectó un problema
  2. Un código de salida 0, que indica que se detectó un problema
  3. Un reinicio del dispositivo
  4. Un correo al administrador
Ver respuesta

Respuesta correcta: A. El código de salida 0 indica que el dispositivo está bien; el código 1 indica que se encontró un problema y se ejecuta el script de corrección.

7. El soporte técnico quiere saber qué dispositivos tienen pantallazos azules recurrentes y tiempos de reinicio largos para priorizar la renovación de hardware. ¿Qué capacidad de Intune permite este análisis?

  1. Datos de fiabilidad e inicio de Endpoint analytics
  2. Estado y registros de sincronización del token VPP de Apple
  3. Registros de inicio de sesión de acceso condicional por dispositivo
  4. Informe de estado de asignación de perfiles de implementación de Autopilot
Ver respuesta

Respuesta correcta: A. Endpoint analytics informa de la frecuencia de reinicios, errores de detención y tiempos de inicio, lo que ayuda a identificar dispositivos candidatos a sustitución.

8. ¿Dónde puede comprobar un administrador de Intune si hay una incidencia del servicio de Intune en curso que explique las inscripciones fallidas?

  1. Administración de inquilinos > Estado del inquilino (Estado del servicio) en Intune
  2. Perfiles de configuración de dispositivos, en el informe de estado por opción
  3. La aplicación Portal de empresa
  4. Informes de Windows Update para empresas en el libro de Azure Monitor
Ver respuesta

Respuesta correcta: A. El estado del inquilino muestra incidencias y avisos del servicio, estado de los conectores y licencias, por lo que conviene consultarlo antes de investigar más a fondo.
