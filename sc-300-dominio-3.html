SC-300 · Dominio 3 de 4 · 20-25% del examen

Planificar e implementar identidades de carga de trabajo

El dominio 3 de SC-300 supone entre el 20 y el 25% del examen. En EarnYourCert tienes 103 preguntas originales de este dominio, todas con explicación: 67 de opción múltiple, 14 de sí o no y 22 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 103 para este dominio. Intenta responder antes de ver la solución.

1. ¿Cuál es la diferencia entre una identidad administrada asignada por el sistema y una asignada por el usuario?

  1. Las asignadas por el usuario no pueden acceder a Key Vault, así que se necesita la del sistema para secretos
  2. La asignada por el sistema sigue el ciclo de vida de un recurso; la asignada por el usuario es independiente y compartible
  3. No hay ninguna diferencia
  4. Las asignadas por el sistema solo las pueden usar usuarios y las asignadas por el usuario sirven a aplicaciones
Ver respuesta

Respuesta correcta: B. Usa identidades asignadas por el usuario cuando varios recursos necesiten la misma identidad o cuando necesites preautorizar el acceso.

2. Una aplicación que se ejecuta en una máquina virtual necesita llamar a la API de Azure Resource Manager sin credenciales en el código. ¿Cuál es la secuencia correcta?

  1. Habilitar una identidad administrada en la VM y concederle un rol de Azure
  2. Crear un usuario invitado para la aplicación y guardar su contraseña en la VM
  3. Guardar una contraseña de administrador en el archivo de configuración
  4. Deshabilitar Azure RBAC en la suscripción
Ver respuesta

Respuesta correcta: A. La aplicación obtiene tokens del punto de conexión de metadatos de la instancia sin manejar secretos.

3. ¿Qué enfoque de autenticación permite que un flujo de trabajo de GitHub Actions acceda a recursos de Azure sin almacenar un secreto?

  1. Verificación por SMS
  2. Un secreto de cliente de larga duración en el repositorio
  3. Una contraseña de administrador compartida
  4. Federación de identidades de carga de trabajo mediante OpenID Connect
Ver respuesta

Respuesta correcta: D. Las credenciales federadas confían en los tokens de proveedores de identidades externos.

4. ¿Qué requiere el conector de Microsoft Entra Application Proxy en cuanto a la conectividad de red?

  1. Acceso saliente al servicio de Application Proxy; sin puertos de entrada
  2. Una dirección IP pública en el servidor
  3. Acceso entrante desde internet al servidor
  4. Un ExpressRoute dedicado
Ver respuesta

Respuesta correcta: A. Las conexiones solo salientes reducen la superficie de ataque.

5. Un registro de aplicación está configurado para una aplicación de página única. ¿Qué configuración debe agregarse para que Entra ID pueda devolver tokens a la aplicación después del inicio de sesión?

  1. Un URI de redirección de tipo SPA
  2. Un registro TXT de DNS
  3. Una contraseña prohibida personalizada
  4. Una regla de grupo dinámico
Ver respuesta

Respuesta correcta: A. Los URI de redirección definen adónde se envían los tokens o códigos de autorización tras la autenticación.

6. ¿Qué capacidad de Defender for Cloud Apps ayuda a administrar aplicaciones OAuth de riesgo que tienen acceso a datos de la empresa?

  1. Gobernanza de apps y directivas de apps OAuth
  2. Directivas de BitLocker para los puntos de conexión administrados
  3. Directivas de reuniones de Teams para asistentes externos
  4. Hosts de Azure Bastion en la red virtual
Ver respuesta

Respuesta correcta: A. Las directivas de aplicaciones OAuth detectan aplicaciones con demasiados privilegios o sospechosas y permiten corregirlas.

7. Marcas una aplicación en la nube como no autorizada en Defender for Cloud Apps. ¿Qué puedes hacer a continuación?

  1. Restablecer todas las contraseñas de usuario de la aplicación
  2. Bloquearla mediante Defender for Endpoint o un dispositivo de red
  3. Eliminar el registro de la aplicación y todas sus entidades de servicio
  4. Deshabilitar la MFA de los usuarios que accedieron a la aplicación el mes pasado
Ver respuesta

Respuesta correcta: B. La no autorización se puede aplicar con la integración de endpoints o de red.

8. ¿Qué capacidad de Defender for Cloud Apps ofrece información detallada del acceso a datos de aplicaciones OAuth y permite crear directivas ante comportamientos inusuales, como que una aplicación lea muchos correos de repente?

  1. Recopilador de registros
  2. Gobernanza de aplicaciones
  3. Cloud Discovery
  4. Control de aplicaciones de acceso condicional con directivas de sesión
Ver respuesta

Respuesta correcta: B. La gobernanza de aplicaciones supervisa el uso de Graph API por aplicaciones OAuth y puede deshabilitar automáticamente las de riesgo.
