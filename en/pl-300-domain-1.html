Domain 1 sample questions

8 questions from our 104-question bank for this domain. Try to answer before revealing the solution.

1. Which connector would you use to import data from a folder of monthly CSV files and combine them automatically?

  1. Blank query with a manual list of files
  2. Web connector pointing to each file path
  3. Folder connector with Combine Files
  4. OData feed exposed by the file server
Show answer

Correct answer: C. Combine Files appends files with the same schema.

2. Which storage mode setting makes a dimension table load into memory while the large fact table stays in DirectQuery to improve slicer performance?

  1. Import on the fact table only
  2. Hidden columns
  3. Streaming
  4. Dual storage mode on the dimension
Show answer

Correct answer: D. Dual tables act as Import or DirectQuery as needed.

3. Which connector imports data from a SharePoint folder that holds many Excel workbooks with the same layout?

  1. SharePoint folder
  2. Web page
  3. Blank query only
  4. OData feed
Show answer

Correct answer: A. The SharePoint folder connector lists and combines files.

4. You want to extend an existing published semantic model with your own Excel table without copying the original data. What should you use?

  1. A dataflow
  2. DirectQuery for Power BI semantic models (composite model)
  3. Import the semantic model into a new PBIX file with all tables
  4. A live connection only
Show answer

Correct answer: B. Converting a live connection to DirectQuery lets you add local tables while querying the remote model.

5. Which feature lets you reuse a transformation across several queries as a function?

  1. Create function from a query with parameters
  2. Duplicate the query many times
  3. Reference the query without changes
  4. Disable load for the query
Show answer

Correct answer: A. Custom functions encapsulate steps so they can be invoked per row or reused.

6. Which merge join kind returns only rows from the first table that have no match in the second table?

  1. Full outer
  2. Right outer
  3. Left anti
  4. Inner
Show answer

Correct answer: C. Left anti finds unmatched rows.

7. You need a copy of a query that follows changes made to the original query's earlier steps. Which option should you use?

  1. Duplicate
  2. Reference
  3. Rename
  4. Disable load
Show answer

Correct answer: B. A reference query builds on the original; a duplicate copies steps independently.

8. Which key design is best for a relationship between a Sales fact table and a Product dimension table?

  1. No key, relating the tables on the product name text
  2. A date column from the fact table
  3. A concatenated text key with spaces between the parts
  4. A single-column unique key such as ProductKey
Show answer

Correct answer: D. Relationships need a unique key on the one side.
