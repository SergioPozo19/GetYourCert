PL-300 sample questions

Five real questions from our 330-question bank. Try to answer before revealing the solution.

1. Which transformation turns unique values in an Attribute column into separate columns using a Values column?

  1. Remove duplicates
  2. Append
  3. Pivot Column
  4. Unpivot Columns
Show answer

Correct answer: C. Pivot spreads values across columns.

2. Which function calculates a running year-to-date total of a measure?

  1. LOOKUPVALUE
  2. SWITCH
  3. COUNTROWS
  4. TOTALYTD
Show answer

Correct answer: D. TOTALYTD and DATESYTD are year-to-date helpers.

3. Which feature creates a drill-down path such as Year > Quarter > Month in the model?

  1. Field parameter
  2. Hierarchy
  3. Calculation group
  4. Perspective
Show answer

Correct answer: B. Hierarchies enable drill-down in visuals.

4. A user wants to prevent a visual from filtering other visuals on the same page when selected. Which feature controls this?

  1. Field parameters on the visual
  2. Visual-level filters on each chart
  3. Edit interactions
  4. Bookmarks with selected visuals only
Show answer

Correct answer: C. Edit interactions sets filter, highlight or none.

5. What is the effect of marking a semantic model as Certified?

  1. It deletes old versions of the model and keeps only the certified one
  2. It encrypts the model with a key
  3. It adds row-level security automatically based on the reviewer's groups
  4. Signals that an authorized reviewer verified its quality
Show answer

Correct answer: D. Certification is an endorsement level.

Frequently asked questions

How many questions does the PL-300 practice exam have?

The question bank has 330 original questions. Each practice exam draws 50 questions weighted by domain, just like the official exam.

What's the passing score for PL-300?

Microsoft's official PL-300 exam requires a score equivalent to 70% to pass. We use the same threshold in our practice exams so you train under realistic conditions.

What domains does the PL-300 exam cover?

Four domains: prepare the data (25-30%), model the data (25-30%), visualize and analyze the data (25-30%), and manage and secure Power BI (15-20%).

Is the PL-300 practice exam free?

Yes, you can practice for free without signing up. Creating a free account adds progress tracking and smart review (SRS); the Pro tier removes daily question limits.
