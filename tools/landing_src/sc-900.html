Confusiones típicas en el examen

Common exam traps

Defender for Cloud frente a Sentinel

Defender for Cloud vs Sentinel

Defender for Cloud mejora la postura de seguridad y protege cargas de trabajo; Sentinel recoge señales de muchas fuentes para detectar, investigar y responder (SIEM y SOAR).

Defender for Cloud improves security posture and protects workloads; Sentinel collects signals from many sources to detect, investigate and respond (SIEM and SOAR).

Etiquetas de confidencialidad frente a etiquetas de retención

Sensitivity labels vs retention labels

Las de confidencialidad clasifican y protegen (cifrado, marcas); las de retención deciden cuánto tiempo se guarda o cuándo se borra el contenido.

Sensitivity labels classify and protect (encryption, markings); retention labels decide how long content is kept or when it is deleted.

Compliance Manager frente a puntuación de seguridad

Compliance Manager vs secure score

Compliance Manager mide el cumplimiento de normativas con una puntuación de cumplimiento; la puntuación de seguridad mide la postura de seguridad de tus configuraciones.

Compliance Manager measures regulatory compliance with a compliance score; secure score measures the security posture of your configuration.

PIM frente a acceso condicional

PIM vs Conditional Access

PIM da roles de administrador solo cuando hacen falta y por tiempo limitado; el acceso condicional decide si se permite un inicio de sesión según usuario, dispositivo, ubicación o riesgo.

PIM grants admin roles only when needed and for a limited time; Conditional Access decides whether a sign-in is allowed based on user, device, location or risk.
