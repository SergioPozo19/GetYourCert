AZ-305 sample questions

Five real questions from our 321-question bank. Try to answer before revealing the solution.

1. An Azure VM must access Azure SQL Database without any password in its configuration. What should you recommend?

  1. A managed identity with Microsoft Entra authentication on the database
  2. Anonymous access restricted by firewall rules
  3. A password stored in an environment variable
  4. A password in app settings
Show answer

Correct answer: A. Managed identities remove secrets from configuration.

2. Which feature encrypts sensitive columns so that even database administrators cannot see plaintext values?

  1. Dynamic data masking only
  2. Always Encrypted
  3. Transparent data encryption only
  4. Public endpoint
Show answer

Correct answer: B. Always Encrypted keeps keys outside the database engine.

3. Which factor is most important when choosing a Cosmos DB partition key?

  1. The partition key must be a boolean value
  2. A constant value for all items to simplify queries
  3. High cardinality that distributes requests and storage evenly
  4. The shortest possible string value
Show answer

Correct answer: C. A poor key creates hot partitions.

4. An organization needs to protect SQL Server databases running in Azure VMs with log backups every 15 minutes. Which option fits?

  1. Azure Backup for SQL Server in Azure VMs
  2. Azure VM snapshots
  3. Native SQL backups to a local disk
  4. Azure Site Recovery
Show answer

Correct answer: A. The workload-aware backup supports log backups and PITR.

5. Which service provides regional layer-7 load balancing with URL-based routing, TLS termination and an optional WAF?

  1. Azure Load Balancer
  2. Azure Traffic Manager
  3. Azure Application Gateway
  4. Azure NAT Gateway
Show answer

Correct answer: C. Application Gateway is a regional web traffic load balancer.
