Domain 3 sample questions

8 questions from our 93-question bank for this domain. Try to answer before revealing the solution.

1. Which advanced hunting table contains process creation events from devices onboarded to Defender for Endpoint?

  1. DeviceProcessEvents
  2. EmailEvents
  3. CloudAppEvents
  4. IdentityLogonEvents
Show answer

Correct answer: A. The DeviceProcessEvents table holds process creation events, with command lines, from devices onboarded to Defender for Endpoint. EmailEvents is for email, CloudAppEvents for cloud apps, and IdentityLogonEvents for sign-ins.

2. Which table should you query to find emails delivered to users with their sender, subject and threat detection details?

  1. DeviceRegistryEvents
  2. DeviceNetworkEvents
  3. EmailEvents
  4. IdentityDirectoryEvents
Show answer

Correct answer: C. EmailEvents holds Defender for Office 365 email delivery information: sender, subject and threat detections. DeviceRegistryEvents and DeviceNetworkEvents are device tables, and IdentityDirectoryEvents is for Active Directory.

3. What does threat analytics in Microsoft Defender XDR provide?

  1. A report of licensed users per workload with renewal dates and costs
  2. A summary of monthly cloud spend broken down by subscription and service
  3. A schedule of device backups
  4. Reports on emerging threats with exposure and recommended mitigations
Show answer

Correct answer: D. Defender XDR threat analytics publishes reports on emerging threats with your exposure and recommended mitigations, so you can prioritize. It isn't a licensing, cloud spend or backup report.

4. Which table contains activity from Defender for Cloud Apps connected apps, such as SaaS file downloads?

  1. CloudAppEvents
  2. SecurityEvent
  3. EmailEvents
  4. DeviceEvents
Show answer

Correct answer: A. CloudAppEvents holds activity from apps connected to Defender for Cloud Apps, such as SaaS file downloads. SecurityEvent is for Windows, EmailEvents for email, and DeviceEvents for miscellaneous device events.

5. What does the KQL let statement do?

  1. Sends the query results by email
  2. Deletes the matching rows
  3. Defines a variable or reusable expression
  4. Creates a saved function in the workspace for all users
Show answer

Correct answer: C. let defines a variable or reusable expression inside the query, such as a time range. It doesn't email results, delete rows, or create a saved function for all users.

6. What does the Microsoft Sentinel MCP server enable?

  1. Replication of Sentinel data to another Azure region
  2. AI assistants and agents can securely query Sentinel data
  3. Automatic Windows updates for the monitored servers
  4. DNS resolution for names inside the workspace
Show answer

Correct answer: B. The Sentinel MCP server lets AI assistants and agents securely query Sentinel data, since MCP is a protocol that connects AI tools to data sources. It doesn't replicate data across regions, update Windows or resolve DNS.

7. Which Sentinel table stores alerts generated by Sentinel and connected products?

  1. Heartbeat
  2. OfficeActivity
  3. SecurityAlert
  4. Perf
Show answer

Correct answer: C. SecurityAlert stores alerts from Sentinel and connected products; SecurityIncident stores incidents. Heartbeat records agent health, OfficeActivity Microsoft 365 activity, and Perf performance counters.

8. Which KQL operator splits a dynamic array column into one row per element?

  1. top
  2. mv-expand
  3. distinct
  4. summarize
Show answer

Correct answer: B. mv-expand splits a dynamic array or property bag column into one row per element. top returns the first sorted rows, distinct removes duplicates, and summarize aggregates.
