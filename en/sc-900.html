SC-900 sample questions

Five real questions from our 310-question bank. Try to answer before revealing the solution.

1. Why is identity often called the new security perimeter?

  1. Because firewalls are no longer needed once all users have cloud identities assigned
  2. Because identities replace encryption, so data no longer needs to be protected at rest
  3. Because people and devices access resources from anywhere, so access depends on who asks
  4. Because passwords are never used anymore, so network location is the only remaining control
Show answer

Correct answer: C. With remote work and cloud apps, the network edge no longer defines trust; verifying identity does.

2. Which Microsoft Entra product helps discover, remediate and monitor excessive permissions across multicloud environments?

  1. Entra Domain Services
  2. Entra Verified ID
  3. Microsoft Entra Connect Sync
  4. Microsoft Entra Permissions Management
Show answer

Correct answer: D. Permissions Management is a cloud infrastructure entitlement management (CIEM) solution.

3. Where do security teams manage incidents, alerts, advanced hunting and reports across Defender products?

  1. The Teams admin center
  2. The Exchange admin center
  3. The Microsoft Defender portal
  4. The Azure Cost Management portal
Show answer

Correct answer: C. The Defender portal (security.microsoft.com) unifies incidents and hunting across the Defender suite.

4. Which Defender for Endpoint feature prioritizes software vulnerabilities on devices by exploitability and business impact?

  1. Entra access reviews
  2. Safe Attachments
  3. Customer Lockbox
  4. Defender Vulnerability Management
Show answer

Correct answer: D. Risk-based prioritization considers threat context and asset value.

5. What are sensitive information types (SITs) in Microsoft Purview?

  1. Patterns, such as credit card numbers, used to detect sensitive content
  2. Folders that organize email messages by the sensitivity of their content
  3. Groups of users with elevated rights over sensitive SharePoint sites
  4. Network routes for sensitive traffic
Show answer

Correct answer: A. SITs use patterns, keywords and confidence levels.
