Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 93 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué tabla de búsqueda avanzada contiene eventos de creación de procesos de los dispositivos incorporados a Defender for Endpoint?

  1. DeviceProcessEvents
  2. EmailEvents
  3. CloudAppEvents
  4. IdentityLogonEvents
Ver respuesta

Respuesta correcta: A. DeviceProcessEvents registra las creaciones de procesos y las líneas de comandos relacionadas.

2. ¿Qué tabla debes consultar para encontrar los correos entregados a los usuarios con su remitente, asunto y detalles de detección de amenazas?

  1. DeviceRegistryEvents
  2. DeviceNetworkEvents
  3. EmailEvents
  4. IdentityDirectoryEvents
Ver respuesta

Respuesta correcta: C. EmailEvents contiene información de entrega de correo de Defender for Office 365.

3. ¿Qué proporciona el análisis de amenazas en Microsoft Defender XDR?

  1. Un informe de usuarios con licencia por carga de trabajo con fechas de renovación y costes
  2. Un resumen del gasto mensual en la nube desglosado por suscripción y servicio
  3. Una programación de copias de seguridad de dispositivos
  4. Informes sobre amenazas emergentes con exposición y mitigaciones recomendadas
Ver respuesta

Respuesta correcta: D. El análisis de amenazas ayuda a priorizar y mitigar las amenazas actuales.

4. ¿Qué tabla contiene la actividad de las aplicaciones conectadas de Defender for Cloud Apps, como las descargas de archivos SaaS?

  1. CloudAppEvents
  2. SecurityEvent
  3. EmailEvents
  4. DeviceEvents
Ver respuesta

Respuesta correcta: A. CloudAppEvents registra las actividades de aplicaciones en la nube.

5. ¿Qué hace la instrucción let de KQL?

  1. Envía los resultados de la consulta por correo
  2. Elimina las filas coincidentes
  3. Define una variable o expresión reutilizable
  4. Crea una función guardada en el área de trabajo para todos los usuarios
Ver respuesta

Respuesta correcta: C. let simplifica y reutiliza valores como un intervalo de tiempo.

6. ¿Qué habilita el servidor MCP de Microsoft Sentinel?

  1. Replicación de datos de Sentinel a otra región de Azure
  2. Asistentes y agentes de IA consultan datos de Sentinel de forma segura
  3. Actualizaciones automáticas de Windows de los servidores
  4. Resolución DNS de nombres dentro del área de trabajo
Ver respuesta

Respuesta correcta: B. MCP es un protocolo que conecta herramientas de IA con orígenes de datos.

7. ¿Qué tabla de Sentinel almacena las alertas generadas por Sentinel y los productos conectados?

  1. Heartbeat
  2. OfficeActivity
  3. SecurityAlert
  4. Perf
Ver respuesta

Respuesta correcta: C. SecurityIncident almacena incidentes; SecurityAlert almacena alertas.

8. ¿Qué operador KQL divide una columna de matriz dinámica en una fila por elemento?

  1. top
  2. mv-expand
  3. distinct
  4. summarize
Ver respuesta

Respuesta correcta: B. mv-expand expande matrices o conjuntos de propiedades en filas independientes.
