SC-500 · Dominio 4 de 4 · 20-25% del examen

Administrar y supervisar la posición de seguridad

El dominio 4 de SC-500 supone entre el 20 y el 25% del examen. En EarnYourCert tienes 98 preguntas originales de este dominio, todas con explicación: 61 de opción múltiple, 17 de sí o no y 20 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 4

8 preguntas de nuestro banco de 98 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué capacidad de Defender CSPM ayuda a priorizar los riesgos mostrando cómo un atacante podría pasar de una VM expuesta a internet a datos sensibles?

  1. Recomendaciones de puntuación de seguridad sin rutas de ataque
  2. Análisis de rutas de ataque y el explorador de seguridad en la nube
  3. El panel de cumplimiento normativo de estándares ISO
  4. Solicitudes de acceso Just-in-Time a puertos de administración
Ver respuesta

Respuesta correcta: B. Las rutas de ataque priorizan las cadenas de riesgo explotables.

2. ¿Cómo puedes evaluar los recursos de AWS y GCP en Defender for Cloud?

  1. Solo se pueden evaluar los recursos de Azure
  2. Conectar las cuentas en la nube mediante conectores multinube
  3. Migrar primero los recursos de AWS y GCP a Azure
  4. Cargar manualmente inventarios de recursos como archivos CSV
Ver respuesta

Respuesta correcta: B. Los conectores habilitan CSPM y protección de cargas de trabajo entre nubes.

3. ¿Qué característica de Defender for Cloud permite aplicar el mismo estándar de seguridad a muchas suscripciones y seguir el cumplimiento en todas ellas?

  1. Solo una puntuación de seguridad por suscripción
  2. Exenciones de Azure Policy
  3. Estándares de seguridad asignados a nivel de grupo de administración
  4. Etiquetas de grupos de recursos
Ver respuesta

Respuesta correcta: C. Los estándares se pueden asignar a escala.

4. ¿Qué conector lleva los eventos del plano de control de las suscripciones de Azure a Sentinel?

  1. Eventos de seguridad de Windows
  2. CEF mediante AMA
  3. TAXII
  4. Azure Activity
Ver respuesta

Respuesta correcta: D. Los registros de actividad de Azure capturan las operaciones de administración.

5. ¿Qué capacidad de Sentinel activa un flujo de Logic Apps para aislar un dispositivo cuando se crea un incidente de gravedad alta?

  1. Una regla de automatización que ejecuta un cuaderno de estrategias
  2. Una lista de seguimiento
  3. Un libro
  4. Una configuración de agrupación de alertas de una regla de análisis
Ver respuesta

Respuesta correcta: A. Los cuadernos de estrategias ejecutan acciones de respuesta.

6. Los incidentes de una regla de análisis deben mostrar la cuenta y el host afectados como entidades para investigar. ¿Qué debes configurar en la regla?

  1. Asignación de entidades
  2. Mayor frecuencia de consulta y un período retrospectivo más largo
  3. Solo la agrupación de alertas
  4. Retención de datos
Ver respuesta

Respuesta correcta: A. La asignación de entidades convierte columnas de la consulta en entidades usadas por los gráficos de investigación y UEBA.

7. ¿Qué proporcionan los complementos de Security Copilot?

  1. Datos y acciones de herramientas de seguridad de Microsoft y terceros
  2. Hardware dedicado para ejecutar los modelos de lenguaje localmente
  3. Un servicio DNS que resuelve los puntos de conexión de los productos
  4. Un inquilino independiente para cada producto conectado y sus administradores
Ver respuesta

Respuesta correcta: A. Los complementos amplían los orígenes que Copilot puede usar.

8. ¿Qué deben revisar periódicamente los administradores de los complementos y agentes de Security Copilot?

  1. Qué plugins y agentes están habilitados, sus permisos y su uso
  2. Solo si los nombres y descripciones de productos están bien escritos en la lista
  3. Solo el tema de color del portal
  4. La zona DNS de la organización y los certificados que usa cada plugin
Ver respuesta

Respuesta correcta: A. La gobernanza de las extensiones reduce el riesgo.
