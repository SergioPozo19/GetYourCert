Guía de estudio de AB-900: qué entra y cómo prepararlo

AB-900 study guide: what's covered and how to prepare

AB-900 valida los fundamentos para administrar Microsoft 365 Copilot y los agentes de forma segura. El examen gira en torno a una idea: Copilot solo usa los datos a los que cada usuario ya tiene acceso, así que la seguridad y la gobernanza de esos datos son clave.

AB-900 validates the fundamentals of administering Microsoft 365 Copilot and agents securely. The exam revolves around one idea: Copilot only uses data each user can already access, so securing and governing that data is key.

Confusiones típicas en el examen

Common exam traps

Copilot no cambia los permisos

Copilot does not change permissions

Copilot no da acceso a nada nuevo: muestra lo que el usuario ya podía abrir. Si aparece información que no debería, el problema es un permiso demasiado amplio, y se corrige en el origen.

Copilot grants no new access: it surfaces what the user could already open. If it shows information it should not, the problem is an overly broad permission, fixed at the source.

Etiquetas de confidencialidad frente a etiquetas de retención

Sensitivity labels vs retention labels

Las de confidencialidad clasifican y protegen el contenido (por ejemplo, cifrándolo); las de retención deciden cuánto tiempo se conserva y cuándo se elimina.

Sensitivity labels classify and protect content (for example, by encrypting it); retention labels decide how long it is kept and when it is deleted.

Microsoft 365 Copilot frente a Copilot Chat

Microsoft 365 Copilot vs Copilot Chat

Microsoft 365 Copilot necesita licencia y trabaja con los datos de la organización (correo, archivos, reuniones); Copilot Chat se basa en la web y viene incluido para los usuarios de Microsoft 365 con cuenta de Entra.

Microsoft 365 Copilot needs a license and works with organizational data (mail, files, meetings); Copilot Chat is web-grounded and included for Microsoft 365 users with an Entra account.
