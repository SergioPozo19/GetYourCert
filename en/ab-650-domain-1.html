Domain 1 sample questions

8 questions from our 89-question bank for this domain. Try to answer before revealing the solution.

1. Users in the Madrid office report slow Teams and SharePoint. Which Microsoft 365 admin center feature shows network performance insights per office location?

  1. Network connectivity in the Health section
  2. Service health with the full incident history
  3. Message center with planned changes
  4. Usage reports for Microsoft 365 apps
Show answer

Correct answer: A. Health > Network connectivity shows network assessments and insights per office location, based on location data and connectivity tests.

2. A finance employee must manage subscriptions and invoices but not users or settings. Which role follows least privilege?

  1. Global Administrator
  2. User Administrator with access to the billing pages
  3. License Administrator
  4. Billing Administrator
Show answer

Correct answer: D. Billing Administrator handles purchases, subscriptions and invoices; License Administrator only assigns licenses.

3. A license assignment fails with the error that the usage location is missing. What should you do?

  1. Add a custom domain
  2. Turn on targeted release for the user and every member of the group
  3. Set the user's usage location, then assign the license
  4. Reset the user's password
Show answer

Correct answer: C. Usage location is required because service availability varies by country.

4. A project needs a channel that only five members of a 200-person team can see, with its own SharePoint site. Which channel type should you use?

  1. Standard channel with a pinned tab
  2. General channel
  3. Announcement channel
  4. Private channel
Show answer

Correct answer: D. Private channels are visible only to their members and get a separate SharePoint site; standard channels are visible to the whole team.

5. Members of a partner organization must collaborate in one channel without being added as guests to the whole team. Which channel type fits?

  1. Shared channel
  2. Private channel
  3. Standard channel
  4. Org-wide channel
Show answer

Correct answer: A. Shared channels allow people inside and outside the organization (via B2B direct connect) to collaborate without joining the parent team.

6. Before deploying Copilot, you discover that a sensitive HR site is shared with 'Everyone except external users'. Which report helps find other sites like this?

  1. SharePoint data access governance reports
  2. The Teams PSTN usage report filtered by site
  3. The Service health incident history
  4. The Microsoft 365 Apps usage report
Show answer

Correct answer: A. Data access governance (DAG) reports in SharePoint Advanced Management list sites with sharing links, EEEU permissions or oversharing so you can fix them.

7. An HR archive site should stay accessible to its members but must not appear in Copilot responses or organization-wide search. What should you enable?

  1. Site deletion and restore from Microsoft 365 Backup
  2. Restricted access control on the site
  3. A sensitivity label with encryption for every file
  4. Restricted content discovery on the site
Show answer

Correct answer: D. Restricted content discovery hides a site's content from Copilot and org-wide search without changing permissions; restricted access control limits who can open the site.

8. Several department sites must share navigation, branding and a common search scope. What should you create?

  1. A retention policy
  2. A hub site and associate the sites to it
  3. A Microsoft 365 group that contains every department's members
  4. A single site with subfolders
Show answer

Correct answer: B. Hub sites connect related sites with shared navigation, theme and search.
