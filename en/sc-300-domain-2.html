Domain 2 sample questions

8 questions from our 116-question bank for this domain. Try to answer before revealing the solution.

1. An administrator suspects an account is compromised and wants to immediately end all active sessions for the user. What should they do?

  1. Increase the license count
  2. Wait for the token to expire naturally
  3. Revoke the user's sessions and disable or reset the account
  4. Delete the user's mailbox only
Show answer

Correct answer: C. Revoking sessions invalidates refresh tokens so the user must reauthenticate.

2. An on-premises Active Directory needs the same banned password list as the cloud. Which components are deployed?

  1. Password Protection proxy service and DC agents
  2. Application Proxy connectors on the domain controllers
  3. Intune Remediations scripts
  4. Microsoft Entra Cloud Sync agents with password writeback
Show answer

Correct answer: A. DC agents validate passwords against the policy downloaded via the proxy.

3. How can a Conditional Access policy target only devices that are not Intune compliant, such as unmanaged personal laptops?

  1. A group naming policy for the managed devices
  2. A device filter or the device state condition
  3. An application proxy connector near the devices
  4. Access reviews for the device owners every quarter
Show answer

Correct answer: B. Device filters evaluate device attributes such as trust type or compliance.

4. Users flagged with elevated insider risk by Purview must be blocked from sensitive apps. Which Conditional Access condition fits?

  1. Device platforms
  2. Insider risk
  3. Client apps for browsers and mobile apps only
  4. Named locations
Show answer

Correct answer: B. The insider risk condition uses adaptive protection levels from Microsoft Purview.

5. Which feature prompts users to register for MFA by displaying a nudge at sign-in for a defined period?

  1. Named location
  2. Group expiration
  3. Access review
  4. Registration campaign
Show answer

Correct answer: D. Registration campaigns encourage users to set up Microsoft Authenticator.

6. Which risk detection type is generated when a user signs in from two distant locations in a time frame that makes travel impossible?

  1. Anonymous IP
  2. Leaked credentials
  3. Password spray
  4. Impossible travel
Show answer

Correct answer: D. Impossible travel is an offline sign-in risk detection.

7. Where do you investigate risky workload identities, such as a service principal with suspicious activity?

  1. The Azure Activity log
  2. The App registrations owners tab
  3. The Risky workload identities report in ID Protection
  4. The Enterprise applications consent page
Show answer

Correct answer: C. Workload identity risk detections require Workload ID Premium and appear in ID Protection; Conditional Access can block risky service principals.

8. Which Global Secure Access feature lets you block access to categories of websites such as gambling by using web content filtering?

  1. Microsoft Entra application proxy with pre-authentication
  2. Web content filtering in Entra Internet Access policies
  3. Conditional Access session controls for cloud apps
  4. Universal tenant restrictions for external tenants
Show answer

Correct answer: B. Internet Access includes secure web gateway capabilities.
