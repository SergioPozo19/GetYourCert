SC-500 · Dominio 1 de 4 · 20-25% del examen

Administrar identidad, acceso y gobernanza

El dominio 1 de SC-500 supone entre el 20 y el 25% del examen. En EarnYourCert tienes 92 preguntas originales de este dominio, todas con explicación: 61 de opción múltiple, 17 de sí o no y 14 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 92 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué característica de Entra le ayuda a detectar usuarios con inicios de sesión de riesgo para que el acceso condicional pueda responder automáticamente?

  1. Revisiones de acceso de Microsoft Entra
  2. Microsoft Entra ID Protection
  3. Microsoft Entra Connect Health
  4. Privileged Identity Management
Ver respuesta

Respuesta correcta: B. Las señales de riesgo alimentan las directivas de acceso condicional.

2. ¿Qué configuración de Entra limita qué usuarios pueden registrar aplicaciones en el inquilino?

  1. Directiva de nomenclatura de grupos aplicada a grupos de seguridad de aplicaciones
  2. Configuración de usuario: Los usuarios pueden registrar aplicaciones = No
  3. Configuración de colaboración externa para invitaciones de invitados
  4. Configuración de acceso entre inquilinos
Ver respuesta

Respuesta correcta: B. Restringir el registro reduce las aplicaciones en la sombra.

3. ¿Qué característica de Key Vault rota las claves automáticamente según una programación?

  1. Directivas de acceso de Key Vault
  2. Eliminación temporal
  3. Directiva de rotación de claves
  4. Una configuración de diagnóstico
Ver respuesta

Respuesta correcta: C. La rotación automática reduce la antigüedad y el riesgo de las claves.

4. ¿Qué capacidad de Defender CSPM detecta secretos expuestos como claves privadas SSH o tokens de API en VM y repositorios?

  1. Evaluación de vulnerabilidades
  2. Análisis de secretos
  3. Análisis de rutas de ataque
  4. Acceso Just-in-Time
Ver respuesta

Respuesta correcta: B. El análisis de secretos respalda el análisis de rutas de ataque.

5. ¿Qué tipo de objeto de Key Vault almacena certificados X.509 con administración del ciclo de vida?

  1. Claves
  2. Directivas de acceso
  3. Secretos
  4. Certificados
Ver respuesta

Respuesta correcta: D. Key Vault almacena secretos, claves y certificados.

6. ¿Qué característica de Azure identifica y ayuda a eliminar permisos no usados o excesivos de las asignaciones de roles de Azure?

  1. Análisis de permisos / recomendaciones de acceso con privilegios excesivos
  2. Revisiones de acceso de Microsoft Entra para usuarios invitados
  3. Vista de cumplimiento de Azure Policy
  4. Recomendaciones de costes de Azure Advisor
Ver respuesta

Respuesta correcta: A. Ajustar los permisos reduce el riesgo.

7. ¿Qué característica de Azure Policy permite definir tus propias reglas cuando ninguna definición integrada cumple el requisito?

  1. Exenciones de directiva
  2. Solo iniciativas integradas
  3. Solo implementaciones en grupos de administración
  4. Definiciones de directivas personalizadas
Ver respuesta

Respuesta correcta: D. Las directivas personalizadas expresan reglas específicas de la organización en JSON.

8. ¿Qué efecto de directiva puede implementar automáticamente la configuración de diagnóstico en recursos existentes mediante corrección?

  1. Append
  2. DeployIfNotExists
  3. Audit
  4. Deny
Ver respuesta

Respuesta correcta: B. DeployIfNotExists usa una identidad administrada y tareas de corrección para arreglar recursos existentes.
