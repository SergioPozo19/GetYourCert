Preguntas de ejemplo del dominio 4

8 preguntas de nuestro banco de 136 para este dominio. Intenta responder antes de ver la solución.

1. Un equipo necesita control total de Kubernetes, operadores personalizados e integración con una malla de servicios. ¿Qué servicio debe elegir?

  1. Azure App Service
  2. Azure Kubernetes Service (AKS)
  3. Azure Container Instances
  4. Azure Functions
Ver respuesta

Respuesta correcta: B. AKS ofrece Kubernetes administrado con acceso completo a la API.

2. Debe transferir 80 TB a Azure por un enlace lento. ¿Qué opción es más adecuada?

  1. AzCopy por internet
  2. Una VPN con más ancho de banda
  3. Azure Data Box
  4. Solo Azure File Sync
Ver respuesta

Respuesta correcta: C. Data Box es un dispositivo físico para transferencias masivas sin conexión.

3. ¿Qué patrón protege a un servicio posterior de la sobrecarga almacenando solicitudes en búfer entre productores y consumidores?

  1. Acoplamiento síncrono
  2. Base de datos compartida
  3. Nivelación de carga basada en colas
  4. Copia directa de archivos
Ver respuesta

Respuesta correcta: C. Las colas absorben los picos y desacoplan los componentes.

4. ¿Qué servicio detecta y evalúa servidores, bases de datos y aplicaciones web locales para determinar su preparación para la migración y estimar costes?

  1. Azure Advisor
  2. Azure Migrate
  3. Azure Site Recovery
  4. Azure Database Migration Service
Ver respuesta

Respuesta correcta: B. Azure Migrate ofrece herramientas de detección, evaluación y migración.

5. ¿Qué estrategia de migración rediseña una aplicación para usar servicios nativos de la nube como microservicios y sin servidor?

  1. Retirar y sustituir por SaaS
  2. Rediseñar o recompilar
  3. Conservar en local por ahora
  4. Volver a hospedar en VM de Azure (lift and shift)
Ver respuesta

Respuesta correcta: B. Rediseñar ofrece los máximos beneficios de la nube con mayor esfuerzo.

6. ¿Qué servicio ofrece una conexión privada y dedicada entre el entorno local y Azure que no atraviesa internet público?

  1. Azure DNS
  2. Azure VPN Gateway por internet
  3. Azure ExpressRoute
  4. Azure Bastion
Ver respuesta

Respuesta correcta: C. ExpressRoute ofrece conectividad privada mediante un proveedor.

7. ¿Qué opción de red mejora el rendimiento de red de las VM al omitir el conmutador virtual del host?

  1. Conjunto de disponibilidad
  2. Redes aceleradas
  3. Grupos de ubicación por proximidad
  4. Discos Premium SSD v2
Ver respuesta

Respuesta correcta: B. Las redes aceleradas usan SR-IOV para reducir la latencia y el uso de CPU.

8. ¿Qué servicio ofrece acceso RDP/SSH seguro a las VM sin exponer IP públicas ni abrir puertos de administración?

  1. Azure Firewall
  2. Azure NAT Gateway
  3. Azure DDoS Protection
  4. Azure Bastion
Ver respuesta

Respuesta correcta: D. Bastion se conecta por TLS desde el portal.
