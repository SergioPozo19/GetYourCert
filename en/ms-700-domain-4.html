Domain 4 sample questions

8 questions from our 88-question bank for this domain. Try to answer before revealing the solution.

1. You need to investigate who changed a specific team's membership and when, with action detail. What do you consult?

  1. The unified audit log search in Purview
  2. A sensitivity label published for that team
  3. The Call Quality Dashboard filtered by that team
  4. The Network Planner of the Teams admin center
Show answer

Correct answer: A. The unified audit log search shows who, what, and when for actions such as team membership changes.

2. You want to use the Call Quality Dashboard (CQD) to identify if quality issues affect users in a specific building. What must you upload to CQD to enable filtering by building?

  1. A custom Power BI report that imports building data from Microsoft Entra ID into the CQD dashboard
  2. A building data file that maps IP subnets to building names and locations
  3. A user CSV file associating each email address with their assigned building and floor
  4. A network site configuration file linking Teams Admin Center subnets to CQD
Show answer

Correct answer: B. The CQD building data file is a CSV that maps IP subnets to location information (building, city, country). Once uploaded, it allows filtering quality reports by physical location rather than just by IP address.

3. You need to monitor in real time the call quality of a specific user experiencing issues during an ongoing meeting. Which tool in Teams Admin Center allows this?

  1. Real-time call analytics, which shows live network metrics for the user's active sessions
  2. Call Quality Dashboard, which updates its statistics in real time for users currently on a call
  3. Teams device monitor, which shows real-time status of the user's devices
  4. Meeting diagnostics, which analyzes the quality of an ongoing meeting through its identifier
Show answer

Correct answer: A. Real-time call analytics in Teams Admin Center lets admins see live quality metrics (jitter, packet loss, RTT) for active sessions of specific users, useful for troubleshooting during an ongoing meeting.

4. You want a report showing how many PSTN outbound call minutes your organization made last month, broken down by user and call type. Which Teams Admin Center report provides this information?

  1. The Microsoft 365 service health report, which includes Teams Phone usage metrics by tenant
  2. The PSTN call usage report in Teams Admin Center, accessible in the Analytics and reports section
  3. The Call Quality Dashboard, which includes total PSTN call minutes in its main summary view
  4. The Teams user activity report in the Microsoft 365 admin center, calls tab
Show answer

Correct answer: B. The PSTN call usage report in the Analytics and reports section of Teams Admin Center shows PSTN call details per user, including duration, type (inbound/outbound), dialed number, and cost.

5. Teams Admin Center shows your tenant's poor call rate is 12%, above the recommended 3% threshold. What is the first step to identify the root cause?

  1. Update audio drivers and Teams clients for all tenant users to rule out software issues first
  2. Filter the Call Quality Dashboard by building, subnet or endpoint to find where it concentrates
  3. Check Microsoft 365 service health to confirm whether an active incident affects quality globally
  4. Review all individual call analytics for users with poor calls to identify common error patterns
Show answer

Correct answer: B. CQD allows filtering and breaking down quality data by multiple dimensions (building, subnet, client type, ISP, etc.). The first step is to identify whether the issue is concentrated at a specific location, network type, or device type to guide corrective actions.

6. The Call Quality Dashboard shows the poor call rate is 0.01% but one branch has 85% poor calls. What explains this discrepancy and how do you investigate it?

  1. The bad branch has few users, so it barely moves the global rate; filter CQD by building
  2. The CQD date filter is misaligned with the incident date; adjust the date range to see correct data
  3. The CQD data for that building hasn't loaded into the dashboard yet; wait 24 hours for it to update
  4. The 85% threshold indicates hardware problems at that branch's endpoints, only visible in individual call analytics
Show answer

Correct answer: A. When a small branch has a high poor call rate but the global average is low, that branch's call volume isn't enough to affect the average. The solution is to filter CQD by building/subnet of that branch to analyze the specific problem.

7. An administrator needs to verify whether a specific user can start a channel meeting. The user claims they don't see the meeting button in the channel. Which PowerShell cmdlet shows the effective meeting policies assigned to the user?

  1. Get-CsMeetingConfiguration -Identity <UPN> to get the meeting configuration for the specific user
  2. Get-CsOnlineUser -Identity <UPN> | Select-Object TeamsMeetingPolicy to see the meeting policy field
  3. Get-CsTeamsMeetingPolicy -Identity <UPN> to get the meeting policy assigned to the user
  4. Get-CsUserPolicyAssignment -Identity <UPN> -PolicyType TeamsMeetingPolicy to see the effective meeting policy
Show answer

Correct answer: D. Get-CsUserPolicyAssignment with the PolicyType parameter shows which policy is effectively assigned to a user, including whether it comes from a direct assignment, group, or global policy. This is useful for diagnosing why a user doesn't have certain features.

8. A user cannot sign into Teams on their mobile device but can on their desktop. The mobile error is 'Cannot sign in. Contact your administrator.' What is the most likely cause?

  1. The user's Teams license doesn't include access to the Teams mobile client for iOS or Android apps
  2. The user's Teams policy has mobile device access disabled in Admin Center
  3. An Microsoft Entra Conditional Access policy blocking access to Teams from unmanaged or non-compliant devices
  4. The user's mobile device doesn't meet the minimum OS requirements for the Teams mobile client
Show answer

Correct answer: C. The error 'Cannot sign in. Contact your administrator' on mobile generally indicates a Conditional Access block. A CA policy may require the device to be managed (enrolled in Intune) or compliant. The corporate desktop may meet the policy but the personal mobile may not.
