Preguntas de ejemplo de SC-300

Cinco preguntas reales de nuestro banco de 306. Intenta responder antes de ver la solución.

1. Dos empresas del mismo grupo quieren que los usuarios de cada inquilino aparezcan automáticamente en el directorio del otro. ¿Qué característica lo proporciona?

  1. AD FS
  2. Inicio de sesión único de conexión directa
  3. Sincronización de hash de contraseñas
  4. Sincronización entre inquilinos
Ver respuesta

Respuesta correcta: D. La sincronización entre inquilinos automatiza la creación, actualización y eliminación de usuarios de colaboración B2B entre inquilinos.

2. ¿Con qué frecuencia ejecuta Microsoft Entra Connect Sync la sincronización diferencial de forma predeterminada?

  1. Solo manualmente
  2. Una vez al año
  3. Cada 30 minutos
  4. Cada 30 segundos
Ver respuesta

Respuesta correcta: C. El programador ejecuta la sincronización diferencial aproximadamente cada 30 minutos; puedes forzar un ciclo con Start-ADSyncSyncCycle.

3. ¿Qué capacidad de Global Secure Access protege el acceso a internet público y a aplicaciones SaaS con filtrado web y acceso condicional?

  1. PIM
  2. Microsoft Entra Internet Access
  3. Microsoft Entra Connect Sync
  4. Microsoft Entra Private Access
Ver respuesta

Respuesta correcta: B. Internet Access es una puerta de enlace web segura integrada con Entra.

4. ¿Cuál es la relación entre un registro de aplicación y una aplicación empresarial?

  1. Una aplicación empresarial es una cuenta de usuario que inicia sesión en nombre del registro
  2. Son dos nombres para exactamente el mismo objeto en cada inquilino, sin ninguna diferencia
  3. El registro es el objeto de aplicación; la aplicación empresarial es su entidad de servicio en un inquilino
  4. Un registro de aplicación es un dispositivo
Ver respuesta

Respuesta correcta: C. El objeto de aplicación es global en el inquilino de origen; cada inquilino tiene su propia entidad de servicio.

5. ¿Qué opción de revisor permite que los usuarios revisen su propio acceso?

  1. Invitador de invitados
  2. Autorrevisión
  3. Lector global
  4. Cuenta break-glass
Ver respuesta

Respuesta correcta: B. Los revisores pueden ser propietarios, usuarios seleccionados, responsables o los propios usuarios.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica SC-300?

El banco de preguntas tiene 306 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar SC-300?

El examen oficial de Microsoft SC-300 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen SC-300?

Cuatro dominios: implementar y administrar identidades de usuario (20-25%), implementar la autenticación y la administración de acceso (25-30%), planificar e implementar identidades de carga de trabajo (20-25%) y planificar y automatizar la gobernanza de identidades (20-25%).

¿Es gratis el examen de práctica SC-300?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para SC-300, no extractos del examen real ni "exam dumps".
