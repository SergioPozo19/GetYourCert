AB-900 · Dominio 2 de 3 · 35-40% del examen

Seguridad de datos y cumplimiento

El dominio 2 de AB-900 supone entre el 35 y el 40% del examen, el de más peso del temario. En EarnYourCert tienes 193 preguntas originales de este dominio, todas con explicación: 121 de opción múltiple, 41 de sí o no y 31 de completar u ordenar, como en el examen real.

Practicar el dominio 2 gratis →Sin registro. Elige cuántas preguntas quieres hacer.

Qué entra en este dominio

  • Etiquetas de confidencialidad y cifrado con Microsoft Purview
  • Prevención de pérdida de datos (DLP) y directivas de retención
  • Sobreexposición de contenido en SharePoint y OneDrive y cómo detectarla
  • Gestión de la postura de seguridad de datos para IA (DSPM para IA)

Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 193 para este dominio. Intenta responder antes de ver la solución.

1. Complete la frase: En Microsoft Purview, las etiquetas de confidencialidad pueden configurarse para aplicar [___] al contenido etiquetado.

  1. una regla de flujo de correo de Exchange Online al documento etiquetado
  2. una directiva de retención fija de siete años en todo el contenido etiquetado
  3. un nivel de permisos de SharePoint al sitio que contiene el contenido
  4. cifrado, marcas de contenido y restricciones de acceso
Ver respuesta

Respuesta correcta: D. Las etiquetas de confidencialidad pueden aplicar cifrado, marcas (encabezados/pies/marcas de agua) y restricciones de acceso. No definen retención fija, reglas de correo ni niveles de permiso de SharePoint.

2. ¿Qué describe mejor una directiva de retención aplicada a una ubicación?

  1. Aumenta la cuota de la papelera de reciclaje del sitio
  2. Conserva o elimina el contenido según las reglas definidas
  3. Bloquea el inicio de sesión de los usuarios en ese sitio
  4. Cambia el color de los iconos de los archivos de la ubicación
Ver respuesta

Respuesta correcta: B. Correcto: Conserva o elimina el contenido según las reglas definidas.

3. ¿Qué describe mejor el etiquetado de confidencialidad por defecto?

  1. Comparte el archivo con usuarios externos de forma automática
  2. Borra el contenido que no lleva ninguna etiqueta asignada
  3. Aplica una etiqueta base de forma automática al crear contenido
  4. Convierte el documento creado en una imagen estática siempre
Ver respuesta

Respuesta correcta: C. Correcto: Aplica una etiqueta base de forma automática al crear contenido.

4. ¿Qué describe correctamente el uso de datos de Microsoft 365 Copilot para el entrenamiento de modelos?

  1. Los mensajes de los usuarios se publican en Internet para mejorar la calidad del modelo
  2. Todos los mensajes de los usuarios se usan para entrenar modelos de lenguaje públicos
  3. Los datos del inquilino se comparten con todos los demás clientes de Microsoft 365
  4. Los datos del cliente y los mensajes no se usan para entrenar los modelos fundacionales
Ver respuesta

Respuesta correcta: D. Los datos del cliente, los mensajes y las respuestas de Copilot no se usan para entrenar los modelos fundacionales subyacentes. No se comparten entre clientes ni se publican.

5. ¿Por qué importa el principio de mínimo acceso antes de implementar Copilot?

  1. Copilot publica todo el contenido en internet de forma abierta
  2. Copilot cifra todos los buzones que hay en el inquilino
  3. Copilot elimina los permisos configurados en los sitios
  4. Copilot expone contenido al que el usuario puede acceder
Ver respuesta

Respuesta correcta: D. Correcto: Copilot expone contenido al que el usuario puede acceder.

6. ¿Qué describe mejor cómo trata Copilot los permisos existentes?

  1. Los respeta al recuperar y al mostrar el contenido al usuario
  2. Los convierte en acceso anónimo abierto para toda la web
  3. Los ignora por completo para acelerar las respuestas que da
  4. Los elimina cada vez que indexa el contenido del inquilino
Ver respuesta

Respuesta correcta: A. Correcto: Los respeta al recuperar y al mostrar el contenido al usuario.

7. Complete la frase: Compliance Manager ayuda a las organizaciones a [___].

  1. asignar y revocar licencias de Copilot en función del consumo mensual de cada usuario
  2. buscar y preservar contenido en las cargas de trabajo de M365 para casos legales en curso
  3. crear buzones compartidos donde el equipo de cumplimiento archive los registros regulados
  4. evaluar su postura de cumplimiento frente a las normativas y recibir acciones de mejora con una puntuación
Ver respuesta

Respuesta correcta: D. Compliance Manager evalúa la postura de cumplimiento frente a normativas con puntuación y acciones de mejora. Buscar contenido es eDiscovery; asignar licencias es del centro de M365; los buzones son de Exchange.

8. ¿Qué describe mejor el propósito de SharePoint Advanced Management?

  1. Editar y publicar vídeos internos para la organización
  2. Crear encuestas y cuestionarios dirigidos a los empleados
  3. Diseñar plantillas de presentaciones para los empleados
  4. Controlar el acceso y el uso compartido a gran escala
Ver respuesta

Respuesta correcta: D. Correcto: Controlar el acceso y el uso compartido a gran escala.
