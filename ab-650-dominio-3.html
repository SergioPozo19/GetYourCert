Administrar y proteger servicios de IA en Microsoft 365

El dominio 3 de AB-650 supone entre el 35 y el 40% del examen. En EarnYourCert tienes 121 preguntas originales de este dominio, todas con explicación: 81 de opción múltiple, 18 de sí o no y 22 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 121 para este dominio. Intenta responder antes de ver la solución.

1. Quiere que Copilot Chat sea fácil de encontrar en Teams y Outlook para todos los usuarios. ¿Qué debe configurar?

  1. Una directiva de Teams que oculte otras aplicaciones
  2. Una regla de flujo que enlace a Copilot Chat
  3. Anclar Microsoft Copilot Chat en la configuración de Copilot
  4. Una etiqueta de confidencialidad llamada Copilot Chat
Ver respuesta

Respuesta correcta: C. La opción Anclar Copilot Chat ancla Copilot Chat en la barra de navegación de Teams, Outlook y la app Microsoft Copilot.

2. ¿Qué aporta Microsoft Entra Agent ID a los agentes de IA?

  1. Un buzón y una cuenta de OneDrive para cada agente por defecto
  2. Un inquilino aparte donde los agentes se ejecutan aislados
  3. Identidades de agente dedicadas que se gobiernan como otras identidades
  4. Licencias gratuitas de Copilot para cada agente de Copilot Studio
Ver respuesta

Respuesta correcta: C. Entra Agent ID da a los agentes identidades propias en Microsoft Entra para aplicarles acceso condicional, ID Protection, gobernanza y auditoría.

3. ¿Cuál es la diferencia entre el propietario y el patrocinador de un agente en Microsoft Entra?

  1. Los propietarios lo operan; los patrocinadores responden de él
  2. No hay diferencia; ambos términos describen el mismo rol
  3. Los patrocinadores deben ser invitados; los propietarios, administradores globales
  4. Los propietarios pagan el agente; los patrocinadores solo leen sus registros
Ver respuesta

Respuesta correcta: A. Los propietarios responden de la operación técnica y los incidentes; los patrocinadores tienen la responsabilidad de negocio sobre el acceso y el ciclo de vida del agente.

4. El patrocinador de un agente deja la empresa. ¿Cómo evita que el agente quede huérfano sin trabajo manual?

  1. Convertir el buzón del patrocinador en compartido para el agente
  2. Eliminar la identidad del agente antes de deshabilitar al patrocinador
  3. Usar flujos de ciclo de vida que avisen a copatrocinadores y transfieran el patrocinio
  4. Asignar al agente una licencia de Copilot para que no necesite patrocinador
Ver respuesta

Respuesta correcta: C. Los flujos de ciclo de vida de Entra ID Governance incluyen plantillas que avisan a responsables y copatrocinadores y transfieren el patrocinio cuando el patrocinador cambia de puesto o se va.

5. TI quiere que cada nueva instancia de agente parta de una configuración aprobada de herramientas, acceso a datos y gobernanza. ¿Qué debe usar en Agent 365?

  1. Un contacto de correo por instancia
  2. Un tema personalizado para las tarjetas
  3. Una etiqueta de retención para las salidas
  4. Plantillas de agente aprobadas por TI
Ver respuesta

Respuesta correcta: D. Agent 365 admite un sistema de plantillas aprobadas por TI para que las instancias de agente se creen con una configuración coherente y gobernada.

6. Cumplimiento debe detectar e investigar interacciones de agentes poco éticas o inapropiadas. ¿Qué capacidad de Purview encaja?

  1. Entrenamiento de simulación de ataques solo para propietarios
  2. Una directiva de expiración para grupos de agentes
  3. Temas personalizados para los canales de Teams
  4. Cumplimiento de comunicaciones para interacciones de IA
Ver respuesta

Respuesta correcta: D. El cumplimiento de comunicaciones puede detectar contenido inapropiado en interacciones de IA, y la retención y eDiscovery permiten conservarlas e investigarlas.

7. Los auditores preguntan qué agentes no tienen propietario, plantilla de gobernanza o directivas necesarias. ¿Qué le ayuda a evaluar estas carencias?

  1. La lista de entidades restringidas del portal de Defender
  2. La papelera de reciclaje de los sitios de agentes
  3. Los resultados de la prueba de conectividad de red
  4. La información de gobernanza de Agent 365 y las vistas filtradas del registro
Ver respuesta

Respuesta correcta: D. Agent 365 muestra carencias de gobernanza (agentes sin propietario, en riesgo, solicitudes pendientes, excepciones) y detalles de cumplimiento para corregirlas desde vistas filtradas del registro.

8. Muchos usuarios con licencia no han usado Copilot en 60 días. ¿Cuál es la mejor forma de aprovechar esta información?

  1. Desactivar la búsqueda web para hacer Copilot más atractivo
  2. Ofrecerles formación de adopción o reasignar sus licencias
  3. Eliminar sus buzones para liberar espacio
  4. Bloquear su inicio de sesión hasta que vuelvan a usar Copilot
Ver respuesta

Respuesta correcta: B. Los informes de uso identifican usuarios con licencia inactivos para impulsar la adopción (formación, embajadores) o reasignar licencias y reducir costes.
