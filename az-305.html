Preguntas de ejemplo de AZ-305

Cinco preguntas reales de nuestro banco de 354. Intenta responder antes de ver la solución.

1. Una VM de Azure debe acceder a Azure SQL Database sin ninguna contraseña en su configuración. ¿Qué debes recomendar?

  1. Una identidad administrada con autenticación de Microsoft Entra en la base de datos
  2. Acceso anónimo restringido por reglas de firewall
  3. Una contraseña guardada en una variable de entorno
  4. Una contraseña en la configuración de la aplicación
Ver respuesta

Respuesta correcta: A. Las identidades administradas eliminan los secretos de la configuración.

2. ¿Qué característica cifra columnas sensibles de modo que ni siquiera los administradores de la base de datos puedan ver los valores en texto sin formato?

  1. Solo enmascaramiento dinámico de datos
  2. Always Encrypted
  3. Solo cifrado de datos transparente
  4. Punto de conexión público
Ver respuesta

Respuesta correcta: B. Always Encrypted mantiene las claves fuera del motor de base de datos.

3. ¿Qué factor es más importante al elegir una clave de partición de Cosmos DB?

  1. La clave de partición debe ser un valor booleano
  2. Un valor constante para todos los elementos para simplificar las consultas
  3. Una cardinalidad alta que distribuya las solicitudes y el almacenamiento de forma uniforme
  4. El valor de cadena más corto posible
Ver respuesta

Respuesta correcta: C. Una clave deficiente crea particiones calientes.

4. Una organización necesita proteger bases de datos de SQL Server que se ejecutan en VM de Azure con copias de registros cada 15 minutos. ¿Qué opción encaja?

  1. Azure Backup para SQL Server en VM de Azure
  2. Instantáneas de VM de Azure
  3. Copias de seguridad nativas de SQL en un disco local
  4. Azure Site Recovery
Ver respuesta

Respuesta correcta: A. La copia de seguridad que conoce la carga admite copias de registros y PITR.

5. ¿Qué servicio ofrece equilibrio de carga regional de capa 7 con enrutamiento basado en URL, terminación TLS y un WAF opcional?

  1. Azure Load Balancer
  2. Azure Traffic Manager
  3. Azure Application Gateway
  4. Azure NAT Gateway
Ver respuesta

Respuesta correcta: C. Application Gateway es un equilibrador de carga de tráfico web regional.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica AZ-305?

El banco de preguntas tiene 354 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar AZ-305?

El examen oficial de Microsoft AZ-305 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen AZ-305?

Cuatro dominios: diseñar soluciones de identidad, gobernanza y supervisión (25-30%), de almacenamiento de datos (20-25%), de continuidad del negocio (15-20%) y de infraestructura (30-35%).

¿Es gratis el examen de práctica AZ-305?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para AZ-305, no extractos del examen real ni "exam dumps".
