Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 166 para este dominio. Intenta responder antes de ver la solución.

1. Las cuentas de directivos no deben modificarse ni siquiera por Administradores de usuarios de todo el inquilino. ¿Qué debe usar?

  1. Una revisión de acceso del rol Administrador de usuarios
  2. Caja de seguridad del cliente para los directivos
  3. Un grupo dinámico con los puestos directivos
  4. Una unidad administrativa de administración restringida
Ver respuesta

Respuesta correcta: D. En una unidad administrativa de administración restringida solo los administradores asignados a la unidad pueden modificar a sus miembros; los de nivel de inquilino (salvo Administrador global) no.

2. ¿Por qué debe excluir las cuentas de acceso de emergencia de las directivas de acceso condicional?

  1. Para no quedarse sin acceso al inquilino si una directiva se configura mal
  2. Porque las cuentas de emergencia no pueden tener licencia de Entra ID P1
  3. Porque el acceso condicional solo se aplica a invitados
  4. Para que puedan leer cualquier buzón sin aprobación
Ver respuesta

Respuesta correcta: A. Excluir cuentas de emergencia supervisadas evita que una directiva defectuosa (o un fallo de MFA) deje a todos los administradores sin acceso.

3. Los usuarios con dispositivos no administrados pueden leer archivos de SharePoint en el explorador, pero no descargarlos. ¿Qué control de sesión encaja?

  1. Usar restricciones aplicadas por la aplicación
  2. Sesión persistente del explorador en Siempre
  3. Exigir Pase de acceso temporal para SharePoint
  4. Bloquear el acceso a todos los usuarios de SharePoint
Ver respuesta

Respuesta correcta: A. Las restricciones aplicadas por la aplicación permiten que SharePoint y Exchange Online ofrezcan acceso limitado, solo en el explorador (sin descargar, imprimir ni sincronizar), en dispositivos no administrados.

4. Los usuarios deben volver a iniciar sesión cada 8 horas en PC de quiosco compartidos. ¿Qué control de sesión debe usar?

  1. Contexto de autenticación
  2. Restricciones aplicadas por la aplicación
  3. Frecuencia de inicio de sesión
  4. Exigir dispositivo conforme
Ver respuesta

Respuesta correcta: C. La frecuencia de inicio define cuánto tiempo pasa antes de reautenticarse; la sesión persistente controla si la sesión sobrevive al cerrar el explorador.

5. Una simulación debe probar si los usuarios escanean códigos QR que llevan a una página de inicio falsa. ¿Qué técnica encaja?

  1. URL oculta hacia una página de inicio clonada
  2. Robo de credenciales con una carga de código QR
  3. Adjunto con malware
  4. Concesión OAuth con una imagen de código QR
Ver respuesta

Respuesta correcta: B. Las simulaciones de robo de credenciales pueden usar cargas con código QR que llevan a una página falsa; otras técnicas prueban adjuntos, URL ocultas o consentimiento OAuth.

6. Los empleados que fallen una simulación de phishing deben recibir automáticamente un curso breve. ¿Qué debe configurar?

  1. La asignación de formación en la configuración de la simulación
  2. Una etiqueta de retención para quienes pulsaron
  3. Una revisión de acceso de PIM
  4. Un paquete de directivas de Teams para reincidentes
Ver respuesta

Respuesta correcta: A. Las simulaciones pueden asignar módulos de formación de Microsoft (o propios) a quienes pulsan o quedan comprometidos, con fechas límite y recordatorios.

7. ¿Qué característica de Microsoft 365 da protección adicional a los directivos y permite filtrar alertas e informes para ellos?

  1. Protección de cuentas prioritarias
  2. Versión dirigida
  3. Centro de mensajes
  4. Unidades administrativas con administración restringida para directivos
Ver respuesta

Respuesta correcta: A. Las cuentas prioritarias reciben protección diferenciada y se etiquetan en alertas, Explorador e informes de Defender.

8. Antes de desplegar Copilot, quiere que DSPM muestre sitios de SharePoint con archivos confidenciales compartidos ampliamente. ¿Qué debe ejecutar?

  1. Una evaluación de riesgo de datos (uso compartido excesivo)
  2. Un informe de incidentes de Estado del servicio
  3. Un seguimiento de mensajes de los últimos 90 días
  4. Una simulación de ataque de robo de credenciales
Ver respuesta

Respuesta correcta: A. Las evaluaciones de riesgo de datos de DSPM analizan sitios en busca de uso compartido excesivo y recomiendan correcciones como etiquetas, acceso restringido o revisiones.
