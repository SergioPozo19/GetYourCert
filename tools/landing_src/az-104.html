AZ-104 study guide: what's covered and how to prepare

AZ-104 es el examen de administrador de Azure: pregunta cómo configurar cosas, no solo qué son. Espera escenarios con varios requisitos y preguntas sobre qué opción cumple todos con el menor esfuerzo o coste.

AZ-104 is the Azure administrator exam: it asks how to configure things, not just what they are. Expect scenarios with several requirements and questions about which option meets them all with the least effort or cost.

Confusiones típicas en el examen

Common exam traps

Roles de Azure RBAC frente a roles de Microsoft Entra

Azure RBAC roles vs Microsoft Entra roles

Los roles de Azure (Propietario, Colaborador, Lector) dan acceso a recursos como VMs o cuentas de almacenamiento; los roles de Entra (Administrador de usuarios, Administrador global) administran el directorio.

Azure roles (Owner, Contributor, Reader) grant access to resources such as VMs or storage accounts; Entra roles (User Administrator, Global Administrator) manage the directory.

Punto de conexión de servicio frente a punto de conexión privado

Service endpoint vs private endpoint

El de servicio deja el servicio en su IP pública, pero solo acepta tráfico de tu subred; el privado le da una IP privada dentro de tu VNet y sirve también desde local por VPN o ExpressRoute.

A service endpoint keeps the service on its public IP but only accepts traffic from your subnet; a private endpoint gives it a private IP inside your VNet and also works from on-premises over VPN or ExpressRoute.

El emparejamiento no es transitivo

Peering is not transitive

Si A está emparejada con B y B con C, A no llega a C. Necesitas emparejar A con C o pasar el tráfico por una aplicación virtual de red con rutas definidas por el usuario.

If A is peered with B and B with C, A cannot reach C. You need to peer A with C or route traffic through a network virtual appliance with user-defined routes.

Azure Backup frente a Azure Site Recovery

Azure Backup vs Azure Site Recovery

Backup guarda copias para recuperar datos borrados o dañados; Site Recovery replica máquinas a otra región para seguir funcionando si cae la principal.

Backup keeps copies so you can recover deleted or damaged data; Site Recovery replicates machines to another region so you keep running if the primary goes down.
