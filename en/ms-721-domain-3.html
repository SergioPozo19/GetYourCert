Domain 3 sample questions

8 questions from our 153-question bank for this domain. Try to answer before revealing the solution.

1. An administrator wants to prevent users from making international calls from Teams. Which policy should be configured?

  1. A caller ID policy that masks the user's number for outbound calls
  2. An outbound call restriction policy that limits calls to domestic numbers only
  3. A call park policy that redirects international calls to voicemail
  4. A voice routing policy with no international routes
Show answer

Correct answer: B. The outbound call restriction policy in Teams Phone allows controlling what types of calls users can make (e.g., domestic only, prohibit international, etc.).

2. An administrator needs to assign a toll-free phone number to a call queue so customers can call support for free. What additional configuration must be done alongside the toll-free number assignment?

  1. A Direct Routing SBC with toll-free routing
  2. Communication Credits for the tenant
  3. A Teams Phone Standard license for the resource account
  4. An Operator Connect plan with toll-free numbers
Show answer

Correct answer: B. Toll-free numbers require Communication Credits to fund inbound calls. Microsoft covers the cost of calls to toll-free numbers using the credits configured in the tenant.

3. An administrator wants to prevent users from seeing whether their messages have been read by recipients in Teams. Which messaging policy setting should they disable?

  1. Read receipts
  2. Priority notifications
  3. URL previews
  4. Message translation
Show answer

Correct answer: A. The 'Read receipts' setting in the messaging policy controls whether users can see when their messages have been read. It can also be user-configurable if the policy allows it.

4. An administrator wants Teams Phone users to be able to call a 9-digit number starting with 9 (Spanish local phone number) using the tenant dial plan. What type of normalization rule is needed?

  1. A rule that translates the 9-digit number to E.164 format by adding the +34 prefix
  2. A rule that removes the first digit of the 9-digit number
  3. A rule that adds the country code without the + sign at the beginning of the number
  4. A rule that translates the number to the Madrid area code automatically
Show answer

Correct answer: A. To normalize a 9-digit Spanish phone number (like 915551234) to E.164 format (+34915551234), the normalization rule must capture the 9-digit number and add the +34 prefix. For example: pattern ^(9\d{8})$ → translation +34$1.

5. An administrator wants to prevent Teams users from redirecting their calls to external phone numbers outside the organization. Which policy and setting should they modify?

  1. Calling policy: disable 'Allow call forwarding to phone' (AllowCallForwardingToPhone)
  2. Teams policy: disable external call redirection
  3. Messaging policy: block sending messages to external numbers
  4. External access settings: block all external domains
Show answer

Correct answer: A. The AllowCallForwardingToPhone setting in the calling policy controls whether users can configure call forwarding to external phone numbers (PSTN). Disabling it prevents users from forwarding calls outside the Teams network.

6. An organization has a branch office where all PSTN calls must be routed through the local SBC rather than over the internet to Microsoft, due to regulatory requirements that media traffic must stay local. Which Direct Routing feature addresses this?

  1. Survivable Branch Appliance (SBA) for call continuity during internet outages
  2. Location-Based Routing (LBR)
  3. Local Media Optimization (LMO)
  4. On-network conferencing for internal conference calls without going to PSTN
Show answer

Correct answer: B. Location-Based Routing (LBR) prevents PSTN media traffic from bypassing through Microsoft's cloud. It is used when regulations require media to remain on the local network. Local Media Optimization (LMO) optimizes media paths but does not enforce that traffic cannot leave the local network.

7. An administrator needs to configure trunk translation rules in Direct Routing to convert internal extension numbers to E.164 format before sending them to the SBC. Where are these rules configured?

  1. In the user's voice routing policy that defines the allowed outbound PSTN routes
  2. In the trunk (PSTN gateway) configuration in the Teams admin center or via PowerShell
  3. In the tenant dial plan that defines number normalization rules for users
  4. In the user's caller ID policy that controls the number presented to the recipient
Show answer

Correct answer: B. Trunk translation rules are configured in the PSTN gateway (SBC trunk) configuration in the Teams admin center or using the PowerShell cmdlets New-CsTeamsTranslationRule and Set-CsOnlinePSTNGateway.

8. An organization uses Direct Routing and wants media traffic (audio and video) to go directly between the user's Teams client and the SBC, without passing through Microsoft's media servers. Which feature should be configured?

  1. Location-Based Routing (LBR)
  2. Media bypass
  3. Local Media Optimization (LMO)
  4. On-network conferencing
Show answer

Correct answer: B. Media bypass in Direct Routing allows media traffic to go directly between the Teams client and the SBC, bypassing Microsoft's media processors. This reduces latency and bandwidth consumption.
