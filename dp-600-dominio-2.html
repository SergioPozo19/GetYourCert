Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 184 para este dominio. Intenta responder antes de ver la solución.

1. ¿Dónde se descubren y exploran los elementos de datos disponibles en la organización, incluidos los aprobados?

  1. La interfaz de Spark
  2. El punto de conexión XMLA
  3. Una canalización de implementación
  4. Catálogo de OneLake
Ver respuesta

Respuesta correcta: D. El catálogo de OneLake es el centro de descubrimiento.

2. Quieres añadir a una tabla una columna con el margen de beneficio (beneficio dividido entre ingresos) en cada fila, sin cambiar el origen. ¿Cuál es el mejor lugar?

  1. Una asignación de rol del área de trabajo que concede permisos de cálculo
  2. Una vista o una columna personalizada en la capa de transformación
  3. Una regla de la canalización de implementación que agrega la columna en Producción
  4. Una aprobación en la tabla
Ver respuesta

Respuesta correcta: B. Las columnas derivadas se añaden durante la transformación.

3. ¿Qué diseño se recomienda para modelos analíticos en un lakehouse o almacén para el mejor rendimiento y usabilidad de las consultas?

  1. Una tabla por archivo de origen sin claves
  2. Solo relaciones de varios a varios
  3. Un esquema de estrella con tablas de hechos y de dimensiones
  4. Una única tabla de texto muy ancha
Ver respuesta

Respuesta correcta: C. Los esquemas de estrella simplifican combinaciones y agregaciones.

4. Debes conservar solo la fila más reciente por cliente de una tabla con duplicados. ¿Qué patrón de T-SQL es adecuado?

  1. TRUNCATE TABLE en el origen y recargar solo las filas del último día
  2. ROW_NUMBER() OVER (PARTITION BY CustomerId ORDER BY ModifiedDate DESC) = 1
  3. SELECT DISTINCT CustomerId, ModifiedDate FROM la tabla ORDER BY ModifiedDate
  4. SELECT TOP 1 * FROM la tabla ORDER BY ModifiedDate DESC, CustomerId ASC
Ver respuesta

Respuesta correcta: B. Una función de ventana con clasificación identifica el registro más reciente.

5. En Power Query, ¿qué paso elimina las filas duplicadas exactas según las columnas seleccionadas?

  1. Rellenar hacia abajo en la columna clave
  2. Transponer
  3. Anular dinamización de las columnas seleccionadas
  4. Quitar duplicados
Ver respuesta

Respuesta correcta: D. Quitar duplicados conserva una fila por combinación de claves.

6. ¿Qué comando de mantenimiento de tablas Delta compacta muchos archivos pequeños para mejorar el rendimiento de lectura?

  1. SHOW
  2. DESCRIBE
  3. Solo VACUUM
  4. OPTIMIZE
Ver respuesta

Respuesta correcta: D. OPTIMIZE agrupa archivos pequeños.

7. ¿Qué instrucción crea y rellena una tabla nueva del almacén a partir de una consulta en un solo paso?

  1. TRUNCATE TABLE
  2. ALTER TABLE ... ADD COLUMN con un valor predeterminado
  3. INSERT INTO ... VALUES
  4. CREATE TABLE AS SELECT (CTAS)
Ver respuesta

Respuesta correcta: D. CTAS define la tabla a partir del resultado de la consulta y la carga en paralelo.

8. ¿Qué función DAX devuelve el valor de una columna cuando el contexto de filtro tiene un único valor y, si no, un blanco o resultado alternativo?

  1. DISTINCTCOUNT
  2. CONCATENATEX
  3. SELECTEDVALUE
  4. TOTALYTD
Ver respuesta

Respuesta correcta: C. SELECTEDVALUE gestiona selecciones únicas de forma segura.
