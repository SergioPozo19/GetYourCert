Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 116 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué permite marcar una tabla como tabla de fechas?

  1. Ocultar la tabla de la vista del informe
  2. El comportamiento correcto de las funciones de inteligencia de tiempo
  3. Seguridad de nivel de fila automática
  4. Actualización más rápida de todas las tablas
Ver respuesta

Respuesta correcta: B. Una tabla de fechas marcada con fechas continuas permite que funciones como TOTALYTD y SAMEPERIODLASTYEAR funcionen de forma fiable.

2. ¿Qué función quita todos los filtros de una tabla o columna dentro de CALCULATE, por ejemplo para calcular un porcentaje del total?

  1. KEEPFILTERS
  2. ALLSELECTED en el objeto visual
  3. VALUES (o DISTINCT)
  4. ALL (o REMOVEFILTERS)
Ver respuesta

Respuesta correcta: D. ALL borra los filtros de la tabla o las columnas especificadas.

3. ¿Qué función devuelve las primeras N filas de una tabla ordenadas por una expresión, como los 5 mejores productos por ventas?

  1. TOPN
  2. Solo SAMPLE
  3. FIRSTNONBLANK
  4. EARLIER
Ver respuesta

Respuesta correcta: A. TOPN devuelve una tabla.

4. Una medida debe devolver 0 en lugar de blanco cuando no hay ventas. ¿Qué función es la más concisa?

  1. DIVIDE([Sales], 1, 0) usada como envoltorio de la medida
  2. COALESCE([Sales], 0)
  3. BLANK()
  4. IFERROR([Sales], 0)
Ver respuesta

Respuesta correcta: B. COALESCE devuelve el primer argumento que no está en blanco.

5. Una columna DateTime tiene una cardinalidad alta por las marcas de tiempo y solo se usa por fecha. ¿Cómo puedes mejorar la compresión?

  1. Duplicar la columna en la tabla de hechos y ocultar la original
  2. Dividir en columnas de fecha y hora o conservar solo la fecha
  3. Convertir la columna a texto
  4. Conservar los milisegundos por precisión y ordenar la columna
Ver respuesta

Respuesta correcta: B. Reducir la granularidad reduce la cardinalidad.

6. ¿Qué herramienta ayuda a encontrar objetos visuales lentos y ver las duraciones de las consultas DAX?

  1. Analizador de rendimiento
  2. Panel de selección
  3. Temas
  4. Panel de marcadores
Ver respuesta

Respuesta correcta: A. El Analizador de rendimiento registra los tiempos de carga de los objetos visuales.

7. ¿Qué enfoque DAX suele ser más eficiente que iterar por filas una tabla grande?

  1. Anidar varias funciones FILTER
  2. Usar agregadores por conjuntos y variables
  3. Usar columnas calculadas para cada métrica
  4. Convertir primero las medidas a texto
Ver respuesta

Respuesta correcta: B. Las variables evitan recalcular expresiones y los agregadores aprovechan el motor de almacenamiento.

8. Una tabla grande de importación con actualización incremental también debe mostrar las transacciones de hoy en tiempo real. ¿Qué debes habilitar?

  1. Actualización automática de página en un modelo solo de importación
  2. Obtener los datos más recientes en tiempo real con DirectQuery (tabla híbrida)
  3. Deshabilitar la actualización incremental y actualizar toda la tabla cada 30 minutos
  4. Fecha y hora automáticas
Ver respuesta

Respuesta correcta: B. Las tablas híbridas mantienen importadas las particiones históricas y agregan una partición DirectQuery con los datos más recientes.
