AB-650 sample questions

Five real questions from our 303-question bank. Try to answer before revealing the solution.

1. What do you need before you can protect SharePoint sites, OneDrive accounts and Exchange mailboxes with Microsoft 365 Backup?

  1. Pay-as-you-go billing set up for Microsoft 365 Backup
  2. A third-party backup app approved in the App Store
  3. A retention policy that keeps all content for 10 years
  4. An Azure Backup vault in the same region as the tenant
Show answer

Correct answer: A. Microsoft 365 Backup is a pay-as-you-go service: you first connect billing to an Azure subscription, then turn on Backup and create backup policies.

2. Network connectivity insights show no data for your branch offices. What should you do first?

  1. Open the Service health page and subscribe to advisories
  2. Enable location data collection and add office locations
  3. Create a Conditional Access named location per office
  4. Assign a Teams Phone license to each branch office user
Show answer

Correct answer: B. Insights require office locations (added manually or discovered) and permission to collect location data from Windows devices or the connectivity test.

3. An item is subject to a 3-year retention policy and a 7-year retention label, both retaining content. How long is it kept?

  1. 10 years, because the periods are added together
  2. 3 years, because policies override labels
  3. It depends on which one was created first
  4. 7 years, because the longest retention period wins
Show answer

Correct answer: D. Under the principles of retention, retention wins over deletion and the longest retention period wins.

4. Many agents created from the same design must share owners, sponsors and access settings. What should you use in Entra Agent ID?

  1. A shared mailbox per agent family
  2. An agent identity blueprint
  3. A custom Teams policy package
  4. A dynamic distribution list
Show answer

Correct answer: B. An agent identity blueprint is a reusable template that standardizes how agent identities are created and governed (owners, sponsors, access, lifecycle).

5. Makers in Copilot Studio are sharing agents with the whole company. How can you limit sharing to small groups?

  1. Disable web search for Copilot in the cloud policy
  2. Assign the makers the Global Reader role only
  3. Set environment sharing limits in Power Platform
  4. Block the agents' URLs in the Tenant Allow/Block List
Show answer

Correct answer: C. Copilot Studio sharing controls (Editor and Viewer roles, sharing limits) are set at the managed environment or environment group level in the Power Platform admin center.
