MD-102 · Dominio 4 de 5 · 15-20% del examen

Proteger dispositivos

El dominio 4 de MD-102 supone entre el 15 y el 20% del examen. En EarnYourCert tienes 145 preguntas originales de este dominio, todas con explicación: 97 de opción múltiple, 22 de sí o no y 26 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 4

8 preguntas de nuestro banco de 145 para este dominio. Intenta responder antes de ver la solución.

1. Quieres crear una directiva de antivirus en Intune para dispositivos Windows que configure Microsoft Defender Antivirus. ¿Dónde debes crearla en el portal de Intune?

  1. Dispositivos > Directivas de cumplimiento
  2. Seguridad de puntos de conexión > Antivirus
  3. Configuración de dispositivos > Perfiles
  4. Aplicaciones > Directivas de configuración de aplicaciones
Ver respuesta

Respuesta correcta: B. Las directivas de antivirus se crean en Seguridad de puntos de conexión > Antivirus en el portal de Intune. Permiten configurar Microsoft Defender Antivirus con opciones específicas de seguridad.

2. ¿Qué directiva de seguridad de puntos de conexión en Intune permite configurar el Firewall de Windows Defender, incluyendo reglas de entrada y salida específicas para aplicaciones y puertos?

  1. Directiva de antivirus > Microsoft Defender Antivirus
  2. Directiva de firewall en Seguridad de puntos de conexión
  3. Perfil de configuración de dispositivos > Restricciones de dispositivos
  4. Línea base de seguridad de Windows
Ver respuesta

Respuesta correcta: B. Las directivas de Firewall en Seguridad de puntos de conexión de Intune permiten configurar el Firewall de Windows Defender, incluyendo habilitación por perfil de red y reglas personalizadas de entrada y salida.

3. ¿Qué tipo de directiva de seguridad de puntos de conexión en Intune debes crear para configurar el cifrado BitLocker en dispositivos Windows y almacenar automáticamente las claves de recuperación en Microsoft Entra ID?

  1. Directiva de antivirus en Seguridad de puntos de conexión
  2. Directiva de cifrado de disco en Seguridad de puntos de conexión
  3. Perfil de configuración de dispositivos con tipo Endpoint Protection
  4. Línea base de seguridad de Windows
Ver respuesta

Respuesta correcta: B. Las directivas de cifrado de disco en Seguridad de puntos de conexión permiten configurar BitLocker para Windows con opciones como cifrado solo del espacio usado, método de cifrado y copia de seguridad de claves en Entra ID.

4. ¿Qué información proporciona la puntuación de seguridad de Microsoft (Microsoft Secure Score) en relación con Intune?

  1. La puntuación de cumplimiento de los dispositivos administrados por Intune con el estado detallado de cada directiva de seguridad aplicada
  2. Una puntuación que mide la postura de seguridad de la organización con recomendaciones de mejora que incluyen acciones de Intune
  3. El porcentaje exacto de dispositivos con antivirus actualizado a la última versión disponible según los informes de cumplimiento de Intune
  4. El número total de incidentes de seguridad activos detectados por Microsoft Defender for Endpoint en dispositivos gestionados con Intune
Ver respuesta

Respuesta correcta: B. Microsoft Secure Score mide la postura de seguridad global de la organización e incluye recomendaciones de Intune como 'Habilitar BitLocker', 'Configurar directivas de cumplimiento', etc., con su impacto en la puntuación.

5. ¿Cuántos niveles de riesgo de dispositivo define la integración de Microsoft Defender para punto de conexión con las directivas de cumplimiento de Intune?

  1. Dos: conforme y no conforme
  2. Tres: bajo, medio y alto
  3. Cuatro: ninguno, bajo, medio y alto
  4. Cinco: ninguno, informativo, bajo, medio y alto
Ver respuesta

Respuesta correcta: C. La integración MDE-Intune define cuatro niveles de riesgo del dispositivo: Ninguno (sin amenazas), Bajo, Medio y Alto. En la directiva de cumplimiento de Intune defines el nivel máximo aceptable.

6. ¿Qué función de Intune permite planificar y supervisar el estado de las actualizaciones de Windows en toda la organización, incluyendo el porcentaje de dispositivos actualizados y los errores de instalación?

  1. El panel de cumplimiento de Intune con información de estado de directivas de actualización de dispositivos
  2. Informes de actualizaciones de Windows en el portal de Intune (Informes > Actualizaciones de Windows)
  3. El Centro de mensajes de Microsoft 365 con anuncios de actualizaciones de seguridad de Windows
  4. El Catálogo de Microsoft Update con historial de aprobaciones de actualizaciones de calidad
Ver respuesta

Respuesta correcta: B. El portal de Intune incluye informes detallados sobre el estado de las actualizaciones de Windows, mostrando qué dispositivos están actualizados, cuáles tienen errores y el progreso de despliegue por anillo.

7. ¿Qué informes de Intune permiten ver el porcentaje de dispositivos actualizados correctamente dentro de cada anillo de actualización de Windows?

  1. Informes de cumplimiento de dispositivos en la sección de Cumplimiento de dispositivos del portal de Intune
  2. Informes de actualización de Windows en Informes > Actualizaciones de Windows de Intune
  3. Informes de configuración de aplicaciones en la sección de aplicaciones del portal de Intune
  4. El portal de análisis de puntos de conexión (Endpoint Analytics) en la sección de Informes de Intune
Ver respuesta

Respuesta correcta: B. Los informes de Windows Update en Intune (Informes > Actualizaciones de Windows) muestran el estado de actualización de los dispositivos, incluyendo el porcentaje actualizado, errores y dispositivos pendientes por anillo.

8. ¿Qué herramienta puede usar un administrador para verificar el estado actual de Delivery Optimization en un dispositivo Windows y ver estadísticas de descargas P2P vs. CDN?

  1. Microsoft Intune Reports > Actualizaciones de Windows > Optimización de distribución, en la sección de informes del portal
  2. La aplicación "Optimización de distribución" en el Panel de control de Windows, sección de red avanzada
  3. El cmdlet de PowerShell Get-DeliveryOptimizationStatus o el panel de configuración de Windows > Actualizaciones
  4. Microsoft Defender para punto de conexión > Informes de red > Tráfico de Optimización de distribución
Ver respuesta

Respuesta correcta: C. El cmdlet Get-DeliveryOptimizationStatus en PowerShell proporciona estadísticas detalladas de DO en el dispositivo. El panel de Windows > Actualizaciones también muestra estadísticas básicas de DO.
