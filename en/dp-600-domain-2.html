8 questions from our 184-question bank for this domain. Try to answer before revealing the solution.

1. Where do you discover and browse available data items across the organization, including endorsed items?

  1. The Spark UI
  2. The XMLA endpoint
  3. A deployment pipeline
  4. OneLake catalog
Show answer

Correct answer: D. The OneLake catalog is the discovery hub.

2. You want to add a column to a table that shows the profit margin (profit divided by revenue) for every row, without changing the source. Where is the best place?

  1. A workspace role assignment that grants calculation rights
  2. A view or a custom column in the transformation layer
  3. A deployment pipeline rule that adds the column in Production
  4. An endorsement on the table
Show answer

Correct answer: B. Derived columns are added during transformation.

3. Which design is recommended for analytical models in a lakehouse or warehouse for best query performance and usability?

  1. One table per source file with no keys
  2. Only many-to-many relationships
  3. A star schema with fact and dimension tables
  4. A single very wide text table
Show answer

Correct answer: C. Star schemas simplify joins and aggregations.

4. You must keep only the most recent row per customer from a table with duplicates. Which T-SQL pattern is appropriate?

  1. TRUNCATE TABLE on the source and reload only the rows from the last day
  2. ROW_NUMBER() OVER (PARTITION BY CustomerId ORDER BY ModifiedDate DESC) = 1
  3. SELECT DISTINCT CustomerId, ModifiedDate FROM the table ORDER BY ModifiedDate
  4. SELECT TOP 1 * FROM the table ORDER BY ModifiedDate DESC, CustomerId ASC
Show answer

Correct answer: B. A ranked window function identifies the latest record.

5. In Power Query, which step removes rows that are exact duplicates based on selected columns?

  1. Fill down on the key column
  2. Transpose
  3. Unpivot the selected columns
  4. Remove duplicates
Show answer

Correct answer: D. Remove duplicates keeps one row per key combination.

6. Which Delta table maintenance command compacts many small files to improve read performance?

  1. SHOW
  2. DESCRIBE
  3. VACUUM only
  4. OPTIMIZE
Show answer

Correct answer: D. OPTIMIZE bin-packs small files.

7. Which statement creates and fills a new warehouse table from a query in one step?

  1. TRUNCATE TABLE
  2. ALTER TABLE ... ADD COLUMN with a default value
  3. INSERT INTO ... VALUES
  4. CREATE TABLE AS SELECT (CTAS)
Show answer

Correct answer: D. CTAS defines the table from the query result and loads it in parallel.

8. Which DAX function returns the value of a column when the filter context has a single value, otherwise a blank or alternate result?

  1. DISTINCTCOUNT
  2. CONCATENATEX
  3. SELECTEDVALUE
  4. TOTALYTD
Show answer

Correct answer: C. SELECTEDVALUE handles single selections safely.
