Domain 1 sample questions

8 questions from our 118-question bank for this domain. Try to answer before revealing the solution.

1. A meeting organizer needs attendees to be able to join by dialing a phone number because they have no internet access. What must the administrator assign to the organizer?

  1. A Teams Phone Standard license with PSTN connectivity enabled
  2. An Audio Conferencing license
  3. A Direct Routing voice routing policy configured with a voice route
  4. A Teams Rooms Pro license with conferencing bridge included
Show answer

Correct answer: B. The Audio Conferencing license assigned to the meeting organizer is what provides the dial-in number that appears in the invitation. Without it, attendees cannot dial in.

2. An organization needs to implement emergency calling so that when a Teams Phone user at the Madrid office dials 112, emergency services receive the Madrid address. Which feature must the administrator configure?

  1. A call park policy with emergency override
  2. Location Information Service (LIS) with network topology mappings
  3. An auto attendant that routes 112 calls to a dedicated queue
  4. A voice routing policy with a 112 route
Show answer

Correct answer: B. The Location Information Service (LIS) maps network identifiers (subnets, Wi-Fi access points) to verified emergency locations. When a user calls 112 from that network, the correct address is transmitted to emergency services.

3. A company has Teams users in several European countries. They want emergency calls from each country to use local emergency services. Which Teams Phone technology manages mapping network locations to local emergency services?

  1. Location-Based Routing (LBR) to prevent toll bypass on international calls
  2. Location Information Service (LIS) with emergency calling policies per location
  3. Voice routing policy with separate PSTN routes configured for each European country
  4. Local dial plans configured per country to normalize emergency numbers
Show answer

Correct answer: B. The Location Information Service (LIS) in Teams Phone allows mapping subnets, WiFi access points, and switches to physical locations. Emergency calling policies assign each location the corresponding local PSAP (public safety answering point) for the country.

4. Which feature allows supervisors to manage call queue agents from the Teams client and requires Teams Premium licensing?

  1. The Queues app
  2. Call park
  3. Cloud video interop
  4. Teams casting
Show answer

Correct answer: A. The Queues app lets authorized leads opt agents in or out and view queue metrics.

5. An administrator needs to deploy third-party SIP desk phones (not certified for Teams) to work with Teams Phone. Which solution allows using these existing devices?

  1. Cloud Video Interop (CVI)
  2. SIP Gateway
  3. Direct Guest Join
  4. Teams Rooms on Android
Show answer

Correct answer: B. SIP Gateway allows compatible SIP phones (not natively certified for Teams) to register with Teams Phone through Microsoft's infrastructure. Not all SIP devices are compatible; Microsoft publishes the list of supported devices.

6. An administrator needs to upload building and subnet data so the Call Quality Dashboard (CQD) can show call quality reports filtered by office location. Where should this data be uploaded?

  1. Microsoft Defender portal — Secure Score and network threat assessment
  2. Teams admin center — Analytics & Reports — Call Quality Dashboard — Tenant Data Upload
  3. Microsoft Purview — Data connectors for importing network activity log data
  4. Entra admin center — Identity governance and periodic access reviews
Show answer

Correct answer: B. Building and subnet data is uploaded to CQD through the Tenant Data Upload section of the Teams admin center. This allows filtering call quality reports by physical location.

7. What is the key difference between the Call Quality Dashboard (CQD) and per-user call analytics in Teams?

  1. CQD is exclusively for Teams Phone and per-user analytics is dedicated only to Teams meetings
  2. CQD shows aggregated quality trends for the entire organization; per-user analytics shows individual sessions for one user
  3. CQD requires an E5 license to access and per-user analytics is available free without additional license
  4. CQD provides real-time quality data and per-user analytics shows only historical data from past sessions
Show answer

Correct answer: B. CQD is for aggregated quality analysis at organizational scale (thousands of calls) to identify trends and systemic issues. Per-user analytics is for investigating specific problems of a particular user, seeing their individual sessions with detailed metrics.

8. An administrator wants to use CQD to identify quality issues related to a specific company Wi-Fi network. What data must be uploaded to CQD to enable filtering by Wi-Fi network name?

  1. The Direct Routing network topology file with FQDNs and IP addresses of the SBCs
  2. The building data file that includes mapping of Wi-Fi access points to buildings
  3. The DHCP server logs exported from the building server with per-device IP assignments
  4. The building's network switch configuration file with VLAN and port definitions
Show answer

Correct answer: B. The CQD building data file can include mappings of subnets and Wi-Fi access points to buildings and floors. When uploaded, CQD can segment quality data by connection type (wired vs Wi-Fi) and by access point or building.
