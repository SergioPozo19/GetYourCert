Administrar un entorno de operaciones de seguridad

Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 170 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué hace la interrupción automática de ataques cuando detecta un ataque de ransomware de alta confianza?

  1. Espera a que un analista apruebe cada acción de contención antes de actuar
  2. Solo crea un informe para la revisión mensual
  3. Contiene los activos afectados, por ejemplo aislando dispositivos
  4. Envía un correo de alerta al SOC sin realizar ninguna acción de contención
Ver respuesta

Respuesta correcta: C. La interrupción actúa a velocidad de máquina para detener el avance del ataque.

2. ¿Qué acciones puede realizar una regla de automatización de Sentinel sin un cuaderno de estrategias?

  1. Asignar un propietario, cambiar el estado o la gravedad y agregar etiquetas o tareas
  2. Reinstalar un dispositivo de forma remota y restaurarlo desde la última copia
  3. Aislar un dispositivo de la red y recopilar un paquete de investigación
  4. Rotar un certificado
Ver respuesta

Respuesta correcta: A. Las reglas también pueden ejecutar cuadernos de estrategias para acciones más complejas.

3. Varias reglas de automatización se aplican al mismo incidente. ¿Cómo se determina su orden de ejecución?

  1. Por la hora de creación del incidente
  2. Alfabéticamente por nombre de regla
  3. Por el analista que creó la regla
  4. Por el número de orden asignado a cada regla
Ver respuesta

Respuesta correcta: D. Las reglas se ejecutan en orden ascendente salvo que una regla detenga el procesamiento.

4. ¿Qué rol es adecuado para un responsable del SOC que necesita ver todos los datos de Sentinel pero no debe cambiar nada?

  1. Propietario
  2. Administrador de acceso de usuario
  3. Lector de Microsoft Sentinel
  4. Colaborador de Microsoft Sentinel
Ver respuesta

Respuesta correcta: C. Lector proporciona acceso de solo lectura a los datos de Sentinel.

5. ¿Qué controla qué eventos y campos recopila el Azure Monitor Agent y adónde los envía?

  1. Una regla de recopilación de datos (DCR)
  2. Una etiqueta de retención
  3. Una directiva de acceso condicional
  4. Una directiva de nomenclatura
Ver respuesta

Respuesta correcta: A. Las DCR definen orígenes, filtros, transformaciones y destinos.

6. ¿Qué ocurre con los indicadores de amenazas en Sentinel cuando pasa su fecha de caducidad?

  1. Se eliminan del área de trabajo de inmediato
  2. Su puntuación de confianza se duplica
  3. Dejan de considerarse activos para la coincidencia
  4. Se exportan al portal de Defender como incidentes
Ver respuesta

Respuesta correcta: C. Los indicadores caducados no se usan en las detecciones.

7. ¿Cuál es el propósito de la asignación de entidades en una regla de análisis de Sentinel?

  1. Para facturar a cada analista el tiempo de consulta que usa la regla
  2. Para eliminar datos de eventos de más de 90 días de las tablas de origen
  3. Para cambiar el nombre de las tablas del área de trabajo
  4. Para identificar usuarios, hosts e IP y así poder correlacionar alertas
Ver respuesta

Respuesta correcta: D. Las entidades impulsan el gráfico de investigación y la agrupación de incidentes.

8. ¿Qué opción de frecuencia de una regla de detección personalizada de Defender XDR comprueba los datos de forma continua?

  1. Continua (NRT)
  2. Cada año
  3. Solo manual
  4. Cada 30 días
Ver respuesta

Respuesta correcta: A. Otras opciones incluyen cada 1, 3, 12 o 24 horas.
