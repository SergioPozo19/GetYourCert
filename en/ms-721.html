MS-721 sample questions

Five real questions from our 449-question bank. Try to answer before revealing the solution.

1. A company in a country without Microsoft Calling Plans wants to keep its current carrier. Which design supports this with minimal on-premises equipment?

  1. Operator Connect
  2. Microsoft Calling Plan
  3. Teams Rooms Basic
  4. Audio Conferencing only
Show answer

Correct answer: A. Operator Connect lets operators provide PSTN connectivity directly managed from Teams admin center.

2. Where are files shared in a Teams private channel stored?

  1. In a separate SharePoint site collection created specifically for that private channel
  2. In the same document library as the parent team's SharePoint site
  3. In the private channel owner's OneDrive
  4. In Teams' encrypted storage, separate from SharePoint
Show answer

Correct answer: A. Each Teams private channel automatically creates its own independent SharePoint site collection with its own storage space and permissions, separate from the parent team's SharePoint site.

3. An administrator is configuring call queue routing. They want calls distributed so that the agent who has gone longest without receiving a call is the first to receive the next one. Which routing method should be selected?

  1. Round robin, which distributes calls in rotation among all available agents
  2. Attendant routing, which rings all available agents at the same time simultaneously
  3. Serial, which always tries the first agent on the list before moving to the next
  4. Longest idle
Show answer

Correct answer: D. The 'Longest idle' routing method routes the next call to the agent who has been inactive the longest. Round robin distributes evenly; Serial calls agents in fixed order; Attendant rings all simultaneously.

4. In a Direct Routing deployment, the administrator must configure emergency call routing separately. Why are emergency call routing policies specific to Direct Routing?

  1. Because Microsoft Calling Plans do not support emergency calls to the 112 number in any country
  2. Because in Direct Routing the administrator manages PSTN routing, including the route to the emergency number
  3. Because emergency call routing policies are completely disabled for Operator Connect deployments
  4. Because the Location Information Service (LIS) is only compatible with Direct Routing deployments
Show answer

Correct answer: B. With Microsoft Calling Plans, emergency routing is managed automatically by Microsoft. With Direct Routing, the administrator controls all PSTN routing, including the specific route for emergency numbers (112, 911, etc.), so they need to configure emergency routing policies.

5. An administrator wants to prevent Teams users from sending feedback to Microsoft via the 'Give feedback' button in Teams. What should they configure?

  1. Disable the feedback option in the Microsoft 365 feedback policy (Microsoft feedback policy)
  2. Create a messaging policy that blocks the feedback button
  3. Disable external access in the Teams admin center
  4. Configure an Information Barrier to block communication with Microsoft
Show answer

Correct answer: A. The Microsoft 365 feedback policy (configurable in the Microsoft 365 admin center > Settings > Org settings > Microsoft feedback) allows administrators to control whether users can send feedback, suggestions, or diagnostic data to Microsoft from Teams and other Microsoft 365 apps.
