El dominio 3 de PL-300 supone entre el 25 y el 30% del examen. En EarnYourCert tienes 106 preguntas originales de este dominio, todas con explicación: 72 de opción múltiple, 16 de sí o no y 18 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 106 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué son los cálculos visuales en Power BI?

  1. Flujos de datos que preparan y limpian los datos antes de cargar
  2. Cálculos DAX definidos directamente sobre un objeto visual
  3. Temas de informe aplicados a todas las páginas
  4. Marcadores que guardan el estado de los objetos visuales de una página
Ver respuesta

Respuesta correcta: B. Los cálculos visuales simplifican los totales acumulados y las medias móviles.

2. ¿Qué panel permite reordenar, ocultar y agrupar objetos visuales y establecer las capas?

  1. Panel Filtros
  2. Panel Campos
  3. Preguntas y respuestas
  4. Panel Selección
Ver respuesta

Respuesta correcta: D. El panel Selección controla la visibilidad y el orden.

3. ¿Qué característica adapta una página de informe para que se vea bien en un teléfono?

  1. Diseño de teléfono
  2. Un tema de informe
  3. Un ajuste de tamaño de página 16:9
  4. Una suscripción a la aplicación móvil
Ver respuesta

Respuesta correcta: A. El diseño móvil organiza los objetos visuales para pantallas pequeñas.

4. ¿Qué filtro mantiene un objeto visual mostrando solo los últimos 30 días de forma dinámica al actualizar el informe?

  1. Filtro de N superiores por valor de fecha
  2. Filtro básico con las fechas de hoy
  3. Filtro de fecha relativa
  4. Filtro avanzado es igual o posterior a
Ver respuesta

Respuesta correcta: C. Los filtros de fecha relativa se mueven con la fecha de hoy.

5. ¿Qué panel permite controlar el orden de los objetos visuales y ocultarlos o mostrarlos en un informe?

  1. Panel de selección
  2. Panel de campos
  3. Solo panel de datos
  4. Temas
Ver respuesta

Respuesta correcta: A. El panel de selección gestiona las capas y la visibilidad.

6. ¿Qué opción de formato colorea las celdas de una tabla en un degradado según sus valores?

  1. Un marcador con selecciones
  2. Un tema de informe con una paleta de sentimiento
  3. Una página de información con tarjetas de color
  4. Formato condicional con una escala de color
Ver respuesta

Respuesta correcta: D. Las escalas de color sombrean los valores en un degradado.

7. Una fila de botones debe enumerar automáticamente todas las páginas del informe y actualizarse cuando se agreguen páginas. ¿Qué debes usar?

  1. Obtención de detalles
  2. Botones individuales con acciones de navegación a cada página
  3. Navegador de páginas
  4. Navegador de marcadores
Ver respuesta

Respuesta correcta: C. El navegador de páginas crea un botón por cada página visible automáticamente.

8. ¿Qué objeto visual escribe automáticamente texto que resume hallazgos clave y se actualiza con los filtros?

  1. Gráfico de dispersión
  2. Objeto visual de P y R
  3. Narrativa inteligente
  4. Detección de anomalías
Ver respuesta

Respuesta correcta: C. La narrativa inteligente genera texto dinámico y puede personalizarse con valores dinámicos.
