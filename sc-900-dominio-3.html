SC-900 · Dominio 3 de 4 · 35-40% del examen

Describir las funcionalidades de las soluciones de seguridad de Microsoft

El dominio 3 de SC-900 supone entre el 35 y el 40% del examen, el de más peso del temario. En EarnYourCert tienes 131 preguntas originales de este dominio, todas con explicación: 79 de opción múltiple, 17 de sí o no y 35 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 131 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué permite hacer Azure Private Link?

  1. Cifrar el correo en tránsito entre Exchange Online y servidores de correo externos
  2. Acceder a servicios PaaS de Azure mediante un punto de conexión privado en tu red virtual
  3. Crear un sitio web público para una aplicación PaaS con dominio personalizado y TLS
  4. Sustituir por completo Azure Firewall
Ver respuesta

Respuesta correcta: B. Un punto de conexión privado asigna a tu red virtual una dirección IP privada del servicio.

2. ¿Cuál es un beneficio de Azure Front Door con WAF para una aplicación web global?

  1. Equilibrio de carga global con protección perimetral frente a ataques web
  2. Sustituye a Microsoft Entra ID para el inicio de sesión de los usuarios
  3. Administra licencias de usuario globalmente
  4. Almacena los secretos y certificados de la aplicación web en un almacén global
Ver respuesta

Respuesta correcta: A. Front Door es un punto de entrada global; WAF filtra las solicitudes maliciosas.

3. ¿Qué plan de Defender for Cloud ofrece protección frente a amenazas para máquinas virtuales y servidores, incluida la integración de detección y respuesta en el endpoint?

  1. Defender for Servers
  2. Defender for Key Vault
  3. Defender for Storage
  4. Solo Defender for DNS
Ver respuesta

Respuesta correcta: A. Defender for Servers integra Defender for Endpoint y la evaluación de vulnerabilidades.

4. En Microsoft Sentinel, ¿qué agrupa alertas relacionadas en un único elemento accionable que un analista puede investigar?

  1. Un incidente
  2. Un libro
  3. Una lista de seguimiento
  4. Un conector de datos
Ver respuesta

Respuesta correcta: A. Los incidentes agregan alertas y entidades para que los analistas puedan investigar y responder en conjunto.

5. ¿Dónde pueden los equipos de seguridad usar Microsoft Sentinel junto con Defender XDR en una única experiencia unificada de operaciones de seguridad?

  1. El centro de administración de Microsoft 365
  2. El portal de Microsoft Defender
  3. El centro de administración de Intune
  4. La página de informes de cumplimiento del Portal de confianza de servicios
Ver respuesta

Respuesta correcta: B. Sentinel se incorpora al portal de Defender para que incidentes, búsqueda y automatización funcionen en ambos.

6. ¿Qué producto de Defender es un agente de seguridad de acceso a la nube (CASB) que ofrece visibilidad y control sobre las aplicaciones en la nube y la TI en la sombra?

  1. Microsoft Sentinel
  2. Microsoft Defender for Office 365
  3. Microsoft Defender for Cloud Apps
  4. Microsoft Defender for Endpoint
Ver respuesta

Respuesta correcta: C. Defender for Cloud Apps descubre las aplicaciones en uso, aplica directivas y protege los datos en aplicaciones SaaS.

7. ¿Qué capacidad de Defender for Office 365 permite a los equipos de seguridad ejecutar campañas de phishing realistas para formar a los usuarios?

  1. Solo el explorador de amenazas
  2. Formación con simulación de ataques
  3. Revisiones de acceso
  4. Etiquetas de retención
Ver respuesta

Respuesta correcta: B. La formación con simulación de ataques ayuda a medir y mejorar la resistencia de los usuarios al phishing.

8. Un analista quiere contexto sobre una dirección IP vista en una alerta, como actores de amenazas e infraestructura relacionados. ¿Qué solución lo proporciona?

  1. Informes del explorador de actividad de Purview
  2. Paneles de telemetría de Azure DDoS Protection
  3. Historial de revisiones de acceso de Entra
  4. Microsoft Defender Threat Intelligence
Ver respuesta

Respuesta correcta: D. Microsoft Defender Threat Intelligence ofrece a los analistas inteligencia sobre indicadores como IP y dominios, incluidos actores de amenazas, infraestructura y artículos relacionados.
