SC-900 · Dominio 2 de 4 · 25-30% del examen

Describir las funcionalidades de Microsoft Entra

El dominio 2 de SC-900 supone entre el 25 y el 30% del examen. En EarnYourCert tienes 114 preguntas originales de este dominio, todas con explicación: 73 de opción múltiple, 15 de sí o no y 26 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 114 para este dominio. Intenta responder antes de ver la solución.

1. Un empleado trabaja en remoto e inicia sesión desde un portátil personal no administrado por la organización. ¿Qué concepto de Microsoft Entra permite a la empresa reconocer y controlar este dispositivo en las decisiones de acceso?

  1. Un usuario invitado
  2. Microsoft Entra Domain Services
  3. Una unidad administrativa
  4. Dispositivo registrado en Microsoft Entra
Ver respuesta

Respuesta correcta: D. Los dispositivos registrados representan dispositivos personales que acceden a recursos de la organización.

2. ¿Qué característica permite a los usuarios restablecer sus propias contraseñas olvidadas sin llamar al servicio de asistencia?

  1. Revisiones de acceso
  2. Privileged Identity Management
  3. Restablecimiento de contraseña por autoservicio (SSPR)
  4. Acceso condicional
Ver respuesta

Respuesta correcta: C. SSPR permite que los usuarios verifiquen su identidad con métodos registrados y restablezcan su propia contraseña.

3. ¿Qué afirmación sobre las passkeys es correcta?

  1. Las passkeys solo funcionan sin conexión
  2. Las passkeys usan criptografía de clave pública, por lo que no hay un secreto compartido que se pueda suplantar mediante phishing
  3. Las passkeys almacenan la contraseña del usuario en texto sin formato
  4. Las passkeys son lo mismo que las preguntas de seguridad
Ver respuesta

Respuesta correcta: B. Las passkeys vinculan las credenciales a la parte de confianza y resisten el phishing.

4. ¿Qué método de autenticación es un dispositivo físico USB o NFC que ofrece un inicio de sesión sin contraseña resistente al phishing?

  1. Llave de seguridad FIDO2
  2. Preguntas de seguridad respondidas durante el restablecimiento de contraseña
  3. Código de verificación por SMS
  4. Llamada de voz
Ver respuesta

Respuesta correcta: A. Las llaves de seguridad FIDO2 contienen una clave de acceso vinculada al sitio, así que no se pueden obtener mediante phishing.

5. Un empleado nuevo aún no tiene credenciales y debe registrar una clave de acceso el primer día. ¿Qué método le permite iniciar sesión durante un tiempo limitado?

  1. Valores predeterminados de seguridad
  2. Bloqueo inteligente
  3. Una contraseña permanente compartida por el equipo de soporte
  4. Pase de acceso temporal
Ver respuesta

Respuesta correcta: D. El pase de acceso temporal es un código de tiempo limitado para incorporar o recuperar métodos sin contraseña.

6. ¿Qué rol asignarías a un administrador que solo necesita restablecer contraseñas de usuarios no administradores?

  1. Administrador global
  2. Administrador de roles con privilegios
  3. Administrador de seguridad
  4. Administrador del departamento de soporte técnico
Ver respuesta

Respuesta correcta: D. Privilegios mínimos: el Administrador de soporte técnico puede restablecer contraseñas de usuarios no administradores sin control total del inquilino.

7. ¿Qué capacidad permite a Microsoft Entra ID revocar el acceso casi en tiempo real, por ejemplo cuando se deshabilita un usuario, en lugar de esperar a que caduque el token?

  1. Sincronización de hash de contraseñas cada dos minutos
  2. Evaluación continua de acceso
  3. Modo solo informe
  4. Revisiones de acceso
Ver respuesta

Respuesta correcta: B. La evaluación continua de acceso permite a los servicios compatibles reaccionar a eventos críticos como la deshabilitación de la cuenta o el cambio de ubicación.

8. ¿Qué ayudan a hacer las revisiones de acceso de Microsoft Entra ID Governance a una organización?

  1. Verificar periódicamente que los usuarios siguen necesitando acceso a grupos, aplicaciones y roles
  2. Detectar inicios de sesión de riesgo con aprendizaje automático
  3. Crear cuentas de usuario automáticamente a partir de datos de RR. HH.
  4. Cifrar los datos almacenados en sitios de SharePoint
Ver respuesta

Respuesta correcta: A. Las revisiones de acceso eliminan el acceso innecesario y ayudan a evitar la acumulación de permisos.
