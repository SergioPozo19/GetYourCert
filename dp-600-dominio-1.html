Preguntas de ejemplo del dominio 1

8 preguntas de nuestro banco de 102 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué permiso de elemento permite a un usuario leer los archivos y tablas Delta subyacentes de un lakehouse mediante OneLake, por ejemplo con Spark?

  1. Volver a compartir
  2. Compilar
  3. ReadData
  4. ReadAll
Ver respuesta

Respuesta correcta: D. ReadAll da acceso a los datos de OneLake; ReadData solo da acceso SQL.

2. ¿Qué servicio de Microsoft proporciona las etiquetas de confidencialidad que se pueden aplicar a los elementos de Fabric?

  1. Microsoft Purview Information Protection
  2. Microsoft Intune
  3. Azure Monitor
  4. Solo Microsoft Defender for Cloud Apps
Ver respuesta

Respuesta correcta: A. Fabric usa etiquetas de Microsoft Purview Information Protection.

3. El propietario de un equipo quiere destacar un modelo semántico como listo para un uso más amplio sin revisión formal. ¿Qué aprobación encaja?

  1. Datos maestros
  2. Etiqueta de confidencialidad
  3. Promovido
  4. Certificado
Ver respuesta

Respuesta correcta: C. Cualquier usuario con permiso de escritura puede promover un elemento.

4. ¿Cómo se pueden restringir filas en una base de datos KQL de un Eventhouse para distintos usuarios?

  1. Usar una configuración de sesión de Spark
  2. Usar un filtro de nivel de informe de Power BI
  3. Usar un parámetro de Dataflow Gen2
  4. Usar una directiva de seguridad de nivel de fila en la tabla
Ver respuesta

Respuesta correcta: D. Las bases de datos KQL admiten directivas de seguridad de nivel de fila.

5. Un lector del área de trabajo no debe leer una tabla confidencial del almacén aunque los lectores normalmente pueden consultar el punto de conexión SQL. ¿Qué puedes usar?

  1. Una aprobación Promovido
  2. Una regla de implementación
  3. Un tema nuevo del área de trabajo
  4. Un DENY de T-SQL en la tabla
Ver respuesta

Respuesta correcta: D. Los permisos de T-SQL pueden restringir aún más a los lectores del área de trabajo.

6. Antes de cambiar un lakehouse, quieres ver qué modelos semánticos, informes y paneles dependen de él. ¿Qué característica ayuda?

  1. Análisis de impacto en la vista de linaje
  2. Vista de prueba de roles de seguridad de nivel de fila
  3. Una actualización de flujo de datos
  4. Historial de elementos de la app de métricas de capacidad
Ver respuesta

Respuesta correcta: A. El análisis de impacto enumera los elementos descendentes y los usuarios afectados.

7. ¿Qué punto de conexión permite que herramientas como Tabular Editor o SSMS lean y escriban los metadatos de un modelo semántico en una capacidad de Fabric?

  1. El punto de conexión DFS de OneLake
  2. El URI de consulta KQL
  3. El punto de conexión XMLA
  4. El punto de conexión de análisis SQL
Ver respuesta

Respuesta correcta: C. El punto de conexión XMLA admite operaciones de lectura y escritura en modelos.

8. ¿Qué formato de informe de un proyecto de Power BI guarda cada página y objeto visual como archivos JSON separados más fáciles de comparar?

  1. PBIDS
  2. PBIT con parámetros para cada origen de datos
  3. PBIX
  4. PBIR
Ver respuesta

Respuesta correcta: D. PBIR (formato de informe mejorado) divide la definición del informe en muchos archivos, lo que mejora el control de código fuente.
