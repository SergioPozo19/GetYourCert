1. Which storage account setting prevents anonymous public read access to blobs at the account level?

  1. Disable 'Allow Blob anonymous access'
  2. Enable public containers with read-only SAS
  3. Enable static website with a custom domain
  4. Use account keys in code
Show answer

Correct answer: A. Disabling anonymous access is a baseline hardening step.

2. Which feature ensures blob data cannot be modified or deleted for a set period to meet regulatory requirements?

  1. A lifecycle rule that deletes blobs after seven years
  2. Blob versioning combined with soft delete
  3. Immutable storage with a time-based retention policy
  4. A read-only resource lock on the storage account
Show answer

Correct answer: C. WORM storage meets SEC and similar requirements.

3. Where does auditing for SQL Managed Instance write its logs?

  1. Local files on the instance host
  2. Microsoft 365 audit logs only
  3. Azure Storage, Log Analytics or Event Hubs
  4. The Azure Activity log only
Show answer

Correct answer: C. Auditing destinations include Storage, Log Analytics and Event Hubs.

4. Which authentication option for Azure Database for PostgreSQL Flexible Server lets you use Microsoft Entra identities?

  1. Public tokens
  2. Shared admin password only
  3. Anonymous login
  4. Microsoft Entra authentication
Show answer

Correct answer: D. Entra auth centralizes identity management.

5. Which Azure Firewall rule type translates inbound internet traffic to a private IP and port in the virtual network?

  1. Application rules
  2. Network rules
  3. Threat intelligence-based filtering
  4. DNAT rules
Show answer

Correct answer: D. DNAT publishes internal services through the firewall IP.

6. An organization wants to secure a Virtual WAN hub with firewall inspection of branch-to-branch and internet traffic. What should it deploy?

  1. Network security groups on each branch connection
  2. A secured virtual hub with Azure Firewall and routing intent
  3. A public IP address on each branch device
  4. A virtual hub without routing intent or a firewall
Show answer

Correct answer: B. Routing intent sends traffic through the firewall in the hub.

7. Which Network Watcher feature tests whether a specific packet is allowed or denied by NSG rules for a VM?

  1. IP flow verify
  2. Packet capture only
  3. Cost view
  4. Topology only
Show answer

Correct answer: A. IP flow verify identifies the rule allowing or denying traffic.

8. NSG flow logs are being retired. Which Network Watcher feature should you use instead to log traffic at the virtual network level?

  1. Virtual network flow logs
  2. IP flow verify
  3. Connection monitor
  4. Packet capture on every VM in the virtual network
Show answer

Correct answer: A. VNet flow logs record traffic for the whole virtual network, including traffic not governed by NSGs.
