AZ-900 · Dominio 3 de 3 · 30-35% del examen

Descripción de la administración y la gobernanza de Azure

El dominio 3 de AZ-900 supone entre el 30 y el 35% del examen. En EarnYourCert tienes 153 preguntas originales de este dominio, todas con explicación: 101 de opción múltiple, 25 de sí o no y 27 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 153 para este dominio. Intenta responder antes de ver la solución.

1. Un equipo financiero necesita generar automáticamente, cada mes, un archivo con el detalle de costes de Azure para cargarlo en su sistema de contabilidad, sin tener que entrar manualmente al portal. ¿Qué función de Microsoft Cost Management deben configurar?

  1. Azure Advisor con recomendaciones de coste basadas en el análisis del uso histórico de CPU y memoria de VM
  2. Un presupuesto (budget) de Microsoft Cost Management con alertas automáticas por correo al superar el umbral
  3. Una exportación (export) programada de datos de costes a una cuenta de almacenamiento
  4. La calculadora de precios de Azure para estimar el coste mensual de los servicios antes de desplegarlos
Ver respuesta

Respuesta correcta: C. Las exportaciones de Microsoft Cost Management permiten programar la generación periódica (diaria, semanal o mensual) de archivos con datos detallados de costes y guardarlos automáticamente en una cuenta de almacenamiento, desde donde otros sistemas pueden consumirlos. Un presupuesto solo genera alertas cuando se supera un umbral, no exporta datos detallados; Azure Advisor da recomendaciones, y la calculadora de precios estima costes futuros, no históricos.

2. Una empresa con cargas de trabajo en SQL Server local, con licencias cubiertas por Software Assurance, planea migrar esas bases de datos a Azure SQL Database. ¿Qué beneficio le permite reducir el coste de cómputo en Azure reutilizando esas licencias?

  1. Azure Hybrid Benefit
  2. Una VM Spot
  3. Precios Dev/Test
  4. Un plan de ahorro de almacenamiento
Ver respuesta

Respuesta correcta: A. Azure Hybrid Benefit permite a los clientes con licencias de SQL Server o Windows Server cubiertas por Software Assurance (o suscripciones equivalentes) aplicar esas licencias a recursos de Azure como Azure SQL Database o máquinas virtuales, reduciendo significativamente el coste de cómputo. Las VM Spot ofrecen descuentos por capacidad no utilizada sin relación con licencias, los precios Dev/Test se limitan a entornos de desarrollo y pruebas, y no existe un 'plan de ahorro de almacenamiento' como tal en Azure.

3. Una empresa quiere identificar máquinas virtuales que están infrautilizadas y que podrían cambiarse a un tamaño menor para reducir costes, basándose en su uso histórico de CPU y memoria. ¿Qué herramienta debería consultar en primer lugar?

  1. La calculadora de precios de Azure para comparar el coste teórico de distintos tamaños de VM en cada región
  2. Azure Advisor, en su sección de recomendaciones de costes
  3. El Service Trust Portal para revisar informes de auditoría y certificaciones de seguridad de Microsoft
  4. Azure Blueprints para desplegar entornos estandarizados con políticas y asignaciones de roles predefinidas
Ver respuesta

Respuesta correcta: B. Azure Advisor analiza la configuración y los patrones de uso de los recursos desplegados y, en su categoría de costes, sugiere acciones como redimensionar o apagar VM infrautilizadas para ahorrar dinero. La calculadora de precios sirve para estimar costes antes de desplegar, no para analizar recursos existentes; Azure Blueprints se usa para definir plantillas de gobernanza; y el Service Trust Portal proporciona documentación de cumplimiento, no recomendaciones de optimización de costes.

4. Una empresa europea necesita garantizar que el tratamiento de los datos personales de sus clientes cumple con el RGPD. ¿Qué tipo de requisito describe principalmente esto?

  1. Un requisito relacionado únicamente con el tamaño de las máquinas virtuales
  2. Un requisito exclusivamente de rendimiento de red
  3. Un requisito de cumplimiento normativo sobre protección de datos
  4. Un requisito que solo afecta a las copias de seguridad locales
Ver respuesta

Respuesta correcta: C. El RGPD (GDPR) es una normativa de protección de datos que impone requisitos de cumplimiento sobre cómo se recopilan, almacenan y procesan los datos personales, lo que las organizaciones deben tener en cuenta al usar servicios en la nube.

5. Un grupo de recursos contiene una base de datos crítica de producción. Un administrador aplica un bloqueo 'ReadOnly' (solo lectura) a ese grupo de recursos. ¿Qué efecto tiene esto sobre las operaciones que pueden realizar otros usuarios con permisos de Colaborador (Contributor)?

  1. El bloqueo ReadOnly no afecta a los usuarios con rol de Colaborador; solo restringe a los usuarios con rol de Lector
  2. Los usuarios con rol Colaborador podrán seguir modificando la configuración de los recursos, pero no eliminarlos
  3. Los usuarios con rol Colaborador podrán eliminar recursos individualmente, pero no modificar su configuración
  4. No podrán modificar ni eliminar ningún recurso del grupo, aunque RBAC les conceda permisos de Colaborador
Ver respuesta

Respuesta correcta: D. Un bloqueo 'ReadOnly' actúa de forma independiente de RBAC: impide cualquier operación de modificación o eliminación sobre los recursos del ámbito bloqueado, sin importar qué permisos RBAC tenga el usuario, incluso administradores. Esto contrasta con 'CanNotDelete', que solo impide eliminar pero permite modificar. El bloqueo se aplica a todos los usuarios, no solo a los que tienen rol de Lector.

6. ¿Qué permite configurar el escalado automático (autoscale) de Azure Monitor para un conjunto de escalado de máquinas virtuales?

  1. El idioma predeterminado de las máquinas virtuales
  2. Reglas que escalan instancias por métricas o agenda
  3. El cifrado de los discos del conjunto de escalado
  4. Las etiquetas aplicadas a la suscripción completa
Ver respuesta

Respuesta correcta: B. El escalado automático de Azure Monitor permite definir reglas que añaden o quitan instancias de un conjunto de escalado en función de métricas, como el uso de CPU, o de una programación horaria.

7. Un desarrollador escribe un archivo Bicep para definir una cuenta de almacenamiento, una red virtual y una máquina virtual. ¿Qué ocurre con ese archivo antes de que Azure Resource Manager lo procese?

  1. Se transpila (compila) a una plantilla ARM en formato JSON, que es lo que finalmente procesa Resource Manager
  2. Se convierte de forma automática en un runbook de Azure Automation ejecutable en un entorno de PowerShell 7
  3. Se ejecuta directamente como un script de PowerShell sin ninguna transformación previa por parte de Azure
  4. Azure Resource Manager interpreta el código Bicep de forma nativa sin conversión gracias al módulo bicep-runtime
Ver respuesta

Respuesta correcta: A. Bicep es un lenguaje declarativo de sintaxis simplificada que se transpila a una plantilla ARM en JSON; es esa plantilla JSON resultante la que Azure Resource Manager procesa realmente para desplegar los recursos. No se ejecuta como un script de PowerShell, no se convierte en un runbook, y aunque para el usuario el proceso es transparente, Resource Manager sigue trabajando internamente con JSON, no con Bicep directamente.

8. Un ingeniero configura diagnostic settings (configuración de diagnóstico) en una cuenta de almacenamiento para enviar los registros de actividad a un workspace de Log Analytics. ¿Qué se logra principalmente con esta configuración?

  1. Se restringe el acceso a la cuenta de almacenamiento para que solo se permitan conexiones desde rangos IP internos
  2. Se crea automáticamente una copia de seguridad diaria de todos los datos almacenados en la cuenta de Blob Storage
  3. Se aplica cifrado adicional con claves administradas por el cliente en Azure Key Vault a todos los datos en reposo
  4. Los registros de la plataforma del recurso se enrutan a un destino donde pueden consultarse, analizarse y usarse para alertas o paneles
Ver respuesta

Respuesta correcta: D. Las configuraciones de diagnóstico permiten enrutar los registros de la plataforma de un recurso (por ejemplo, registros de actividad o métricas) hacia destinos como un workspace de Log Analytics, una cuenta de almacenamiento o Event Hubs, donde los datos pueden consultarse con KQL, visualizarse en workbooks o usarse como base para alertas. No crean copias de seguridad de los datos del recurso, no aplican cifrado adicional, y no son un mecanismo de restricción de red.
