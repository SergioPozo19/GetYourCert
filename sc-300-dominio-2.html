Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 116 para este dominio. Intenta responder antes de ver la solución.

1. Un administrador sospecha que una cuenta está comprometida y quiere finalizar de inmediato todas las sesiones activas del usuario. ¿Qué debe hacer?

  1. Aumentar el número de licencias
  2. Esperar a que el token caduque de forma natural
  3. Revocar las sesiones del usuario y deshabilitar o restablecer la cuenta
  4. Eliminar solo el buzón del usuario
Ver respuesta

Respuesta correcta: C. Revocar las sesiones invalida los tokens de actualización, por lo que el usuario debe volver a autenticarse.

2. Un Active Directory local necesita la misma lista de contraseñas prohibidas que la nube. ¿Qué componentes se implementan?

  1. Servicio de proxy de Password Protection y agentes de DC
  2. Conectores del proxy de aplicaciones en los controladores de dominio
  3. Scripts de Intune Remediations
  4. Agentes de Microsoft Entra Cloud Sync con escritura diferida de contraseñas
Ver respuesta

Respuesta correcta: A. Los agentes de controlador de dominio validan las contraseñas con la directiva descargada mediante el proxy.

3. ¿Cómo puede una directiva de acceso condicional dirigirse solo a dispositivos que no son compatibles con Intune, como los portátiles personales no administrados?

  1. Una directiva de nomenclatura de grupos para los dispositivos
  2. Un filtro de dispositivos o la condición de estado del dispositivo
  3. Un conector de Application Proxy cerca de los dispositivos
  4. Revisiones de acceso para los propietarios cada trimestre
Ver respuesta

Respuesta correcta: B. Los filtros de dispositivos evalúan atributos del dispositivo como el tipo de confianza o el cumplimiento.

4. Los usuarios marcados con riesgo interno elevado por Purview deben bloquearse en aplicaciones confidenciales. ¿Qué condición del acceso condicional encaja?

  1. Plataformas de dispositivo
  2. Riesgo interno
  3. Aplicaciones cliente solo para exploradores y aplicaciones móviles
  4. Ubicaciones con nombre
Ver respuesta

Respuesta correcta: B. La condición de riesgo interno usa los niveles de protección adaptable de Microsoft Purview.

5. ¿Qué característica solicita a los usuarios que se registren en MFA mostrando un aviso al iniciar sesión durante un período definido?

  1. Ubicación con nombre
  2. Caducidad de grupo
  3. Revisión de acceso
  4. Campaña de registro
Ver respuesta

Respuesta correcta: D. Las campañas de registro animan a los usuarios a configurar Microsoft Authenticator.

6. ¿Qué tipo de detección de riesgo se genera cuando un usuario inicia sesión desde dos ubicaciones lejanas en un intervalo de tiempo que hace imposible el viaje?

  1. IP anónima
  2. Credenciales filtradas
  3. Difusión de contraseñas
  4. Viaje imposible
Ver respuesta

Respuesta correcta: D. El viaje imposible es una detección de riesgo de inicio de sesión sin conexión.

7. ¿Dónde investiga las identidades de carga de trabajo de riesgo, como una entidad de servicio con actividad sospechosa?

  1. El registro de actividad de Azure
  2. La pestaña de propietarios de registros de aplicaciones
  3. El informe de identidades de carga de trabajo de riesgo en ID Protection
  4. La página de consentimiento de aplicaciones empresariales
Ver respuesta

Respuesta correcta: C. Las detecciones de riesgo de cargas requieren Workload ID Premium y aparecen en ID Protection; el acceso condicional puede bloquear entidades de servicio de riesgo.

8. ¿Qué característica de Global Secure Access permite bloquear el acceso a categorías de sitios web como los juegos de azar mediante filtrado de contenido web?

  1. Application Proxy de Microsoft Entra con autenticación previa
  2. Filtrado de contenido web en directivas de Entra Internet Access
  3. Controles de sesión de acceso condicional para apps en la nube
  4. Restricciones universales de inquilino para los inquilinos externos
Ver respuesta

Respuesta correcta: B. Internet Access incluye capacidades de puerta de enlace web segura.
