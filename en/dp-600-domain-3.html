Correct answer: C. Variables are evaluated once and reused.

2. Which DAX function returns a table filtered by a condition and is often used as a CALCULATE filter argument?

  1. FORMAT
  2. FILTER
  3. LEN
  4. VALUE

Correct answer: B. FILTER returns rows meeting a predicate.

  2. Git integration
  3. Field parameters
  4. Mirroring
Show answer

Correct answer: C. Field parameters create a selectable list of fields.

4. Which feature should you enable when a semantic model might grow beyond the default size limit and needs efficient large-model handling?

  1. Large semantic model storage format
  2. Template apps with incremental refresh
  3. Dynamic data masking
  4. Sensitivity labels on large tables

5. A report author wants to extend an existing certified semantic model with extra tables from an Excel file without changing the original. Which approach fits?

  1. Build a composite model on top of the semantic model (DirectQuery to the model)
  2. Apply a sensitivity label
  3. Copy the model into a PBIX and delete the original
  4. Create a Git branch
Show answer

Correct answer: A. Composite models can extend shared semantic models.

6. Why is it recommended to disable Auto date/time for large models that already have a date table?

  1. It enables Direct Lake
  2. It avoids hidden date tables that add size

Correct answer: B. Auto date/time creates a hidden table per date column.

Correct answer: A. DirectLakeOnly disables fallback.
