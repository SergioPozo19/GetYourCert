Preguntas de ejemplo del dominio 3

8 preguntas de nuestro banco de 96 para este dominio. Intenta responder antes de ver la solución.

1. ¿Qué solución de Microsoft Purview detecta y ayuda a mitigar los riesgos de seguridad de datos del uso de IA generativa, incluido Copilot?

  1. Microsoft Purview Compliance Manager
  2. Solo la detección de Defender for Cloud Apps
  3. IDPS de Azure Firewall Premium
  4. Data Security Posture Management (DSPM) for AI
Ver respuesta

Respuesta correcta: D. DSPM for AI ofrece visibilidad y recomendaciones.

2. ¿Cuál es el propósito de la protección en tiempo real de los agentes de Copilot Studio?

  1. Supervisar y bloquear las acciones arriesgadas o inseguras de los agentes mientras se ejecutan
  2. Entrenar el modelo de lenguaje del agente con los prompts de los usuarios
  3. Reducir la latencia de respuesta del agente
  4. Archivar las conversaciones del agente para eDiscovery
Ver respuesta

Respuesta correcta: A. La protección en tiempo de ejecución añade una comprobación de seguridad durante la ejecución.

3. ¿Qué configuración de Defender for Servers proporciona análisis de vulnerabilidades sin instalar un agente en cada VM?

  1. Scripts de inventario manuales en cada VM
  2. Implementar el agente de Log Analytics
  3. Análisis sin agente
  4. Supervisión de integridad de archivos
Ver respuesta

Respuesta correcta: C. El análisis sin agente usa instantáneas de disco.

4. ¿Qué implementación de Azure Bastion evita la necesidad de una IP pública en las VM de destino y expone solo el servicio Bastion en la red virtual?

  1. Una dirección IP pública en cada VM de destino
  2. Una regla de NSG que abre RDP desde internet
  3. Azure Bastion implementado en una subred AzureBastionSubnet dedicada
  4. Una VM de salto con una IP pública
Ver respuesta

Respuesta correcta: C. Bastion necesita su propia subred.

5. ¿Qué configuración de Azure Container Apps permite que la aplicación use una identidad administrada para acceder a los secretos de Key Vault?

  1. Habilitar el acceso anónimo al almacén
  2. Guardar los secretos dentro de la imagen del contenedor
  3. Poner secretos en texto sin formato en variables de entorno
  4. Asignar una identidad administrada y hacer referencia a secretos de Key Vault
Ver respuesta

Respuesta correcta: D. Las identidades administradas evitan secretos incrustados.

6. ¿Qué característica de AKS protege los secretos montándolos desde Key Vault en los pods?

  1. Montajes anónimos
  2. Controlador CSI de Secrets Store con el proveedor de Key Vault
  3. Secretos incluidos en la imagen del contenedor al compilarla
  4. Secretos guardados como valores sin cifrar en ConfigMaps de Kubernetes
Ver respuesta

Respuesta correcta: B. El controlador CSI evita almacenar secretos en el estado del clúster.

7. Un servidor de API de AKS público solo debe aceptar conexiones de los intervalos IP de las oficinas. ¿Qué debes configurar?

  1. Intervalos IP autorizados del servidor de API
  2. Directivas de red de pods
  3. Protección en tiempo de ejecución de Defender for Containers en cada nodo
  4. Identidad de carga de trabajo
Ver respuesta

Respuesta correcta: A. Los intervalos IP autorizados limitan quién llega a un servidor de API público; un clúster privado elimina el punto de conexión público.

8. Las aplicaciones de App Service aún permiten implementaciones FTP con credenciales de publicación. ¿Qué debes hacer para reducir el riesgo?

  1. Habilitar el escalado automático
  2. Deshabilitar la autenticación básica para FTP y SCM
  3. Mover la aplicación a un plan de App Service superior con más instancias
  4. Agregar un dominio personalizado
Ver respuesta

Respuesta correcta: B. Deshabilitar la autenticación básica obliga a implementar con métodos basados en Microsoft Entra.
