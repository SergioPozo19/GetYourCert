8 questions from our 97-question bank for this domain. Try to answer before revealing the solution.

1. A multitenant SaaS app must scale out across many databases by tenant. Which pattern and tooling does Azure SQL support?

  1. Azure Backup for each tenant database
  2. Azure Table Storage with one partition
  3. Sharding with elastic database tools and elastic pools
  4. A single large VM running SQL Server
Show answer

Correct answer: C. Elastic tools help manage many databases and shard maps.

2. Which Cosmos DB API should you choose to migrate an existing MongoDB application with minimal code changes?

  1. Azure Cosmos DB for Gremlin
  2. Azure SQL
  3. Table storage only
  4. Azure Cosmos DB for MongoDB
Show answer

Correct answer: D. Compatible APIs reduce migration effort.

3. A solution stores billions of simple key-value entities with low cost and does not need rich queries. Which service is the cheapest fit?

  1. Azure Table Storage
  2. Azure SQL Business Critical
  3. Cosmos DB with 50,000 RU/s
  4. Azure NetApp Files
Show answer

Correct answer: A. Table Storage is a low-cost NoSQL key-value store.

4. Which storage account setting helps ensure data is encrypted with keys you control in Azure Key Vault?

  1. Allowing anonymous blob access
  2. Sharing the account keys with the team
  3. Enabling public network access
  4. Customer-managed keys for storage encryption
Show answer

Correct answer: D. CMK lets organizations control the key lifecycle.

5. Data is accessed about once a quarter, must stay online and be kept at least 90 days per tier change, at lower cost than Cool. Which blob tier fits?

  1. Cold
  2. Archive, with rehydration when the data is needed
  3. Premium
  4. Hot
Show answer

Correct answer: A. The Cold tier is online with a 90-day minimum; Archive is offline and needs rehydration.

6. A multitenant Cosmos DB container would exceed the 20 GB logical partition limit for large tenants partitioned by TenantId. What should you design?

  1. A separate Cosmos DB account per user
  2. A single partition key value for all data
  3. Hierarchical partition keys such as TenantId then UserId
  4. Manual throughput raised to the maximum for the container
Show answer

Correct answer: C. Hierarchical partition keys subpartition data so large tenants can exceed 20 GB while queries stay targeted.

7. Which service runs real-time SQL-like queries over streaming data from Event Hubs or IoT Hub?

  1. Azure Event Hubs
  2. Azure Data Lake Storage
  3. Azure Stream Analytics
  4. Azure Data Factory
Show answer

Correct answer: C. Stream Analytics provides serverless stream processing.

8. A global app needs a relational database with multi-region writes and low latency. Which Azure service should you evaluate?

  1. Azure Database for MySQL single server
  2. Azure SQL Database with a read replica
  3. Azure Table Storage with GRS
  4. Azure Cosmos DB with multi-region writes
Show answer

Correct answer: D. Cosmos DB supports multi-region writes with configurable consistency levels. Azure SQL replicas are read-only.
