Diseñar soluciones de almacenamiento de datos

El dominio 2 de AZ-305 supone entre el 20 y el 25% del examen. En EarnYourCert tienes 97 preguntas originales de este dominio, todas con explicación: 63 de opción múltiple, 15 de sí o no y 19 de completar u ordenar, como en el examen real.

Preguntas de ejemplo del dominio 2

8 preguntas de nuestro banco de 97 para este dominio. Intenta responder antes de ver la solución.

1. Una aplicación SaaS multiinquilino debe escalar horizontalmente entre muchas bases de datos por inquilino. ¿Qué patrón y herramientas admite Azure SQL?

  1. Azure Backup para cada base de datos de inquilino
  2. Azure Table Storage con una sola partición
  3. Particionamiento horizontal (sharding) con herramientas de bases de datos elásticas y grupos elásticos
  4. Una sola VM grande con SQL Server
Ver respuesta

Respuesta correcta: C. Las herramientas elásticas ayudan a administrar muchas bases de datos y mapas de particiones.

2. ¿Qué API de Cosmos DB debes elegir para migrar una aplicación MongoDB existente con cambios mínimos de código?

  1. Azure Cosmos DB for Gremlin
  2. Azure SQL
  3. Solo Table Storage
  4. Azure Cosmos DB for MongoDB
Ver respuesta

Respuesta correcta: D. Las API compatibles reducen el esfuerzo de migración.

3. Una solución almacena miles de millones de entidades simples clave-valor con bajo coste y no necesita consultas avanzadas. ¿Qué servicio es el más barato?

  1. Azure Table Storage
  2. Azure SQL Business Critical
  3. Cosmos DB con 50 000 RU/s
  4. Azure NetApp Files
Ver respuesta

Respuesta correcta: A. Table Storage es un almacén clave-valor NoSQL de bajo coste.

4. ¿Qué configuración de la cuenta de almacenamiento ayuda a garantizar que los datos se cifran con claves que controlas en Azure Key Vault?

  1. Permitir el acceso anónimo a blobs
  2. Compartir las claves de la cuenta con el equipo
  3. Habilitar el acceso a la red pública
  4. Claves administradas por el cliente para el cifrado del almacenamiento
Ver respuesta

Respuesta correcta: D. CMK permite a las organizaciones controlar el ciclo de vida de las claves.

5. Los datos se consultan una vez al trimestre, deben seguir en línea y mantenerse al menos 90 días por cambio de nivel, con menor coste que Esporádico. ¿Qué nivel de blob encaja?

  1. Frío
  2. Archivo, con rehidratación cuando se necesiten los datos
  3. Premium
  4. Frecuente
Ver respuesta

Respuesta correcta: A. El nivel Frío está en línea con un mínimo de 90 días; Archivo está sin conexión y requiere rehidratación.

6. Un contenedor multiinquilino de Cosmos DB superaría el límite de partición lógica de 20 GB para inquilinos grandes particionados por TenantId. ¿Qué debes diseñar?

  1. Una cuenta de Cosmos DB por usuario
  2. Un único valor de clave de partición para todos los datos
  3. Claves de partición jerárquicas como TenantId y luego UserId
  4. Rendimiento manual elevado al máximo para el contenedor
Ver respuesta

Respuesta correcta: C. Las claves jerárquicas subdividen los datos para que los inquilinos grandes superen 20 GB manteniendo las consultas dirigidas.

7. ¿Qué servicio ejecuta consultas en tiempo real tipo SQL sobre datos de streaming de Event Hubs o IoT Hub?

  1. Azure Event Hubs
  2. Azure Data Lake Storage
  3. Azure Stream Analytics
  4. Azure Data Factory
Ver respuesta

Respuesta correcta: C. Stream Analytics proporciona procesamiento de streaming sin servidor.

8. Una app global necesita una base de datos con escrituras en varias regiones y baja latencia. ¿Qué servicio de Azure debe evaluar?

  1. Azure Database for MySQL servidor único
  2. Azure SQL Database con una réplica de lectura
  3. Azure Table Storage con GRS
  4. Azure Cosmos DB con escrituras en varias regiones
Ver respuesta

Respuesta correcta: D. Cosmos DB admite escrituras en varias regiones con niveles de coherencia configurables. Las réplicas de Azure SQL son de solo lectura.
