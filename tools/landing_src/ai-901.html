Confusiones típicas en el examen

Common exam traps

Temperatura frente a máximo de tokens

Temperature vs maximum tokens

La temperatura controla lo creativa o aleatoria que es la respuesta; el máximo de tokens solo limita su longitud.

Temperature controls how creative or random the answer is; maximum tokens only limits its length.

RAG frente a ajuste fino

RAG vs fine-tuning

RAG añade tus documentos a la indicación en cada pregunta y se actualiza al cambiar los datos; el ajuste fino cambia el comportamiento del modelo con ejemplos y no sirve para datos que cambian a menudo.

RAG adds your documents to the prompt on every question and stays current as data changes; fine-tuning changes the model's behavior with examples and is a poor fit for data that changes often.

Prompt Shields frente a detección de fundamentación

Prompt Shields vs groundedness detection

Prompt Shields detecta intentos de saltarse las instrucciones (jailbreak e inyección); la detección de fundamentación comprueba si la respuesta se apoya en las fuentes dadas.

Prompt Shields detects attempts to bypass instructions (jailbreaks and injection); groundedness detection checks whether the answer is supported by the given sources.

Transliteración frente a traducción

Transliteration vs translation

La transliteración cambia el alfabeto sin cambiar el idioma; la traducción cambia el idioma.

Transliteration changes the script without changing the language; translation changes the language.
