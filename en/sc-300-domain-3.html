8 questions from our 103-question bank for this domain. Try to answer before revealing the solution.

1. What is the difference between a system-assigned and a user-assigned managed identity?

  1. User-assigned identities cannot access Key Vault, so system-assigned is required for secrets
  2. System-assigned follows one resource's lifecycle; user-assigned is standalone and shareable
  3. There is no difference
  4. System-assigned identities can be used only by users, while user-assigned ones serve apps
Show answer

Correct answer: B. Use user-assigned identities when multiple resources need the same identity or when you need to pre-authorize access.

2. An application running on a virtual machine needs to call the Azure Resource Manager API without credentials in code. What is the correct sequence?

  1. Enable a managed identity on the VM and grant it an Azure role
  2. Create a guest user for the app and store its password on the VM
  3. Store an administrator password in the app configuration file
  4. Disable Azure RBAC on the subscription
Show answer

Correct answer: A. The app gets tokens from the instance metadata endpoint without handling secrets.

3. Which authentication approach lets a GitHub Actions workflow access Azure resources without storing a secret?

  1. SMS verification
  2. A long-lived client secret in the repository
  3. A shared admin password
  4. Workload identity federation using OpenID Connect
Show answer

Correct answer: D. Federated credentials trust tokens from external identity providers.

4. What does the Microsoft Entra Application Proxy connector require regarding network connectivity?

  1. Outbound access to the Application Proxy service; no inbound ports
  2. A public IP address on the server
  3. Inbound access from the internet to the server
  4. A dedicated ExpressRoute
Show answer

Correct answer: A. Outbound-only connections reduce attack surface.

5. An app registration is configured for a single-page application. Which setting must be added so Entra ID can return tokens to the app after sign-in?

  1. A redirect URI of the SPA type
  2. A DNS TXT record
  3. A custom banned password
  4. A dynamic group rule
Show answer

Correct answer: A. Redirect URIs define where tokens or authorization codes are sent after authentication.

6. Which Defender for Cloud Apps capability helps you manage risky OAuth apps that have access to company data?

  1. App governance and OAuth app policies
  2. BitLocker policies for the managed endpoints
  3. Teams meeting policies for external attendees
  4. Azure Bastion hosts in the virtual network
Show answer

Correct answer: A. OAuth app policies detect overprivileged or suspicious apps and allow remediation.

7. You mark a cloud app as unsanctioned in Defender for Cloud Apps. What can you do next?

  1. Reset all user passwords for the app
  2. Block it through Defender for Endpoint or a network appliance
  3. Delete the app's registration and all of its service principals
  4. Disable MFA for the users who accessed the app last month
Show answer

Correct answer: B. Unsanctioning can be enforced with endpoint or network integration.

8. Which Defender for Cloud Apps capability gives detailed insight into OAuth apps' data access and lets you set policies on unusual behavior, such as an app suddenly reading many emails?

  1. Log collector
  2. App governance
  3. Cloud Discovery
  4. Conditional Access app control with session policies
Show answer

Correct answer: B. App governance monitors Graph API usage of OAuth apps and can automatically disable risky apps.
