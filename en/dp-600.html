DP-600 sample questions

Five real questions from our 309-question bank. Try to answer before revealing the solution.

1. Many report authors should reuse one governed semantic model instead of creating their own copies. Which approach fits?

  1. Export the data to Excel for each author
  2. Create one PBIX per author with imported data
  3. Give every author the Admin role
  4. Build reports on a shared semantic model
Show answer

Correct answer: D. A shared model gives one source of truth.

2. Which KQL operator visualizes results as a chart, for example a time chart?

  1. parse
  2. lookup
  3. top
  4. render
Show answer

Correct answer: D. render draws charts from query results.

3. Which KQL operator joins two tables on a key, for example logs and a device list?

  1. render
  2. take
  3. join
  4. extend
Show answer

Correct answer: C. join combines tables on matching keys.

4. Which type of DAX function evaluates an expression row by row over a table and then aggregates the results?

  1. Logical operator
  2. Time intelligence function only
  3. Iterator (for example SUMX)
  4. Information function
Show answer

Correct answer: C. Iterators create a row context.

5. Which DAX practice improves performance when the same sub-expression is used several times in a measure?

  1. Repeat it each time
  2. Store it in a variable
  3. Convert it to text
  4. Wrap it in FORMAT
Show answer

Correct answer: B. A variable is evaluated once.
