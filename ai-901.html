Preguntas de ejemplo de AI-901

Cinco preguntas reales de nuestro banco de 302. Intenta responder antes de ver la solución.

1. En una solicitud a un modelo de chat, ¿qué rol de mensaje establece el comportamiento general y las reglas del asistente?

  1. Asistente
  2. Sistema
  3. Salida de herramienta
  4. Usuario
Ver respuesta

Respuesta correcta: B. El mensaje del sistema guía el comportamiento del modelo.

2. ¿Qué capacidad encuentra y puede ocultar elementos sensibles como números de teléfono y direcciones de correo en un texto?

  1. Descripción de imágenes
  2. Detección de objetos
  3. Detección de información de identificación personal (PII)
  4. Síntesis de voz
Ver respuesta

Respuesta correcta: C. La detección de PII ayuda a proteger los datos personales.

3. ¿Qué enfoque de autenticación se prefiere frente a incrustar una clave de API en el código de la aplicación?

  1. Sin autenticación
  2. Una clave compartida en un repositorio público
  3. Microsoft Entra ID (identidad administrada)
  4. Contraseñas escritas en el archivo de configuración
Ver respuesta

Respuesta correcta: C. La autenticación de Entra ID sin claves evita filtrar secretos.

4. ¿Qué incluye normalmente una respuesta de análisis de opiniones para cada documento?

  1. Un archivo de audio traducido
  2. Un cuadro delimitador para cada palabra y su posición en la página
  3. Solo el recuento de palabras y el idioma detectado del documento
  4. Una etiqueta de opinión (positiva, neutra o negativa) con puntuaciones
Ver respuesta

Respuesta correcta: D. Los resultados de opinión incluyen etiquetas y puntuaciones.

5. ¿Qué función del análisis de audio etiqueta qué hablante dijo cada parte de una conversación?

  1. Etiquetado de imágenes
  2. OCR
  3. Diarización de hablantes
  4. Solo redacción de entidades
Ver respuesta

Respuesta correcta: C. La diarización atribuye el habla a los hablantes.

Preguntas frecuentes

¿Cuántas preguntas tiene el examen de práctica AI-901?

El banco de preguntas tiene 302 preguntas originales. Cada simulacro de examen selecciona 50 preguntas ponderadas por dominio, igual que el examen oficial.

¿Cuál es la puntuación mínima para aprobar AI-901?

El examen oficial de Microsoft AI-901 se aprueba con una puntuación equivalente al 70%. Usamos ese mismo umbral en los simulacros para que practiques en condiciones realistas.

¿Qué dominios cubre el examen AI-901?

Dos dominios: identificar conceptos y capacidades de IA (40-45%) e implementar soluciones de IA con Microsoft Foundry (55-60%).

¿Es gratis el examen de práctica AI-901?

Sí, puedes practicar gratis sin registrarte. Crear una cuenta gratuita añade seguimiento de progreso y repaso inteligente (SRS); la versión Pro elimina los límites diarios de preguntas.

¿Son las preguntas oficiales del examen de Microsoft?

No. Son preguntas originales escritas a partir de la guía oficial de habilidades evaluadas ("Skills measured") de Microsoft para AI-901, no extractos del examen real ni "exam dumps".
