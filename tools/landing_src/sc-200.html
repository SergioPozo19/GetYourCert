Confusiones típicas en el examen

Common exam traps

Regla de automatización frente a cuaderno de estrategias

Automation rule vs playbook

La regla de automatización hace acciones sencillas (asignar, etiquetar, cerrar) y puede lanzar un cuaderno; el cuaderno es una Logic App para lógica compleja o llamadas a otros sistemas.

An automation rule does simple actions (assign, tag, close) and can trigger a playbook; a playbook is a Logic App for complex logic or calls to other systems.

Regla programada frente a NRT

Scheduled vs NRT rule

La programada se ejecuta cada cierto intervalo sobre una ventana de datos; la casi en tiempo real se ejecuta cada minuto con consultas más limitadas.

A scheduled rule runs on an interval over a data window; a near-real-time rule runs every minute with more limited queries.

summarize frente a project

summarize vs project

project elige o renombra columnas; summarize agrupa filas y calcula agregados como count() o dcount().

project picks or renames columns; summarize groups rows and computes aggregates such as count() or dcount().
