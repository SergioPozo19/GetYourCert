DP-600 study guide: what's covered and how to prepare

DP-600 is the Microsoft Fabric analytics engineer exam. It covers lakehouses and warehouses, how to load and transform data, and fast semantic models for Power BI.

Maintain the solution (25-30%)

  • Workspaces, capacities, roles and item permissions
  • Row-, column- and object-level security in the warehouse
  • Deployment pipelines and Git integration
  • Sensitivity labels, endorsement and lineage analysis

Prepare data (45-50%)

  • Lakehouse vs warehouse, shortcuts and OneLake
  • Ingestion with pipelines, Dataflow Gen2 and notebooks
  • Transform with SQL, PySpark and KQL
  • Delta tables, optimization (V-Order, OPTIMIZE, VACUUM) and dimensional models

Semantic models (25-30%)

  • Storage modes: Import, DirectQuery and Direct Lake
  • DAX: measures, calculation groups and field parameters
  • Performance: DAX Studio, Tabular Editor and Best Practice Analyzer
  • Incremental refresh and large models

5-week study plan

1Fabric basics: workspaces, capacities, OneLake and permissions.
2Ingestion: pipelines, Dataflow Gen2, notebooks and shortcuts.
3Transformation with SQL and PySpark, and Delta table optimization. This is the heaviest domain.
4Semantic models: Direct Lake, DAX and performance.
5Deployment pipelines, Git and full mock exams until you score above 80%.

Common exam traps

Lakehouse vs warehouse

A lakehouse stores files and Delta tables and is worked mainly with Spark (its SQL endpoint is read-only); a warehouse supports full T-SQL with writes.

Direct Lake vs DirectQuery

Direct Lake reads Delta tables in OneLake directly, with near-Import performance and no data copy; DirectQuery sends queries to the source on every interaction.

Shortcut vs copying data

A shortcut points to data that already lives elsewhere (another lakehouse, ADLS, S3) without moving it; copying duplicates storage and must be kept in sync.

DP-600 sample questions

Five real questions from our 391-question bank. Try to answer before revealing the solution.

1. Many report authors should reuse one governed semantic model instead of creating their own copies. Which approach fits?

  1. Export the data to Excel for each author
  2. Create one PBIX per author with imported data
  3. Give every author the Admin role
  4. Build reports on a shared semantic model
Show answer

Correct answer: D. A shared model gives one source of truth.

2. How can you share a Fabric workspace's items with the lineage to see downstream impact before a change?

  1. Email the owners of every report
  2. Use impact analysis in the lineage view
  3. Delete the item and check for errors
  4. Export the workspace to a PBIX file
Show answer

Correct answer: B. Impact analysis lists downstream items and users that depend on an item.

3. Which KQL operator visualizes results as a chart, for example a time chart?

  1. parse
  2. lookup
  3. top
  4. render
Show answer

Correct answer: D. render draws charts from query results.

4. A JSON column contains an array of order lines per order. Which PySpark function turns each array element into its own row?

  1. explode
  2. coalesce
  3. dropDuplicates
  4. withColumnRenamed for each element of the array
Show answer

Correct answer: A. explode creates one output row per array element.

5. Which type of DAX function evaluates an expression row by row over a table and then aggregates the results?

  1. Logical operator
  2. Time intelligence function only
  3. Iterator (for example SUMX)
  4. Information function
Show answer

Correct answer: C. Iterators create a row context.

Frequently asked questions

How many questions does the DP-600 practice exam have?

The question bank has 391 original questions. Each practice exam draws 50 questions weighted by domain, just like the official exam.

What's the passing score for DP-600?

Microsoft's official DP-600 exam requires a score equivalent to 70% to pass. We use the same threshold in our practice exams so you train under realistic conditions.

What domains does the DP-600 exam cover?

Three domains: maintain a data analytics solution (25-30%), prepare data (45-50%), and implement and manage semantic models (25-30%).

Is the DP-600 practice exam free?

Yes, you can practice for free without signing up. Creating a free account adds progress tracking and smart review (SRS); the Pro tier removes daily question limits.

Are these the official Microsoft exam questions?

No. These are original questions written based on Microsoft's official "Skills measured" guide for DP-600, not extracts from the real exam or "exam dumps".

How much does the official DP-600 exam cost?

In the United States it costs 165 USD. Elsewhere the price depends on the country and currency, and you see it when booking from Microsoft Learn. Students may get a discount.

How long is the DP-600 exam and how many questions does it have?

You get about 100 minutes to answer, usually 40 to 60 questions, which may include case studies with several questions about the same scenario. Besides multiple choice there are yes/no, drag-and-drop and completion items, like in our practice exams.

Can you use Microsoft Learn during the DP-600 exam?

Yes. During the exam you can open Microsoft Learn in a window, but the clock keeps running. Use it only for specific doubts, not to learn something from scratch.

Does the DP-600 certification expire?

Yes, it lasts one year. You renew it for free with an online assessment on Microsoft Learn during the six months before it expires, without paying for the exam again.
